# D15-A08 音频占位策略

本批次的 30 个音乐主题和 8 个音频层先以 ContentRegistry 元数据和 `.gitkeep` 占位引用登记，未把占位文件伪装成已完成录音。正式素材替换前必须保持 `asset_state=placeholder`，并完成来源、授权、触发条件、混音总线、方向性、字幕回退、循环和加载尖峰检查。

占位资源只允许被音频目录检查器和 UI/事件回退读取；它不写入天气、战斗、关系、任务、经济或奖励状态。替换为正式素材时，资产 Agent 只更新 `asset_` 元数据和授权记录，触发裁决仍由所属系统提供确定性状态。

目标质量门槛：音频层 Q1 占位 → Q2 可审查素材 → Q3 发布素材；音乐主题 Q2 目录 → Q3 发布素材。所有主题都保留 `subtitle_key` 和 `fallback=ui_text_and_event_log`，确保无声或跳过语音时仍可完成游戏。
