## 1. 游戏概述

- **一句话**：1675 年加勒比海域的开放世界航海沙盒 RPG——你是无名水手，在英西法葡列强夹缝中经营船与船员，探索岛屿、贸易、寻宝、生存，最终经营自己的岛屿与势力。
- **类型标签**：开放世界 / 航海模拟 / 生存 / 角色扮演 / 贸易 / 沙盒经营（后期岛屿殖民地）/ 单人（多人预留）
- **背景（已定）**：**1675 年**，海盗黄金时代（1650-1730）开篇，加勒比海，英西法葡四国殖民地并存、冲突密集；西班牙珍宝船队活跃。时代依据见 `docs/game/DESIGN_PILLARS.md` 第 0 节。
- **视角**：第三人称（甲板自由行走）+ 舰桥指挥模式（船员调度/航线）
- **目标（已定）**：**沙盒**——无强制结局，玩家自选路线（商人/海盗/探险家/寻宝人/殖民者）；**后期可经营岛屿、地图势力拓展**；主线简单合理（教学引导器），支线支撑探索/玩法拓展/收藏/寻宝。
- **设计哲学（已定）**：**真实主义、无奇幻**——死寂真实的大海 + 真实海洋动物互动；获取途径符合史实逻辑、不设解密门槛。详见 `DESIGN_PILLARS.md`。
- **美术**：低多边形（Synty 类）热带加勒比风格
- **单次时长**：单航程 30-60 分钟；存档长线（数百小时）
- **初始状态（补）**：初始小船一艘（小渔船，2-3 人）、初始资金少量（够补给 + 一次小贸易）、初始船员 2-3 名（含一名老水手，作为新手引导"老师"）、初始负债 ⚠️（可选：开局背负旧船债，主线引导从还债开始——待定，默认不做）
- **失败与惩罚（补）**：沉船不删档（货物漂流可捞、船员损失不可逆）；被列强逮捕→入狱（时间+罚金）或交赎金、货物没收；被海盗抢劫→可选抵抗/投降；重伤→治疗期。**玩家角色死亡处理 ⚠️ 设计阶段定**（永久死亡 vs 复活惩罚）
- **新手引导（补）**：主线即引导器（P3 支柱）——前 3-5 个主线任务依次教会：航行/贸易/登岛/船员对话/战斗，完成后主线转为可选
- **音频方向（补）**：航海氛围（海浪/风声/帆布/雷暴环境音）+ 民间小调（辛巴达式口琴/手鼓，港口/酒馆/航行分场景）+ AI 生成 + 商用授权（见 SETUP 5.5）

## 2. 核心循环（一次航程 = 一个故事）

```
整备：船坞修船 / 市场采购 / 酒馆招募水手 / 听港口传闻
→ 航线规划：看海图 / 选目的地 / 评估天气与列强巡逻风险
→ 航行：值班轮换（舵手/瞭望/炮手）/ 天气应变 / 与船员交谈 / 突发事件
→ 遭遇：风暴 / 海盗 / 列强巡逻 / 疾病爆发 / 海图未标注的未知小岛
→ 登岛：锚泊 / 登陆采集 / 探索 / 危险遭遇（蛇/蚊虫/掠食者）/ 宝藏 / 部落交易
→ 交易与任务：城镇港商业 / 市政任务 / 黑市 / 沉船打捞
→ 结算：卖货 / 修船 / 分红 / 犒赏（影响忠诚）
→ 船员关系与文化冲突演化 → 下一航程
```

## 3. 系统设计（玩家设定 → 整合为 8 大系统）

> 元素全量登记见 `docs/game/IDEA_BANK.md`（创意池，可无限追加）；新元素按支柱排序进入各系统。

### 3.1 贸易经济系统
- 商品 14 种：香料 / 朗姆酒 / 丝绸 / 烟草 / 蔗糖 / 军火 / 黄金 / 木材 / 染料 / 咖啡 / 可可 / 兽皮 / 药材 / 淡水与补给。**人的自由状态不是商品**；奴役、强迫劳动和跨大西洋贩运作为独立的历史/社会系统处理，不能放进货舱或商品价格表。
- 价格公式：`基础价 × 供需系数 × 列强关税 × 事件扰动`（骨架有默认公式）
- 特色：**列强关税差**（英西法葡不同税率 → 走私/黑市玩法）；港口特产差异

### 3.2 船员状态机（含特质系统 ★玩家核心需求）
- 数值：士气 / 忠诚 / 健康 / 疲劳 / 好感（-100~100）+ 技能 8 项（操帆/领航/炮术/木工/医术/厨艺/贸易/格斗）
- **特质系统**（新建）：角色与 NPC 生成时随机 **3-4 条**特质，每条 = 数值增益/减益 + Persona 注入 + 事件概率修正
  - 分类与首批数量（共 50 条）：
    - 身体（15）：强壮 / 瘦弱 / 肺病 / 肠胃好 / 老花眼 / 伤腿 / 好视力 / 抗热 / 怕冷 / 酒量好…
    - 性格（20）：贪婪 / 怯懦 / 忠诚 / 嗜酒 / 多疑 / 冲动 / 谨慎 / 豪爽 / 记仇 / 乐天…
    - 经历（10）：老水手 / 前私掠者 / 逃犯 / 传教士 / 前海军 / 落难贵族 / 奴隶贩子 / 医生学徒…
    - 疾病（5）：坏血病 / 热病（疟疾） / 黄热病 / 痢疾 / 肺痨（"梅毒"已移除——分级风险；疟疾/黄热病是加勒比真实大杀手，更贴背景）
  - 映射示例：`肺病` → 疲劳上限 -20%、健康衰减 +50%、Persona 注入"你时常咳嗽，爬桅杆吃力"
- 叛变机制：忠诚 + 士气 + 特质（贪婪者更易被策反）→ 事件系统裁决
- **疾病与医疗**：医生职业 / 医疗舱 / 草药（登岛采集）→ 对应健康系统 ⚠️（医疗系统深度待定）
- **人际关系与爱情**（新增）：好感度深化为多维度关系（友谊 / 信任 / 爱情 / 仇恨 / 嫉妒）
  - 玩家↔NPC：对话/礼物/共患难推进感情线（分级内克制表达，不露骨）
  - NPC↔NPC：船员之间也会恋爱、结仇、争风吃醋（AI 生成互动，强逻辑触发事件）
  - 爱情影响：忠诚加成（爱着玩家的船员更忠诚）/ 叛变风险（被背叛的恋人可能投敌）/ 事件（三角恋、争风吃醋）
  - 载体：篝火夜话、酒馆舞会、港口重逢（重交互场景）
  - 分级：Steam 年龄分级问卷按"浪漫/轻微暗示"填写，不做成人内容

### 3.3 事件因果链
- 首批事件 12-15 个，三类：
  - 自然：风暴 / 台风 / 雾 / 坏血病爆发 / 鼠患 / 搁浅 / **船舱火灾**（火药库最危，真实威胁）
  - 人为：海盗袭击 / 列强登船检查 / 叛变苗头 / 船员斗殴 / 文化冲突（宗教/价值观）/ **爱情冲突（争风吃醋/背叛）**
  - 探索：沉船线索 / 宝藏地图 / 部落遭遇 / 珍稀动物目击
- 触发 = 数值阈值 + 随机 + 剧情锚点（强逻辑裁决，LLM 只生成台词与细节）

### 3.4 声望阵营与列强干涉系统（列强争夺 ★玩家核心需求）
- 阵营 7 个：英格兰 / 西班牙 / 法兰西 / 葡萄牙 / 海盗兄弟会 / 加勒比原住民 / 走私网络
- 声望效果：关税折扣 / 专属任务（护航、私掠证）/ 港口通行权 / 通缉与悬赏
- **战争状态**：列强间开战/停战会改变海域局势（巡逻强度、商品价格）→ 玩家可火中取栗
- **海上强国干涉（新增深化）**：1675 常态——
  - **禁运/封锁**：特定港口禁运 → 走私/黑市机会（高风险高回报）
  - **私掠证**：合法抢劫敌国商船（海盗路线的"合法化"，需对应国声望）
  - **扣押/登船检查**：货物合规判定，违禁品被没收/罚款
  - **护航任务**：护卫商队，列强发布
  - ⚠️ 外交谈判（作为势力代表）💡 后置
- 文化差异影响谈判（见 3.7）

### 3.5 船只系统 ★玩家核心需求（最大系统，分 4 子块）
- **3.5.1 船型**（首批 8 种，属性：航速/转向/载重/炮位/船员上限/耐久/吃水/售价）：
  - 小渔船(2-3人) → 单桅纵帆船 → 双桅纵帆船 → 横帆快船 → 小型盖伦 → 商船 → 军用盖伦(重炮) → 传奇旗舰 ⚠️（旗舰后置）
- **3.5.2 改装与装饰**：船体/帆/炮/货舱/医疗舱/厨房/住所（舱室家具）/喷漆/风帆涂鸦——全部数值化+外观层
  - ⚠️ 小游戏拓展（如修船小游戏、装填小游戏）：放 EA 后，先做数值化改装
- **3.5.3 船体状态**：耐久 → 破损 → 进水 → 倾斜（倾斜角影响甲板物品滑动/落海概率）→ 沉船（沉船后货物漂流+船员损失，不直接 Game Over）
  - 买卖：港口船坞（带旧船折价换新）
  - ⚠️ "断裂/物体物理滚动"：M2 做**简化版**（倾斜角数值 + 槽位物品落海概率），完整物理后置
- **3.5.4 驾船与岗位**：玩家设岗位（舵手/瞭望/炮手/修船/瞭望），AI 船员执行；**语言喊话 = P2A 命令**（"左满舵""升主帆""准备接舷战"）→ 这是"重交互"的旗舰卖点
  - 航线日志：自动记录（日期/航路/事件/船员日记，AI 生成摘要）
  - 武器：炮（实心弹/链弹/葡萄弹）+ 登船战（简化格斗）

### 3.6 天气系统
- 7 种：晴 / 多云 / 雨 / 大风 / 风暴 / 台风 / 浓雾（+ 黄昏/日落氛围光）
- 影响：航速 / 疲劳 / 船舱进水 / 事件概率 / 贸易价格（台风后港口缺货）

### 3.7 岛屿与生态系统 ★玩家核心需求（含文化系统）
- **地貌（已定案）**：加勒比 **热带海岛生态**——红树林 / 椰林 / 珊瑚礁 / 雨林 / 白沙滩；与 1675 加勒比背景一致（原"地中海地貌"方案已废弃）
- 岛屿类型 5 种：城镇港（船坞/商业/市政）/ 村落（部落/集市）/ 荒岛（采集/危险）/ 特殊岛（沉船/宝藏/遗迹）/ 列强要塞
- **动物逻辑（拟真降级为"可预判行为"）**：栖息地分布 + 行为状态机（觅食/警戒/攻击/繁殖提示）——完整"繁育/进食拟真"放 EA 后
  - **首批 15 种（全部真实物种，无奇幻）**：海洋 6（鲸群 / 海豚 / 鲨鱼 / 海龟 / 蝠鲼 / 鱼群）/ 无害陆生 4（鬣蜥 / 鹦鹉 / 寄居蟹 / 蟹）/ 危险 4（毒蛇 / 蚊虫群 / 鳄鱼 / 美洲豹）/ 珍稀 1（黄金鹦鹉 ⚠️（金色变种，写实化））
  - **真实行为锚点**：鲸群迁徙路线固定、海豚随船伴航、鲨鱼被血腥味吸引、海龟特定沙滩产卵（珍稀动物互动点）、鸟群指引近陆方向
  - **危险机制**：蚊虫→疾病源；毒蛇→中毒（需医生/药物）；美洲豹/鳄鱼→登岛必须"团结"（带武器/多人/火把）
- **珍稀动物交易与收藏（新增）**：捕猎/圈养/交易珍稀动物（黄金鹦鹉、海龟、鬣蜥等）——真实生意：加勒比珍稀动物运回欧洲贵族圈
  - 买家：港口收藏家 NPC、庄园主、原住民交换（文化差异定价）
  - 收藏册系统：博物收集（探险家路线的成长与声望来源）
  - ⚠️ 圈养（船上/殖民地）💡 后置
- **文化系统（4 大文化群 + 原住民）**：英格兰/西班牙/法兰西/葡萄牙 + 加勒比原住民
  - 每文化：语言口吻 / 宗教（天主教/新教/本土信仰）/ 价值观（荣誉/贸易/殖民态度）/ 行为礼仪
  - 游戏化：文化差异 → 贸易价差 / 任务解锁 / 谈判成功率 / **船员内部文化冲突事件**（AI 生成，强逻辑触发）
  - LLM 优势点：Persona 注入文化背景后，NPC 的价值观冲突对话天然真实——这是"纯 Agent"游戏最能打的差异化

### 3.8 生存与生活系统（新增 ★真实主义支柱的载体）
- **火焰**：生火（火石/燧发，技能+天气影响）；火把（夜间登岛/驱兽）；**火灾**（船舱火药库失火 = 真实威胁事件）
- **篝火**：登岛营地过夜（恢复疲劳但暴露风险）；**篝火夜话 = AI 船员交互场景**（讲故事/吐苦水/密谋/谈情——重交互新载体）
- **烹饪**：厨房舱 + 篝火烹饪；食材（捕捞/采集/采购）→ 餐食质量影响士气/健康
- **坏血病与饮食**：长期缺新鲜蔬果 → 坏血病风险；柑橘/野菜（登岛采集或港口采购）预防与治疗（1675 民间经验存在）
- **淡水**：淡水舱容量 / 登岛补水 / 干旱风险 💡
- **工具与装备（新增）**：指南针（领航精度）、望远镜（瞭望半径）、海图/六分仪（测纬度）、测深绳（防搁浅）、绳索/工具套装（采集修理效率）——挂接船员技能与 P2A 命令

## 15. 船只、海洋与水体表现

### 15.1 船只模型与系统目标

- 20 种船体，每种有独立船体模型、碰撞体、甲板布局、操控参数和存档 ID；
- 80 个改装模块，覆盖船体、帆、桅杆、炮位、货舱、医疗舱、厨房、住所、瞭望台和储水舱；
- 60 个船上功能点，覆盖舵轮、锚机、缆桩、炮位、瞭望台、泵、货梯、货舱、厨房、医务台和篝火；
- 30 个船上装饰和生活道具，影响可读性但不直接修改强逻辑数值；
- 每种船必须有小艇下水、登船、下船、靠泊、离泊、抛锚、收锚和损伤状态；
- 船员岗位必须能影响操帆、领航、炮术、修船、医疗和装卸效率。

### 15.2 水体类型

至少支持以下 8 类水体表现和规则：

1. 深海开阔水面；
2. 近岸浅海；
3. 珊瑚礁浅滩；
4. 红树林水道；
5. 泻湖和内湾；
6. 河口与淡水水面；
7. 港池和码头内水域；
8. 风暴和暴雨水面。

每类水体必须定义：颜色、透明度、波长、浪高、泡沫、海流、可航深度、碰撞层、船体速度修正、鱼群/动物分布和天气响应。

### 15.3 水体质量要求

- 开阔海面有远景层、近景波浪、船尾航迹、浪花和天气反射；
- 港池有低浪、码头倒影、靠泊泡沫和船体碰撞反馈；
- 浅滩有水深颜色变化、礁石可见度和搁浅预警；
- 红树林和泻湖有狭窄水道、植被倒影和船速限制；
- 暴雨有雨滴击水、波浪增强、能见度降低和船员疲劳影响；
- 风暴有浪峰、船体倾斜、货物滑动风险和抛锚风险；
- 水体必须支持没有 Crest 或高端插件时的低成本降级模式；

## 21. 性能、存档、网络和 QA 扩展要求

### 21.1 性能预算

- 单个加载区域同时活跃的高精度动物不超过 80 个；
- 单个加载区域同时活跃的可交互对象不超过 250 个；
- 远距离动物、植被和建筑必须使用低成本代理；
- 每座岛必须有加载预算、卸载预算和最小可玩入口；
- 50 座岛不能一次性全部加载到内存；
- AI 模拟采用玩家附近、当前船员和事件相关对象优先原则；
- 性能报告必须记录 CPU、GPU、内存、加载时间、GC、Draw Call 和帧率分位数。

### 21.2 存档要求

- 存档必须覆盖人物、船只、船员、特质、记忆、金钱、货物、道具、建筑、岛屿、动物收藏、任务、势力、事件、天气和航线日志；
- 50 座岛的发现、访问、资源刷新和建筑状态必须可恢复；
- 旧版本存档必须提供迁移策略，不能因为增加字段直接损坏；
- 存档失败必须保留上一次有效存档，并显示原因；
- 本地 SQLite 是单机权威，Steam Cloud 只同步已验证快照，不在云端直接裁决游戏数值。

### 21.3 QA 分层

- 纯逻辑单测：每个 Systems 的数值、边界和失败路径；
- 契约测试：JSON Schema、OpenAPI、保存字段和版本迁移；
- 运行时冒烟：每个主要入口创建成功、无空引用、无控制台错误；
- 场景测试：50 座岛、港口、船坞、码头、建筑和水体逐项抽查；
- 内容测试：200 道具、300 动物、1,000-2,000 植被条目 ID 无重复、来源齐全；
- 玩家流程测试：新游戏、完整航程、沉船、被捕、治疗、主线、支线、死亡和继续；
- 性能测试：低配、中配、高配、长时间航行和大港口密度；
- 本地化测试：中文/英文、数字、单位、按钮、长文本和字体缺失；
- 发布测试：打包、安装、卸载、首次启动、升级、云存档和崩溃恢复。

| 1672 | 英格兰皇家非洲公司取得特许，西非—加勒比的强制贸易网络进一步公司化 | 作为公司垄断、许可证、商船和奴役制度的历史背景 |
| 1673 | 法国塞内加尔公司成立，法国殖民贸易和强制迁徙网络继续扩大 | 作为法国公司、港口货源和势力竞争的历史背景 |
| 1674-1675 | 荷兰西印度公司推动库拉索成为自由港和区域转口贸易节点 | 作为走私、转口、汇兑、船员流动和多语社会的核心地点 |
| 1675 | 英、西、法、荷、丹麦和地方社群同时争夺航线、港口、木材、糖、烟草、染料、人口和信息 | 作为游戏正式开始状态，世界不是单一阵营控制的地图 |

历史资料显示，1675 年的加勒比不是简单的“海盗时代冒险地图”：殖民港、公司垄断、种植园、教会、军队、私掠者、走私商、原住民社群、非洲裔社群和逃亡社区同时存在。世界系统必须让这些群体互相影响，而不能只生成几个不同颜色的国家图标。

### 24.2 主要势力和社会网络

| 势力/网络 | 历史定位 | 游戏表现 | 设计边界 |
|---|---|---|---|
| 西班牙王室与殖民官僚 | 控制古巴、波多黎各、伊斯帕尼奥拉岛东部及西属美洲航线 | 舰队、海关、天主教教会、港口许可证、珍宝航线、巡逻和走私冲突 | 不能把所有西班牙 NPC 写成单一性格 |
| 英格兰殖民地与种植园利益集团 | 牙买加、巴巴多斯、背风群岛、开曼等英属网络 | 港口议会、种植园、私掠证、商人信用、皇家海军和地方民兵 | “英格兰”不等于每个英属居民都支持同一政策 |
| 法国殖民网络 | 马提尼克、瓜德罗普和伊斯帕尼奥拉岛西部等法国据点 | 公司贸易、糖业、天主教、法国私掠者、港口竞争和边境冲突 | 避免把后来成熟的圣多明各社会结构提前照搬到 1675 |
| 荷兰西印度公司与自由港 | 库拉索及荷兰加勒比贸易节点 | 转口、汇兑、仓储、黑市、语言混合、商人家族和多方船旗 | 荷兰港口既有商业开放，也深度卷入强制贸易，不能只表现成“自由贸易天堂” |
| 丹麦西印度据点 | 圣托马斯等较小的丹麦殖民和商业据点 | 小型港口、补给、转运、中立交易和势力摇摆 | 作为小势力，不与英法西荷平分地图资源 |
| 卡利纳戈（Kalinago）等原住民社群 | 在小安的列斯部分岛屿保持自治、迁徙、贸易和抵抗能力 | 部落政治、土地、独木舟、药材、渔猎、外交、伏击和文化保护 | 不使用殖民者的“野蛮人”标签；不把所有原住民合并成一个部落 |
| 非洲裔自由社群与逃亡社区 | 强制迁徙、自由人、逃亡者、山地和森林社区、港口工匠与水手 | 逃亡路线、情报、互助、救援、反抗、赎身、法律身份和社区建设 | 不把受压迫者只写成任务道具或敌人 |
| 私掠者与海盗网络 | 私掠证、战利品分成、港口保护和跨国流动并存 | 夺船、护航、赎金、分赃、销赃、招募、叛变和法律风险 | 海盗不是一个统一国家，也不是永远正义的自由象征 |
| 商人、船东和特许公司 | 连接欧洲、非洲、美洲港口和殖民地生产 | 保险、信用、合同、仓储、代理人、价格操纵和政治游说 | 商业利益可以影响政府，但不能替代政府和社群的所有行为 |

### 24.3 地名和历史原住民命名规则

- 真实地点可以作为历史参照，但核心玩家地图的 50 座岛以虚构名称为主；
- 真实势力、贸易公司、宗教机构和历史制度可以出现，但关键角色尽量使用虚构人物；
- “Carib”是历史殖民文献中的外部称呼，现代项目默认使用 Kalinago，并在资料中说明称呼差异；
- Taíno 不得简单写成“已经消失的民族”，应表现幸存者、后裔、混合社区、地名、工艺和记忆的延续；
- 不使用“非洲部落”作为单一 NPC 标签，角色需要有来源地区、语言、家庭记忆、职业和个人选择；
- 不把后世的民族国家、现代国界、现代金融机构和现代宗教名称直接套入 1675 年。

## 25. 宗教、信仰与意识形态系统

### 25.1 信仰群体

| 信仰/传统 | 主要载体 | 游戏系统 |
|---|---|---|
| 罗马天主教 | 西班牙、法国殖民地的教会、教士、教堂、圣像和节期 | 教会记录、婚姻、葬礼、慈善、教育、庇护、传教和社会声望 |
| 英格兰国教与其他新教群体 | 英属殖民地、港口和部分商人家庭 | 教会、议会、誓言、慈善、纪律和与天主教势力的政治摩擦 |
| 荷兰归正宗 | 荷兰行政、商人和驻军网络 | 港口管理、婚姻记录、教育、身份和公司关系 |
| 塞法迪犹太社群 | 荷兰港口、跨语言商人、家族网络和避难者 | 信用、翻译、航海知识、家族商贸、社区自治和宗教空间 |
| 非洲来源的宗教实践 | 家庭、船员、工匠、治疗者和逃亡社区 | 治疗、葬礼、音乐、记忆、互助和身份认同；不做“魔法技能树” |
| Kalinago 等原住民传统 | 社群、首领、土地、祖先、河流、动物和仪式空间 | 土地关系、季节、医疗、外交、禁忌和社区信任 |

### 25.2 宗教玩法

- 教堂、礼拜所、传教站、墓地、祭祀空间和社区祈祷场所；
- 礼拜日、节庆、婚礼、葬礼、洗礼、忏悔、慈善和救济；
- 宗教身份影响婚姻、信任、招聘、商品禁忌、政治效忠和社区声望；
- 教士、传教士、治疗者、长老、商人和船员对同一事件可以有不同解释；
- 宗教机构可以提供教育、记录、避难、医疗或政治压力；
- 西班牙港口需要体现天主教制度和殖民官僚，但不把所有角色都写成狂热者；
- 非洲和原住民信仰不得被设计成可随意夺取的“神秘增益”；
- 所有宗教内容都必须是写实世界观，不出现超自然确定事实；
- 术语、仪式和服饰必须经过历史资料复核，避免把 18、19 世纪内容倒灌到 1675 年。

### 25.3 信仰与角色特质

角色除原有 50 条身体/性格/经历/疾病特质外，增加以下独立字段：

- 信仰传统；
- 礼拜频率；
- 宗教权威信任度；
- 宗教宽容度；
- 禁忌物和仪式偏好；
- 家庭、祖先和社区责任；
- 对殖民统治、传教和异教群体的态度。

这些字段不是简单的“好人/坏人”数值，而是影响说话、交易、结盟、婚姻、救济、冲突和任务选择的原因链。

## 26. 英法西荷丹与地方社群的势力争夺系统

### 26.1 势力状态字段

每个势力必须拥有：

- 控制港口、要塞、航线和资源；
- 首府或区域指挥中心；
- 领袖、官僚、军官、商人和地方代理人；
- 军事力量、商船力量、私掠力量和情报网络；
- 合法贸易、禁运商品、税率、许可证和检查规则；
- 宗教传统、殖民治理方式和劳动制度；
- 对其他势力的敌对、竞争、合作、中立或依附关系；
- 当前战争、停战、封锁、护航、通缉和外交状态；
- 玩家行为影响、世界自运行速度和历史事件锚点。

### 26.2 势力冲突玩法

- 港口控制：更换旗帜、驻军、税率、法律、市场和通行证；
- 海上封锁：航线危险提高、商品短缺、黑市价格上升；
- 私掠证：允许攻击指定敌对船只，但必须承担误伤、没收和外交后果；
- 护航：保护商队、补给船、移民船、邮件船和军需船；
- 登船检查：检查货物、船员身份、许可证、宗教和通缉记录；
- 间谍和情报：购买航线、巡逻时间、要塞弱点和港口库存信息；
- 代理战争：地方商人、村落、海盗、原住民和逃亡社区可被不同势力拉拢；
- 谈判：交换俘虏、释放港口、降低关税、换取通行和撤销悬赏；
- 反悔和背叛：势力的政治承诺不是永远有效，玩家需查看信誉和利益；
- 世界推进：玩家不在场时，战争、价格、巡逻和港口繁荣度继续变化。

### 26.3 玩家路线

- 商人：信用、合同、保护、价格和港口关系；
- 私掠者：许可证、敌国目标、战利品、俘虏和法律风险；
- 海盗：销赃、赎金、招募、分赃和港口庇护；
- 探险家：地图、动植物、遗迹、收藏和学术赞助；
- 救援/反抗路线：帮助逃亡者、揭露强迫劳动、营救被扣押者、破坏运输网络；
- 殖民经营者：后置系统，涉及土地、人口、生产、防御和政治责任，不在 D7 范围内。

## 27. 1675 年商业、贸易与金融系统

### 27.1 商品链

商品不能只在港口面板里改变数字，必须有生产、运输、仓储、损耗和消费链：

- 糖：种植园、压榨、煮炼、桶装、仓储、出口和价格；
- 烟草：种植、晾晒、打包、走私和港口税；
- 靛蓝/染料：植物采集、染坊、订单和质量差异；
- 可可：雨林采集、村落贸易、运输损耗和欧洲需求；
- 木材：砍伐、锯木、修船、建筑和森林恢复；
- 盐：盐田、腌制、渔业、肉类保存和远航补给；
- 鱼类和海产：捕捞、晒制、冷藏缺失造成的腐败和港口需求；
- 朗姆酒/糖蜜：糖业副产品、酒馆消费、海员工资和走私；
- 粮食与淡水：本地生产、进口依赖、旱季、风暴和封锁；
- 药材和医疗品：岛屿生态、医生需求、疾病爆发和高价短缺；
- 武器和火药：军需、海盗、港口禁运、储存风险和爆炸事件；
- 人工服务：船工、领航、医生、翻译、搬运、护航和情报，不能被简化成单一商品。

### 27.2 金融工具

1675 年不存在现代银行 App，金融系统使用现金、实物、信用和关系：

- 西班牙银元/八里亚尔等硬币作为跨港结算参照；
- 地方货币、代币、商品抵押和物物交换；
- 商人赊账、船东贷款、船员预支工资和种植园欠款；
- 汇票、代理人结算、仓单、货物抵押和家族信用；
- 海上保险、共同海损、船损理赔和战争附加费；
- 债务、利息、延期、违约、破产和资产查封；
- 港口税、关税、许可证费、护航费、贿赂和罚款；
- 船舶投资、合伙份额、战利品分成和任务预付款；
- 黑市汇兑、假币、盗币、兑换差价和跨语言合同。

### 27.3 金融与玩家行为

- 玩家可以现金贸易，也可以凭声望获得信用额度；
- 高信用能买更好的船和货物，但违约会导致港口拒绝服务；
- 保险不是无条件赔付，天气、战争、走私和船员过失会影响理赔；
- 商人会根据玩家历史、势力关系、货物来源和船员身份改变报价；
- 经济系统必须记录钱从哪里来、流向哪里、为什么变化；
- AI 只能提出谈判语气和合同文本，价格、利息、风险和结算由强逻辑系统裁决。

## 28. 奴役、强迫劳动、抵抗与自由身份系统

> 1675 年的加勒比经济与社会无法脱离奴役和跨大西洋强迫迁徙来理解。游戏可以表现这一历史现实，但不能把人当作货物或用“经营奴隶贸易”作为轻松的赚钱玩法。

### 28.1 身份分类

- 被奴役者：受法律和暴力控制的人，不能在货舱中作为物品出售；
- 自由人：拥有不同程度的财产、职业、迁徙和法律权利；
- 契约劳工：有期限和合同的劳动关系，与终身奴役分开建模；
- 逃亡者/马龙社区成员：逃离强迫劳动后建立的社群；
- 战俘/拘押者：战争和海上冲突产生的身份，不等同于被奴役者；
- 船员、工匠、医生、翻译、商人和水手：根据个人经历与法律身份分别生成；
- 身份可以通过逃亡、赎身、释放、婚姻、判决、转移和社区保护发生变化。

### 28.2 可玩内容

- 发现运输记录、种植园账本、港口检查文件和家族信件；
- 营救被扣押者、帮助逃亡、建立安全路线和联系山地/森林社区；
- 破坏强迫运输网络、偷走登记册、释放船上被押人员；
- 与逃亡社区、原住民社群、教会、商人和地方官员谈判；
- 处理家庭分离、身份文件、赎身、释放承诺和法律风险；
- 让受压迫角色拥有姓名、关系、目标、技能、记忆和主动选择；
- 玩家若帮助压迫性势力，将获得短期利益，但会受到船员士气、社区关系、势力声望和事件链的长期反噬；
- 不允许把“人口数量、身体状态或生命”直接显示成与木材、糖一样的货物单位。

### 28.3 内容安全规则

- 不提供以奴役为核心的利润优化表；
- 不用性暴力、肢解或虐待镜头作为卖点；
- 重大事件提供内容提示、跳过和降低表现强度选项；
- 任务文案避免使用殖民者的贬义称呼作为默认叙事声音；
- 历史事实、角色立场和项目虚构必须在资料页中区分；
- 相关章节必须经过历史顾问或敏感内容审阅；
- 游戏不得暗示奴役是合理、自然或“提高生产力的工具”。

## 29. NPC 行为与社会模拟

### 29.1 NPC 身份字段

每个重要 NPC 至少有：

- 名称、语言、年龄段、性别表达、文化、宗教和法律身份；
- 职业、技能、收入来源、债务、家庭、朋友、敌人和所属群体；
- 居住地、工作地、常去建筑和每日路线；
- 对势力、宗教、殖民、海盗、贸易和玩家的态度；
- 当前目标、短期需求、长期愿望、恐惧、禁忌和秘密；
- 记忆事件、谣言来源、证据可信度和关系变化；
- 受伤、疾病、疲劳、饥饿、贫困、通缉和迁徙状态。

### 29.2 NPC 行为层

1. 生存层：吃饭、饮水、休息、避雨、治疗、逃离危险；
2. 工作层：生产、装卸、修船、售卖、巡逻、传教、看守和运输；
3. 家庭层：照顾家人、婚姻、葬礼、债务和家庭冲突；
4. 社群层：教会、行会、村落、船员、商人家族、军队和逃亡社区；
5. 势力层：服从命令、通报情报、执行检查、征税、招募和战斗；
6. 个人层：复仇、爱情、信仰、发财、逃亡、学习、成名和自由；
7. 记忆层：玩家行为改变信任、恐惧、感激、警惕和传播范围；
8. AI 层：只对重要角色启用 LLM 表达，普通 NPC 使用行为模板和有限状态机。

### 29.3 NPC 日程和动态

- 每个城镇至少拥有清晨、工作、午间、黄昏、夜间和紧急状态六类日程段；
- 雨、风暴、战争、宗教节日、疾病和缺粮会改变日程；
- 港口封锁时，商人囤货、船员失业、黑市扩大、巡逻增加；
- 船坞缺木材时，修船延迟、价格上涨、盗窃和走私增加；
- 酒馆是谣言、招募、债务、冲突和关系事件的聚合点；
- 教堂/礼拜所是记录、慈善、婚礼、葬礼、教育和庇护的聚合点；
- 普通 NPC 使用近景、邻近、远景三档模拟，避免 50 座岛同时运行完整 AI。

## 30. 天气、植被和动物的动态生态逻辑

### 30.1 天气状态机

- 晴朗、多云、降雨、大风、浓雾、雷暴、热带风暴、飓风、黄昏、夜间、旱季和湿季；
- 风向、风速、浪高、降水、能见度、湿度、温度和雷电风险分开计算；
- 天气由海域、季节、时间、风场和事件影响，不由随机数单独决定；
- 天气影响航速、操舵、疲劳、疾病、火灾、船体进水、货物损耗、动物出现和市场供应；
- 远处天气必须先被玩家从云层、风向、海色、鸟群和 NPC 传闻中预告；
- 天气变化要有过渡阶段，不能突然从晴天跳到飓风；
- 天气记录进入航线日志和存档，重大天气生成可追溯事件原因。

### 30.2 植被动态

- 植被有种子/幼苗、成长、成熟、采集后、枯萎、风暴损伤和恢复状态；
- 雨季提高药草、果实和淡水相关资源，旱季增加缺水和火灾风险；
- 玩家过度采集会造成局部资源下降，村落和动物会改变路线；
- 火灾、砍伐、风暴、盐碱、水位和建筑扩张会改变生境；
- 植被变化至少在小区域内可见，并由系统保存关键状态；
- 远距离区域只保存数值状态，靠近时再生成细节，保证性能。

### 30.3 动物生态逻辑

- 动物由栖息地、食物、水源、昼夜、天气、玩家噪声、血腥味和捕猎压力驱动；
- 动物行为包括觅食、饮水、休息、迁徙、警戒、逃跑、攻击、群聚、繁殖提示和受伤；
- 海豚可伴航，鲸群有迁徙路线，鲨鱼对血腥味敏感，海龟在特定海滩活动；
- 蚊虫增加疾病风险，毒蛇和鳄鱼改变登岛准备，美洲豹等大型动物改变团队配置；
- 低等级动物使用规则模板，高等级动物可产生任务、传闻、收藏和生态后果；
- 动物死亡、捕猎、受伤、迁徙和收藏必须写入事件或生态快照；
- 动物不能因为 LLM 随口描述就改变物种、数量、危险等级或生态规则。

### 31.1 特质结构

原有 50 条特质继续保留，增加以下组合层：

### 31.2 特质交互规则

- AI 只能根据角色配置生成台词和建议，不能越过规则修改关系结果。

## 34. 环境系统总纲：从地质到生态

环境不再只作为“地图背景”和资源刷新点，而是由一条完整链路共同生成：

> 地质 → 地形 → 水文 → 生境 → 植被 → 动物 → 人类聚落 → 航海、采集、贸易与生存玩法

### 34.1 环境资产的数量口径

本章所有数量都是制作目录目标，不是现实世界的物种数量，也不是要求一次性全部建模。目录中的“条目”必须能在游戏里被识别、放置、查询或产生玩法影响。

| 名称 | 白话解释 | 是否单独计数 |
|---|---|---|
| 基础模型 | 一棵基础树、一个基础鱼类模型、一种岩壁材质 | 是 |
| 变体 | 同一模型的年龄、颜色、损伤、季节或尺寸变化 | 是 |
| 内容条目 | 玩家能识别或交互的具体对象，例如“东岛红树林幼苗” | 是 |
| 生境节点 | 一段红树林、一块海草床、一个浅滩或一处洞穴入口 | 是 |
| 放置实例 | 某个岛上实际摆放的一棵树、一只鸟或一片珊瑚 | 不纳入模型数量，但纳入性能和验收 |
| 交互点 | 采集点、饮水点、动物巢穴、锚泊点、洞穴入口等 | 是 |

环境内容必须使用唯一 ID，并记录所属岛屿、生境、季节、天气反应、资源用途、危险等级和资产来源。随机生成只能选择经过审核的内容，不得生成与岛屿气候、海水盐度或历史年代冲突的对象。

### 34.2 每座岛的“自然档案卡”

50 座岛屿每座都必须有一张自然档案卡，至少包括：

- 岛屿主地质：火山、石灰岩、珊瑚沙洲或混合地质；
- 迎风面与背风面、主风向、年内干湿变化；
- 海岸类型、潮汐区、海流、浅滩和危险航道；
- 山脊、峡谷、河流、泉眼、瀑布、湿地和地下水；
- 主要植被层、代表动物、季节性迁徙和繁殖活动；
- 淡水容量、可采集资源、疾病与自然灾害风险；
- 人类改造程度：原始、部落管理、种植园、港口工业或战争破坏；
- 与附近岛屿的生态连通关系：鱼群、鸟类、海龟、种子和漂流物的移动方向。

### 35.2 岛屿空间分层

每座中大型岛至少拆成 8—12 个自然区域；小型礁岛至少拆成 3—5 个自然区域。自然区域不是单纯换一张贴图，而是要有不同的：

- 行走难度、可见距离、声音传播和遮挡关系；
- 土壤、岩石、植被密度、淡水来源和资源类型；
- 动物活动时间、巢穴位置、觅食路线和逃跑路线；

- 人类足迹、废弃设施、道路、砍伐痕迹和污染程度。

1. 海岸层：登陆、滩涂、码头、浅海、红树林或礁区；
2. 内陆层：村落、农地、林地、河谷、道路和资源点；
3. 高地或地下层：山脊、洞穴、峡谷、泉眼、瞭望点或遗迹。

低矮沙洲可以没有高地层，但必须用泻湖、礁口、沙脊和潮间带形成垂直变化。

## 36. 地质、山地、悬崖、河流与淡水

### 36.1 四类基础地质

1. 火山岩：玄武岩、火山灰、黑色碎石、陡峭山坡和熔岩通道；适合形成高岛、瀑布和天然深水湾。
2. 石灰岩：溶蚀形成峰林、落水洞、地下河、溶洞和地下泉；地表可能看似干燥但地下水丰富。
3. 珊瑚与贝壳沉积：质地疏松、地势低平、海水入侵风险高；适合沙洲、环礁和浅海。
4. 河口与冲积沉积：泥沙丰富、地形变化快；适合湿地、红树林、河口渔场和易淹聚落。

地质必须影响玩法：岩石决定道路坡度、洞穴类型、采石资源、建筑地基、滑坡风险和可建港位置；不是只影响颜色。

### 36.2 山地类型

| 山地类型 | 视觉特征 | 玩法和环境影响 |
|---|---|---|
| 火山锥与火山脊 | 黑色岩壁、碎石坡、雾带、旧火山口 | 远眺导航、硫磺或矿物采集、落石与滑坡 |
| 石灰岩峰林 | 孤立尖峰、灰白岩壁、林间落水洞 | 迷路、洞穴入口、攀爬绕行、地下水出口 |
| 湿润云雾山 | 云层低、树冠高、溪流密集 | 能见度低、湿滑、稀有药材和鸟类 |
| 背风干燥山脊 | 裸岩、灌木、仙人掌和强风 | 缺水、远距离侦察、野火和热暴露 |

山地至少有海岸、山麓、中山和高地四种高度带；低岛可将其折算为潮间带、沙脊、灌丛和灯塔高点。不同高度带要改变温度、风速、云雾、植物高度、动物分布和可见距离。

### 36.3 河流与地下水

河流不是静态蓝色贴图，至少要有：

- 上游、中游、入海口或季节性终点；
- 水流方向、流速、深浅、可涉水点和冲刷岸线；
- 雨季涨水、旱季断流、洪水后泥沙和漂浮物；
- 饮水、洗涤、灌溉、捕鱼、取水冲突与疾病风险；
- 河口盐度变化，以及淡水与海水交汇处的鱼群和鸟类。

淡水点必须有容量和恢复速度。玩家可以过度取水或污染水源，但第一版不做永久毁灭；系统以季节、降雨和附近植被覆盖率决定恢复速度。

### 36.4 悬崖与坡地

悬崖分为海蚀悬崖、火山岩壁、石灰岩断崖和河谷崖。每类悬崖都应有：

- 可观察但不可直接通行的边界；
- 绕行路线、绳索路线或低潮露出的替代路线；
- 落石、滑坡、强风、海浪拍击和视野风险；
- 鸟巢、海蚀洞、隐藏水道或瞭望点等生态与探索内容。

角色不能无条件爬上所有表面；需要按坡度、材质、体力、天气和装备判定，避免“碰到墙就能攀爬”的假现实主义。

## 37. 洞穴、地下河、落水洞与蓝洞

### 37.1 洞穴类型配额

60 个洞穴地点建议分为：

- 石灰岩干洞 32 个：钟乳石、落水洞、蝙蝠、鸟粪、地下水和狭窄通道；
- 海蚀洞 12 个：潮汐、浪涌、暗礁入口、海盗藏匿和涨潮困人；
- 火山熔岩管 8 个：玄武岩管道、塌陷口、黑暗、热气或硫磺痕迹；
- 落水洞与蓝洞 8 个：垂直入口、地下水、深水、绳索和有限照明。

其中 18 个大型洞穴网络可以连接多个入口、地下水层、峡谷或海岸，但不要求每个洞穴都做成迷宫。

### 37.2 洞穴内部结构

每个洞穴至少从以下模块中选取 4 个：

1. 入口缓冲区：日光、风、植被和动物痕迹；
2. 暮光区：可见度下降、蝙蝠和潮湿岩壁；
3. 黑暗区：需要火把或灯具，声音反射明显；
4. 水层：地下河、水潭、滴水、涉水或小船无法进入的狭窄水道；
5. 生物区：蝙蝠、洞穴昆虫、蟹类、真菌和鸟粪；
6. 地质区：钟乳石、塌方、断层、火山岩管或化石层；
7. 历史痕迹区：临时避难、失踪船员遗留、祭祀痕迹或旧货物；
8. 出口区：另一处山谷、海岸、泉眼或隐蔽登陆点。

历史痕迹不能自动写成“神秘超自然遗迹”。应先判断它是自然现象、原住民文化地点、殖民时期设施、船难遗物还是后续虚构内容。

### 37.3 洞穴危险与交互

- 潮汐洞：进洞时间错误会被浪涌阻断出口；
- 落石洞：暴雨、炮击或玩家制造的震动提高塌方概率；
- 缺氧或烟雾洞：火把变暗、角色咳嗽、能见度下降，但不做无提示秒杀；
- 蝙蝠洞：噪音会惊扰群体，影响角色状态并产生可追踪的声音；
- 湿滑洞：奔跑、负重和雨水会增加摔倒概率；
- 地下水洞：淡水可补给，但受到污染或盐水入侵时不可直接饮用。

洞穴探索必须提供地图标记、绳索或照明消耗、回头路线和失败恢复点。第一版不要求自由潜水穿越复杂水下洞穴；水下洞穴探索列为 M6 后置能力。

## 38. 海岸、浅海、红树林、海草床与暗礁

### 38.1 十二类海岸生境

1. 迎风沙滩；
2. 背风白沙湾；
3. 黑色火山砾滩；
4. 石灰岩海岸；
5. 海蚀悬崖；
6. 潮间带岩池；
7. 泥滩与盐沼；
8. 河口三角洲；
9. 红树林潮汐水道；
10. 海草床浅海；
11. 珊瑚礁与珊瑚碎石滩；
12. 泻湖、礁口与外海深水通道。

每一类海岸都必须在登陆、行走、采集、航行、声音、动物和天气上有差异。玩家靠近海岸时，至少能通过浪线、颜色、礁石、泡沫、鸟群、潮痕或水深变化判断环境，而不是完全依赖 UI。

### 38.2 红树林

红树林是海岸防护、幼鱼育幼、鸟类栖息和隐蔽航道的连接节点。它必须具备：

- 根系形成的狭窄通道、泥滩和浅水；
- 潮汐改变可通行水道、搁浅风险和登陆点；
- 蚊虫、螃蟹、鱼苗、涉禽和蛇类等生物活动；
- 泥沙截留、风暴削弱、岸线稳定和水质变化；
- 砍伐、污染和风暴损伤后的局部恢复；
- 船只进入时的速度、吃水、桅杆和转向限制。

红树林不应被设计成“一键砍树的木材矿场”。木材、树皮、鱼、蜂蜜和药材可以采集，但必须受到刷新、天气、潮汐和社区关系限制。

### 38.3 海草床与浅海

海草床是幼鱼、海龟、贝类和小型无脊椎动物的育幼区，也是浅吃水船只的安全但脆弱航道。玩法包括：

- 浅水航行和搁浅判断；
- 手线、网、笼、采贝和岸边捕鱼；
- 海龟活动、鱼群移动和水下可见度；
- 锚链、拖网、风暴和泥沙造成的局部损伤；
- 水草床恢复与附近红树林、珊瑚礁之间的生态连通。

第一版以水面观察、涉水、岸边采集和小船作业为主；完整水下采集、潜水装备和水下战斗不属于 D7 或 M4 的首要闭环。

### 38.4 暗礁、浅滩与礁口

120 处以上暗礁、浅滩和危险礁脊必须按航海风险分级：

| 等级 | 玩家表现 | 设计要求 |
|---|---|---|
| 低风险 | 水色变浅、浪线明显 | 小船可低速通过，大船需要减速 |
| 中风险 | 礁块、白浪、局部急流 | 需要观察海图、瞭望或测深 |
| 高风险 | 暗礁、窄礁口、回流和浪涌 | 锚泊、转向和天气判断都可能失败 |
| 极高风险 | 风暴中的礁环、无灯标通道 | 作为特殊航线或任务地点，提供预警和替代方案 |

暗礁不是随机伤船按钮。碰撞风险必须由吃水、速度、航向、能见度、潮位、船员瞭望和玩家是否看图共同决定。碰撞后要区分擦伤、进水、舵损、桅杆损坏和搁浅，而不是只有“船沉了”。

### 38.5 泻湖与夜间发光水域

生物发光水域可作为 8—12 个稀有自然地点，表现为划桨、鱼群或浪花短暂发光。它们需要受夜间、天气、盐度、泥沙和月光影响，不能被解释成无限能源或魔法水体。

## 39. 水域分层与水生生物

### 39.1 水域分层

水生生态至少拆成以下六层：

1. 潮间带：螃蟹、贝类、海藻、鸟类和潮痕；
2. 红树林浅水：鱼苗、虾、幼蟹、蛇和涉禽；
3. 海草床：海龟、草食鱼、贝类和小型捕食者；
4. 珊瑚礁与礁口：礁鱼、鳐、鲨、章鱼和丰富的无脊椎动物；
5. 大陆架与外海：鱼群、飞鱼、鲸豚、海鸟和长距离航行资源；
6. 深水与海底：低能见度、深水鱼、沉船、强流和大型海洋动物。

游戏第一版的深水层以航行、观测、捕鱼和事件为主，不要求玩家徒步进入真正的深海。

### 39.2 300 个动物条目的生态分配建议

这 300 个条目是生产目录，不代表只做 300 个个体。单个物种可有幼体、成体、雌雄、颜色、损伤和地域变体。

| 类别 | 条目数 | 主要用途 |
|---|---:|---|
| 陆生哺乳动物 | 35 | 觅食、负重、狩猎、疾病、驯养或聚落冲突 |
| 陆生鸟类 | 55 | 鸣叫、迁徙、报天气、巢穴和海岸识别 |
| 陆生爬行与两栖动物 | 25 | 湿地、洞穴、干旱区、毒性与夜间活动 |
| 昆虫与蛛形动物 | 45 | 授粉、腐败、疾病、蜂蜜、害虫和食物链 |
| 淡水与河口动物 | 20 | 溪流、泉眼、河口、湿地和饮水点 |
| 近岸与礁区鱼类 | 60 | 鱼群、捕鱼、礁区生态、海况提示 |
| 鲨鱼与鳐类 | 12 | 外海风险、鱼群追逐和稀有观察 |
| 海龟与其他海洋爬行动物 | 10 | 产卵、迁徙、海草床和季节事件 |
| 鲸豚、海牛等大型海洋动物 | 8 | 远洋观测、航线事件、声音和生态标志 |
| 甲壳类、贝类与棘皮动物 | 25 | 滩涂采集、笼捕、礁区和食物链 |
| 海鸟与沿岸鸟类 | 5 | 航海导航、鱼群提示、岛屿繁殖地 |
| **合计** | **300** | 珊瑚、海绵、藻类与浮游生物另作生态节点 |

珊瑚、海绵、海藻、海草、浮游生物和真菌不强行塞进 300 个动物条目，而作为生境基础对象单独计入环境目录。

### 39.3 水生生物的行为

- 鱼群根据潮汐、温度、食物、捕食者、噪音和天气移动；
- 礁鱼拥有小范围领地，受到过度捕捞后密度下降；
- 鲨鱼和鳐类不主动追杀所有玩家，而是受血迹、鱼群、船速和水域类型影响；
- 海龟在特定季节返回沙滩产卵，灯光、噪音和人类活动会改变上岸概率；
- 鲸豚通过远距离声音和跃出水面产生可见、可听的航海提示；
- 螃蟹、贝类、海胆和潮间带动物随潮位出现或隐藏；
- 水母、浮游生物和藻类随水温、风和洋流形成局部聚集；
- 台风或强风暴后，鱼群、漂流木、死鱼、珊瑚碎片和沉船残骸会重新分布。

## 40. 植被生境、植物层级与动态变化

### 40.1 十类主要植被生境

| 生境 | 植被层 | 代表玩法 |
|---|---|---|
| 海滩与沙丘 | 海滨草本、低矮灌木、耐盐植物 | 采集、海龟产卵、风暴侵蚀 |
| 红树林与盐沼 | 根系、灌木、潮湿底层 | 潮汐航道、鱼苗、木材与药材 |
| 干旱灌丛与仙人掌地 | 荆棘、肉质植物、稀疏乔木 | 缺水、生火、毒性和远眺 |
| 低地季雨林 | 中低层乔木、藤本、灌木 | 木材、果实、遮蔽和雨季泥泞 |
| 湿润热带雨林 | 高冠层、乔木、藤本、蕨类、附生植物 | 迷路、药材、昆虫、捕猎与疾病 |
| 云雾森林 | 苔藓、蕨类、矮化树、附生植物 | 低能见度、稀有植物和湿滑山路 |
| 河岸与湿地 | 芦苇、棕榈、湿地草本和水生植物 | 饮水、捕鱼、蚊虫和洪水 |
| 石灰岩林与喀斯特灌丛 | 浅土、耐旱树、岩缝植物 | 洞穴、缺水、攀爬和鸟巢 |
| 火山岩坡与次生林 | 岩缝草木、先锋植物和黑色灌木 | 滑坡、矿物、旧火山口和恢复演替 |
| 农地、种植园与废弃地 | 甘蔗、烟草、棉、香料、果树和杂草 | 劳动、贸易、疾病、土地冲突与生态退化 |

### 40.2 植物的六层结构

每个自然区按层级布置，而不是把植物随机撒满地面：

1. 冠层：决定远景轮廓、遮阴、鸟巢和雨水截留；
2. 中层乔木：提供木材、果实、藤本支撑和动物路线；
3. 灌木层：形成视线阻挡、药材、毒性和小型动物栖息地；
4. 地被层：影响脚步声、泥水、采集点和昆虫密度；
5. 藤本与附生层：增强雨林垂直度，也可能遮挡道路和洞口；
6. 潮湿或水生层：芦苇、浮萍、海草、藻类、红树林幼苗和湿地植物。

### 40.3 1,000—2,000 个植被内容条目的分类

植被总目标保持为 1,000—2,000 个内容条目，其中建议包含：

- 150—200 个基础植物模型；
- 250—400 个树木、棕榈、灌木和藤本变体；
- 180—300 个草本、蕨类、苔藓、附生植物和地被条目；
- 120—200 个海滨、盐沼、红树林和湿地条目；
- 100—160 个农作物、果树、香料和废弃地植物；
- 80—140 个药用、染色、纤维、有毒或特殊用途植物；
- 其余作为枯木、落叶、树桩、漂流木、种子、花果、病害和采集阶段变体。

每个可交互植物至少拥有以下标签：

- 食用、药用、木材、纤维、染料、香料、毒性、燃料、建筑或仪式用途；
- 生境、土壤、耐盐、耐旱、需水、海拔、季节和天气反应；
- 可采集部位、刷新时间、成熟阶段、过度采集后的恢复方式；
- 是否属于本地植物、人工引入植物、种植园作物或废弃地逃逸植物。

### 40.4 植被动态

- 风力决定树冠摇摆、棕榈叶、藤蔓和草丛的摆动幅度；
- 降雨决定叶面水珠、泥泞、溪流流量、蘑菇或湿地动物出现率；
- 干旱决定枯黄、落叶、火险、果实减少和动物迁移；
- 风暴决定倒树、断枝、落果、漂流木、海岸侵蚀和红树林损伤；
- 玩家砍伐会留下树桩、空地、脚印和新的次生植被，而不是瞬间恢复；
- 农地废弃后按草本、灌木、次生林的顺序逐步恢复；
- 火灾只在干旱、风向、可燃物和人为火源同时满足时扩散；
- 关键任务植被可以锁定剧情状态，但普通植被必须遵守生态规则。

## 41. 动物行为逻辑与生态关系

### 41.1 行为层级

| 层级 | 内容 | 适用对象 |
|---|---|---|
| L0 环境表现 | 待机、鸣叫、游动、飞行、摆动和简单逃跑 | 大量远景个体 |
| L1 个体反应 | 视觉、声音、距离、伤害、食物和天气反应 | 近景普通动物 |
| L2 群体行为 | 鱼群、鸟群、兽群、领地和首领方向 | 成群鱼鸟、群居动物 |
| L3 生境行为 | 觅食路线、饮水路线、巢穴、潮汐和昼夜活动 | 代表性动物群 |
| L4 特色行为 | 迁徙、产卵、猎食链、与 NPC 或任务联动 | 关键物种和重点地点 |

### 41.2 动物状态

每个需要真实交互的物种至少支持：休息、觅食、饮水、移动、警戒、逃跑、攻击或防御、受伤、寻找栖息地、受天气影响和死亡后的生态反馈。繁殖和种群重建第一版可以用季节事件或抽象数值完成，不要求每只动物真实配对。

动物决策必须由规则系统裁决，Agent 只能提出观察、对话或任务建议，不能直接修改动物位置、数量或生态数值。

### 41.3 食物链与玩家影响

- 植物减少会降低草食动物的觅食成功率；
- 草食动物减少会影响大型捕食者和猎人遇见率；
- 过度捕捞会让近岸鱼群变少，并把鱼群推向礁口或外海；
- 清除红树林会减少幼鱼、螃蟹和涉禽，并提高岸线风暴损伤；
- 污染或沉积增加会降低海草床、珊瑚和淡水点质量；
- 暴雨、飓风和旱季会改变短期数量，但不能让世界永久失去全部物种；
- NPC 的捕捞、伐木、放牧和种植行为要受社区规范、价格和资源状态影响。

## 42. 天气、水文与环境动态

环境天气系统必须与已有 12 种天气状态连接，而不是只有天空盒变化。每种天气至少要定义：

- 风向、风速、阵风、降雨量、云量、能见度和雷电；
- 海浪、涌浪、潮位、流速、河流水量和海岸泡沫；
- 角色体力、体温、湿润、疾病、火把、衣物和航行控制影响；
- 植被摆动、树叶落下、泥水、积水、滑坡、动物躲藏和鱼群移动；
- 码头、锚泊、帆具、舵、船体进水和靠岸操作风险。

环境事件建议分为四级：

1. 日常变化：昼夜、潮汐、云量、微雨、风向和动物活动；
2. 季节变化：旱季、雨季、海龟产卵、鱼群迁徙和作物成熟；
3. 区域事件：暴雨、洪水、干旱、野火、虫害、藻类聚集和局部风暴；
4. 大型灾害：飓风、风暴潮、海岸侵蚀、山体滑坡和船难。

第一版的大型灾害必须可预警、可绕行、可避难和可恢复。玩家不能因为一次没有提示的随机事件永久失去主线内容或整条存档。

## 43. 画质、材质、光照、声音与环境表现

### 43.1 画质目标

- 地形使用分层材质：沙、湿沙、泥、火山岩、石灰岩、珊瑚碎石、苔藓岩和农地；
- 海水至少区分外海、浅海、红树林水道、河口淡咸水和洞穴水面；
- 水面表现风向、波长、浪高、泡沫、反射、浑浊度和船体扰动；
- 森林使用远景轮廓、中景群落、近景单株和交互植被四级层次；
- 山体使用岩层、断层、冲刷、落石、植被覆盖和雾线表达高度；
- 洞穴使用入口强光、暮光、火把照明、湿壁反射、滴水和声音反射；
- 雨、雾、雷电、沙尘、火焰、飞虫、花粉和海雾都要受环境区域限制；
- 夜间不能只降低亮度，要同时改变颜色、可见距离、声音权重和动物活动。

### 43.2 光照与天气反应

同一地点在晴天、雨天、雾天、黄昏和暴风前必须有明显差异，但不能通过完全替换场景解决。光照系统需要保留：

- 太阳高度、云层遮蔽、湿地反光、海面高光和树冠阴影；
- 暴雨前的低色温、远处闪电、海面变暗和风向变化；
- 港口灯火对雾、雨和水面的影响；
- 洞穴火把对岩壁、人物、烟雾和水滴的影响。

### 43.3 环境声音

每种生境至少有底噪、近景声、远景声和事件声四层：

- 海滩：浪、碎石、海鸟、风、木板和潮水；
- 雨林：树叶、昆虫、鸟叫、滴水、远处猴类或蛙类；
- 红树林：泥水、根系摩擦、蚊虫、鱼跃和划船；
- 山地：风、落石、瀑布、回声和远处雷声；
- 洞穴：滴水、脚步回声、蝙蝠、潮汐浪涌和火把燃烧；
- 暗礁：破浪、船底擦碰、索具、瞭望员警告和水流。

声音可以帮助玩家判断方向、天气和危险，但关键机制仍需提供视觉或文字辅助，避免听觉障碍玩家无法游玩。

## 44. 环境交互与玩法清单

环境系统至少支持以下玩法闭环：

1. 观察海色、浪线、鸟群和礁石，判断水深与航线；
2. 使用海图、测深、瞭望和船员报告更新暗礁危险；
3. 选择沙滩、河口、码头或红树林水道登陆；
4. 按潮位安排穿越红树林、海蚀洞和浅滩的时间；
5. 采集植物、木材、果实、药材、贝类、蟹类和淡水；
6. 追踪脚印、折枝、叫声、羽毛、巢穴、粪便和水面扰动；
7. 在暴雨前寻找洞穴、村落、船坞或高地避难；
8. 处理泥泞、滑坡、落石、蚊虫、毒物、热暴露和湿冷；
9. 用船、绳索、火把、笼、手线、网、砍刀和测深工具解决环境问题；
10. 保护、破坏或交易红树林、渔场、泉眼、农地和猎场；
11. 根据生态状态改变 NPC 的物价、工作、冲突、迁移和任务；
12. 在沉船、海蚀洞、礁口、洞穴和山脊之间形成多路线探索。

环境玩法必须满足“看得懂、试得出、失败可恢复”。玩家应能通过观察和准备降低风险，而不是依靠隐藏骰子。

## 46. 环境验收标准

环境专项完成的最低条件：

- 50 座岛都有自然档案卡，且主地貌、气候、淡水、海岸和物种分布互相一致；
- 8 类主地貌至少各有一个可游玩样板，样板之间能通过视觉和玩法区分；
- 60 个洞穴地点、120 个暗礁或浅滩节点、80 个淡水点可以被地图或航海系统识别；
- 植被达到 1,000—2,000 个条目目录，动物达到 300 个条目目录，且每个条目有生境和行为标签；
- 至少一条从雨水、河流、河口、红树林、海草床、礁区到外海的生态链可以被实际观察；
- 至少完成晴天、雨天、雾天、夜间和风暴前后的环境回归；
- 暗礁、潮汐、洞穴、滑坡和洪水都能预警，失败后有替代路线或恢复点；
- 近景动物不会穿地、穿船、在错误生境刷新或无限复制；
- 植物采集、动物数量、鱼群和水源的数值写入所属系统，Agent 只提议，不直接裁决；
- 1080p 目标设备下，岛屿加载、植被 LOD、动物群体和水体特效不会破坏已有航行与保存闭环；
- 每个环境任务都有截图、运行记录、测试结果、文档更新和当日日志；
- 历史文化地点、原住民传统、强制劳动和自然资源利用经过独立审查，不把真实社群当作装饰素材。

### 46.1 第一版与后置范围

第一版必须完成：地表生境、海岸与浅海、基础红树林、海草床、暗礁航行、洞穴探索、潮汐、天气反应、基础动物群和植被动态。

完整水下潜水、复杂水下洞穴、动物繁育、基因或血统系统、可破坏整座森林、全球海洋迁徙和多人共享生态列入 M6 后置，不得在 D7 阶段插入主线。
