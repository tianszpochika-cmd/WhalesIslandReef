## 4. 用户手动验收路径

1. 新游戏进入 InitialHarbor，确认看到人物而不是 Capsule/柱体；
2. WASD 移动，Shift 奔跑，Space 跳跃，确认动作和脚底落地；
3. 靠近舵位/船体按 E，上船后按 W 航行，确认人物随船；
4. 按 E 下船，确认人物落在码头或跳板，不掉入海面；
5. 按 F3、右键/中键和滚轮测试三种镜头；
6. 打开对话、贸易、暂停，确认输入不会穿透到人物或船；
7. 按 F5 保存，返回主菜单后选择继续，确认位置、航程、贸易和 D5 状态恢复；
8. 检查 Console：本次流程不产生红色错误或持续刷屏警告。
