## 4. 用户手动验收路径

进入新游戏后按以下顺序操作：

1. 用 WASD 走几步，按住 Shift 观察奔跑，按 Space 观察跳跃。
2. 靠近老水手按 E，关闭对话后再次按 E 或点击右侧上船按钮。
3. 上船后按住 W 航行，按 E 下船，确认人物回到码头附近。
4. 按 T 开始航程，按 N 推进，按 L 靠港，按 G 采集，按 B 打开并关闭贸易，按 F5 保存。
5. 点击 D5 HUD 按钮和按 ESC，确认没有菜单叠加、按钮无响应或鼠标锁死。
6. 按 F3 依次切换“人物视角→船上视角→港口总览→人物视角”；每种模式用右键/中键拖动和滚轮确认镜头仍可操作。
7. 靠近码头、船体和道具重复切换 F3，确认镜头遇到遮挡会靠近目标而不是穿过障碍，离开遮挡后能平滑恢复。

## 5. 已知边界

- 当前人物动作是项目内生成的可复用动作资源，不等同于最终动捕品质；后续可直接替换 Animator 的 Motion。
- 当前姿态门禁验证的是相对 FBX 原始姿态的稳定性，不替代用户对腿部朝向、步态和模型美术质量的主观验收。
- 当前平滑姿态层改善了占位模型的动作连续性，但不等同于最终动捕、脚步 IK 或真实上下船动画。
- 港口仍使用低模占位资产，D6 做的是灯光、材质和可读性提升，不是最终美术重制。
- 相机遮挡目前是通用 SphereCast + 安全间隙保护，不等同于最终 Cinemachine、室内镜头或复杂地形镜头策略。
- 自动冒烟不能替代用户对视角手感、按钮位置和画面审美的主观确认。
