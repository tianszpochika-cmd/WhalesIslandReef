# 【提示词 P1A】主菜单控制中台 — 可并行

## 角色与任务
你是《鲸骨航线》的 UI 与流程工程师。任务：实现主菜单"控制中台"（新游戏/继续/设置/关于）与场景状态机。

## 必读
1. `docs/AGENTS.md`（铁律）
2. `docs/game/REQUIREMENTS.md` 第 9 节（界面与操作）
3. `docs/DEVELOPMENT_STANDARDS.md` 第 1 节（所有权：你只写 `Assets/Scripts/Gameplay/` 下 UI 相关 + `Assets/Scenes/MainMenu.unity`）

## 前置依赖（P0 已完成）
- `SaveSystem` 接口桩存在（`Assets/Scripts/Systems/Save/SaveSystem.cs`，签名见 P0 提示词）——**你只调用，不实现、不修改**

## 任务清单
1. **MainMenu 场景**：新建 `Assets/Scenes/MainMenu.unity` 加入 Build Settings；背景（纯色/天空盒占位即可）+ 标题"鲸骨航线"。
2. **菜单项**（UGUI）：
   - **新游戏**：点击 → 打开"创建游戏"面板（输入船长名 InputField + 确认按钮；船型 M0 固定小渔船不选择）
   - **继续**：点击 → 调 `SaveSystem.HasSave()`；true → 调 `SaveSystem.Load()` 成功后切场景；false → 按钮置灰并提示"没有存档"
   - **设置**：打开设置面板——音量（主/音乐/音效三个 Slider）、画质档位（Dropdown：低/中/高）、语言（Dropdown：简体中文/English，切换立即生效于当前 UI）、键位说明（只读文本）
   - **关于**：打开关于面板——版本号 v0.1.0-D1、开发信息（独立开发者）、合规声明（素材授权、年龄分级）、退出按钮
3. **设置持久化**：音量/画质/语言存 `PlayerPrefs`（键名 `wb_volume_master/music/sfx`、`wb_quality`、`wb_lang`）；启动时读取应用。
4. **GameManager 状态机**：`Assets/Scripts/Core/GameManager.cs`（单例，DontDestroyOnLoad）：
   - 场景切换封装：`LoadMainMenu()` / `LoadInitialHarbor()`（P1C 的场景，用名字加载，允许暂不存在时给出日志）
   - 游戏状态枚举：`MainMenu / NewGame / InGame`；记录当前状态供其他系统查询
5. **UI 框架**：面板切换基类（显示/隐藏、打开时暂停游戏逻辑可选）；所有 UI 文案走一个静态文本表（为后续本地化做准备：`Assets/Scripts/Gameplay/UI/Localization.cs`，先硬编码中英两套字典，按 PlayerPrefs 语言取）。

## 验收（DoD）

- [ ] 继续按钮按 HasSave() 状态正确置灰/可用；设置/关于正常；语言切换即时生效
- [ ] GameManager 状态机编译通过；UI 代码只在你负责的目录
