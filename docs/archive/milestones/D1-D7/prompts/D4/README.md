# D4 任务总览：内容扩充

> 目标：在 D3 可玩环上完成炮战、势力、生态、医疗、主线和日志，让商人/私掠者/探险家三条路线可走通。
> 范围事实源：[`D4_SCOPE.md`](../../design/D4_SCOPE.md)

| 编号 | 类型 | 任务 | 依赖 | 状态 |
|---|---|---|---|---|
| D4-01 | 同步 | 范围、数据所有权、契约和测试门冻结 | D3 | 已完成 |
| D4-02 | 同步 | 7 势力、声望、战争、私掠/禁运/检查 | D4-01 | 已完成 |
| D4-03 | 异步 | 5 船型与 6 槽位数值改装 | D4-01 | 已完成 |
| D4-04 | 异步 | 三种炮弹、敌船、炮战和简化接舷战 | D4-03 | 已完成 |
| D4-05 | 异步 | 15 种动物与确定性生态行为 | D4-01 | 已完成 |
| D4-06 | 异步 | 5 种疾病、伤势、医疗资源和治疗 | D4-05 | 已完成 |
| D4-07 | 同步 | 三章九任务、教学旗标和航线日志 | D4-02/04/05/06 | 已完成 |
| D4-08 | 同步 | D4 快照存档、旧存档兼容和 Unity 运行时 UI | D4-02~07 | 已完成 |
| D4-09 | 异步 | 服务端 D4 契约镜像和开发态网关 | D4-01 | 已完成 |
| D4-10 | 同步 | 三端构建、Unity 测试、运行时冒烟、文档和验收 | D4-02~09 | 已完成 |

本轮由主 agent 按 01→10 顺序执行完成。D4 的服务端路由只做契约镜像，客户端 Systems 仍是当前单机玩法的强逻辑裁决者。

验收报告：[`D4_ACCEPTANCE_REPORT.md`](../../design/D4_ACCEPTANCE_REPORT.md)。
