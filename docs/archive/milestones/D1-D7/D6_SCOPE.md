# D6 首次航程体验层范围

> 状态：前四项开发计划、D6.1 物理落地补强、D6.2 角色姿态基线、D6.3 动作/视角增强与 D6.4 相机遮挡保护已完成，技术验收通过；用户手动体验验收待进行。日期：2026-08-09

## 1. 阶段目标

D6 的第一批可见目标是把 D5 的技术底座收束成一条清晰的首次航程体验：

`看见人物 → 移动/动作反馈 → 对话 → 上下船 → 操船 → 航程 → 靠港采集 → 贸易 → 保存`

本批次只做表现层、输入层和引导层接线，不改变 D2/D3/D5 Systems 的数值裁决权，也不新增跨端契约。

## 2. 四项交付

| 计划 | 交付内容 | 主要实现 |
|---|---|---|
| 正式角色动作 | 生成并接入六个动作状态；保留三轴姿态基线，使用 Animator 状态 + 平滑姿态层增强步态和上下船过渡 | `D6AnimationAssetInstaller`、`D2CharacterAnimationController`、`Assets/Resources/D6/` |
| 港口场景品质 | 统一灯光、雾、海面材质、岸线泡沫、灯笼和港口标识，保持低模资源可替换 | `HarborPresentationController` |
| 交互稳定化 | 单一 EventSystem、D5 主 HUD、旧 HUD 隐藏、文字不拦截按钮射线、鼠标状态恢复、对话/上船入口去冲突 | `HarborInteractionStabilizer`、`RuntimeHudCoordinator`、`D2ControlRouter` |
| 新手引导闭环 | 以非阻塞提示引导移动、对话、上下船、航程、靠港、采集、贸易和保存，全部按实际运行时状态推进 | `HarborTutorialController` |

## 2.1 D6.1 复测补强

用户手动复测暴露“角色漂浮、沙滩和道具无碰撞、下船后无法稳定落地”的底座问题。D6.1 在不改变 D2/D3/D5 Systems 裁决的前提下补齐 Unity 表现层物理：

- 角色改用 `CharacterController`，统一处理重力、落地、跳跃和碰撞移动；
- 运行时建立沙滩、码头、跳板、码头道具和船体碰撞边界；
- 上船临时关闭人物碰撞，下船后按真实表面重新落地；
- 海岸安全边界只作为游泳系统完成前的临时防护，不伪装成游泳功能。

## 2.2 D6.2 角色姿态基线

针对用户复测中“腿朝上、动作切换后姿态异常”的表现补齐动画资源基线：

- 六个动作片段同时保留 x/y/z 三轴的 FBX 原始骨骼旋转；
- Animator 状态关闭 Write Defaults，避免局部动作覆盖未参与动作的骨骼；
- 待机姿态采样下肢偏差，D5 运行时冒烟要求最大偏差不超过 8°；
- 当前仍是可替换的占位动作，不把生成动作冒充最终动捕品质。

## 2.3 D6.3 动作过渡与视角切换

针对动作生硬和视角不足的问题补齐表现层：

- 动作状态采用 0.18 秒混合，新增待机呼吸、交替步态、奔跑倾身/屈膝、跳跃和上下船过渡；
- 动作只叠加 FBX 原始骨骼姿态，不改变物理碰撞体的定位；
- F3 循环切换人物视角、船上视角、港口总览；
- 三种视角都保留右键/中键拖动和滚轮缩放，视角切换自动更新跟随目标和镜头预设。

## 2.4 D6.4 相机遮挡保护

针对视角切换后镜头可能穿过码头、船体或道具的问题补齐镜头边界：

- `CameraFollow` 从跟随目标 pivot 到期望镜头位置执行 SphereCast；
- 检测到障碍时在障碍物前保留安全 padding，并限制最小观察距离；
- 障碍物离开后平滑恢复当前视角的原始距离，避免镜头跳动；
- 排除当前跟随目标及其子级碰撞体，三种视角和拖动/缩放继续共用保护逻辑；
- 运行时冒烟检查碰撞检测次数、遮挡状态和解析距离是否有效。

## 3. 数据所有权与边界

1. `D2CharacterAnimationController` 只负责视觉动作，不写航行、好感、贸易或存档数值。
2. `HarborPresentationController` 只负责 InitialHarbor 表现对象和渲染参数。
3. `HarborInteractionStabilizer` 只负责 UI 输入路由和射线配置，不替换业务按钮回调。
4. `HarborTutorialController` 只读取 D2/D3/D5 状态并显示提示，不推进航程、不修改资源、不裁决交易。
5. 动作资源由编辑器安装器生成，运行时不下载第三方资源，不引入网络或 LLM。

## 4. 明确不纳入

- 商店级动捕、面部表情、口型、战斗连招和复杂攀爬。
- 最终高模、贴图重制、海洋插件采购或外部资源自动下载。
- Rigidbody 布娃娃、游泳/落水、船体浮力和最终 NavMesh。
- 新的服务器接口、JSON Schema 或 Systems 数值规则。
- 自动替代用户的主观美术验收；最终画面仍需在 Unity Game 视图手动确认。

## 5. 验收门

1. InitialHarbor 自动创建真实人物外观和正式 Animator 控制器。
2. 运行时能区分待机、走路、奔跑、跳跃和上下船过渡，且动作切换平滑。
3. 待机姿态不覆盖 FBX 原始下肢方向，姿态回归门禁通过。
4. F3 能循环切换三种视角，视角切换后仍能旋转、缩放和跟随当前控制对象。
5. 镜头遇到港口/船体/道具遮挡时收缩到安全距离，障碍离开后平滑恢复；运行时解析距离为有限值。
6. 港口品质层创建并初始化海面、岸线泡沫、灯笼和标识对象。
7. D5 主 HUD 可交互，旧 HUD 不叠加、不拦截鼠标；ESC 暂停仍置于最上层。
8. 新手引导对象存在并能按真实 D2/D3/D5 状态推进。
9. AgentCore、Server 和 Unity 脚本编译通过；D5 运行时冒烟通过。
10. 文档、验收报告和当日 memory 同步留痕。
