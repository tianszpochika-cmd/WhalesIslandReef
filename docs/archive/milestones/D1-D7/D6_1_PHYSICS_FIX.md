# D6.1 港口物理落地补强

> 日期：2026-08-09  
> 状态：**技术完成，等待用户在主工程手动确认操作手感**

## 1. 问题与根因

用户复测发现角色漂浮、腿部姿态看起来像悬空、走不到沙滩，且木桶、货箱、码头和船体没有阻挡效果。

根因不是 Unity 没有物理引擎，而是此前的 D2 控制器直接修改 `Transform.position`，只用一个固定的 `_groundY` 模拟重力；同时港口安装器为了避免低模装饰产生杂乱碰撞，主动移除了沙滩、码头和道具的碰撞体。

## 2. 交付内容

| 模块 | 交付 |
|---|---|
| 角色运动 | `D2CharacterController` 改为 Unity `CharacterController`，接入碰撞移动、重力、落地、跳跃、斜坡和台阶参数 |
| 角色出生 | 根据角色渲染包围盒计算碰撞体高度/半径和脚底偏移，运行时从射线检测到的沙滩表面落地 |
| 港口地面 | 新增 `HarborCollisionController`，建立沙滩、码头、跳板三个可行走表面 |
| 物体碰撞 | 为码头立柱、栏杆、系缆柱、木桶、货箱和船体补充静态/跟随船体的碰撞体 |
| 安全边界 | 海岸线增加不可见边界，防止在游泳系统完成前掉入海面；地面射线不会误把安全墙或船体顶部当作落脚面 |
| 上下船 | 上船时关闭人物碰撞体并绑定船体；下船时先恢复角色模式，再启用碰撞并重新吸附到码头/跳板/沙滩 |

## 3. 验收证据

- `dotnet build game/game.sln --no-restore -v:minimal`：0 警告、0 错误。
- `dotnet build game/AgentCore/AgentCore.csproj --no-restore -v:minimal`：0 警告、0 错误。
- Unity 6 D5 运行时冒烟：退出码 0；确认 `BeachGround` 落地、下船落地、CharacterController、碰撞层、跳跃、上下船、Animator 和旧 D5 门禁全部通过。
- 运行时日志关键证据：`[D2/Physics] 玩家已落地：surface=BeachGround`、`[D5 Smoke] Physics check ... grounded=True`、`[D5 Smoke] InitialHarbor verified ... collision/grounding ...`。

## 4. 手动确认路径

进入新游戏后：

1. 观察角色脚底应贴在沙滩，不应悬空或持续下坠。
2. 用 WASD 走向码头、木桶和货箱，角色应被实体边界阻挡；走下跳板后应站到码头/沙滩。
3. 靠近船按 E 上船，再按 E 下船；下船后角色应重新落地且可以继续走动。
4. 按 Space 跳跃，松开后应受重力回到地面；按 Shift 移动应进入奔跑状态。
5. 走向海面时应被临时海岸边界挡住。游泳、落水和船体浮力不属于本补强范围。

## 5. 边界

本补强解决“角色能否站稳和发生基础碰撞”的底座问题，不等同于最终角色物理或船舶物理：

- 人物使用 CharacterController，不加入 Rigidbody 布娃娃、布料和复杂受力。
- 船只仍由 D2 纯 C# 航行系统裁决位置/朝向；船体碰撞只负责表现层边界。
- 海水游泳、落水救援、船体浮力和最终码头 NavMesh 留给后续航海体验任务。
