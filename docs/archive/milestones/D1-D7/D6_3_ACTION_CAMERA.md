# D6.3 动作过渡与视角切换

> 日期：2026-08-09
> 状态：技术验收通过

## 1. 本次目标

用户复测反馈：动作虽然存在，但切换生硬、步态观感不好；同时需要可以快速切换观察角度。本次只增强 Unity 表现层，不改变 D2/D3/D5 Systems 的数值裁决。

## 2. 动作改进

- Animator 继续负责 `Idle/Walk/Run/Jump/Boarding/Disembarking` 状态语义；
- 新增 0.18 秒动作混合，状态变化不再瞬间跳姿势；
- 新增平滑姿态层：待机呼吸、左右交替步态、奔跑倾身和屈膝、跳跃姿态、上下船过渡；
- 姿态层使用 FBX 原始骨骼作为基线，动作只叠加小幅角度，不再把模型整体旋转到异常方向；
- 运行时记录动作过渡次数，冒烟测试确认姿态层确实被执行。

## 3. 视角切换

`CameraFollow` 新增三个视角模式：

| 快捷键 | 模式 | 用途 |
|---|---|---|
| F3 | 人物视角 | 近距离跟随角色，适合走路、对话和上下船 |
| F3 | 船上视角 | 以船为观察目标，适合操船和看甲板 |
| F3 | 港口总览 | 拉远并抬高镜头，适合观察码头布局 |

所有模式都保留右键/中键拖动旋转和滚轮缩放；切换后会自动恢复合适的距离、俯仰角和观察目标。D5 底部提示已同步显示 `F3 切换视角`。

## 4. 验收证据

Unity 6 隔离副本运行冒烟通过：

- 视角循环日志：`船上视角 → 港口总览 → 人物视角`；
- `Camera check: modes=3, cycle=True, restored=人物视角`；
- `Action quality check: proceduralPoseLayer=True, transitions=1`；
- `Pose check: neutralSampled=True, lowerBodyError=0.0°`；
- `[D5 Smoke] InitialHarbor verified`，退出码 `0`；
- 无 C# 编译错误、无 `Step Offset` 警告。

## 5. 边界

当前动作仍是占位模型上的表现增强，不等同于最终动捕、脚步 IK 或真实上下船动画。后续接入正式角色资源时，保留动作状态接口和 F3 视角接口即可替换 Motion。
