## 当前实现与目标

- D4 已实现：5 种简化船型、6 个改装槽、0—3 级改装、基础炮战字段；
- D7 已实现：舵位入口、上下船、甲板状态和控制权切换；
- M4—M5 目标：20 种船体、80 个改装模块、60 个船上功能点、船坞和锚泊完整闭环；
- M6 后置：复杂浮力、可破坏船体、自由舱室摆放、完整小艇物理和多人共享船舶。

## 设计规则

1. 船舶强逻辑由确定性 Systems 裁决；
2. Agent 只能识别命令、提供报告和生成台词；
3. 改装收益必须伴随空间、重量、吃水、人员、材料或风险代价；
4. 新字段先进入 ship/10_SHIP_DATA_MODEL.md，再设计版本化契约；
5. 旧文档与阶段文档只记录历史事实，不覆盖本目录的长期船舶设计。
