# D7 首航体验质量版范围

> 状态：开发中；D6 已完成技术与用户手动验收。日期：2026-08-09

## 1. 阶段目标

D7 不新增大型玩法系统，专门把 D6 的“能运行”提升为“控制稳定、反馈清楚、首航可完成”的质量版本：

`人物控制 → 动作/落地 → 接近舵位 → 上下船 → 出航 → 靠港/采集/贸易 → 全量保存 → 继续恢复`

## 2. 任务拆解

| 任务 | 类型 | 交付 | 验收出口 |
|---|---|---|---|
| D7-01 控制状态统一 | 同步 | 单一控制状态、模态输入锁、ESC 关闭优先级、鼠标/焦点恢复 | 对话/贸易/暂停时不串键、不失锁 |
| D7-02 人物动作质量 | 同步 | 加速度移动、动作状态反馈、视觉落地校准、保留可替换 Animator 接口 | 人物不再表现为柱体/漂浮，走跑跳过渡稳定 |
| D7-03 上下船与舵位 | 同步 | 舵位交互锚点、登船状态、甲板碰撞校验、镜头与控制权切换 | 上船后人物跟船，下船能落到安全表面 |
| D7-04 首航闭环 | 同步 | 全量保存入口、引导状态恢复、首航状态反馈 | 新游戏→首航→保存→返回→继续可恢复 |
| D7-05 综合回归 | 同步 | Unity 运行时门禁、EditMode 回归、构建/控制台检查 | D7 验收报告全绿 |
| D7-A1 材质表现保真 | 异步 | 保留模型贴图，去除 D5 对角色材质的纯色覆盖 | 有贴图的模型不被替换为纯色 |
| D7-A2 音频接线 | 异步 | 港口环境、脚步、登船和船舶移动的可替换音频通道 | 无外部音频时使用低音量程序化兜底 |
| D7-A3 回归测试 | 异步 | 控制状态纯逻辑测试、运行时状态诊断 | 输入锁和权限状态可独立验证 |
| D7-A4 文档/性能留痕 | 异步 | 控制说明、性能采样、D7 memory 与交接说明 | 代码、文档、验收证据同步 |

## 3. 依赖顺序

1. D7-01 先建立输入状态边界；
2. D7-02 依赖 D7-01 的人物控制权；
3. D7-03 依赖人物物理与控制权稳定；
4. D7-04 依赖上下船和 D3 航程入口；
5. D7-05 在同步任务完成后统一执行；D7-A1 至 D7-A4 可在不修改同步任务核心文件的前提下并行。

## 4. 边界

- 不在 D7 引入多人、语音、完整 Cinemachine、游泳、最终动捕或岛屿经营；
- 不改变 D2/D3/D4/D5 Systems 的数值裁决；
- 不新增跨端契约；D7 的输入状态和表现诊断只属于本地客户端；
- 正式美术和音频采用可替换接口，当前没有外部资源时必须安全降级。

## 5. D7 完成标准

- 人物能稳定走、跑、跳，脚底与可行走表面一致；
- 输入在人物、船、对话、贸易、暂停之间只有一个有效控制权；
- 上下船有明确舵位入口，人物/船/镜头状态不互相覆盖；
- F5 或返回主菜单能保存 D2/D3/D4/D5 运行时状态；
- 继续游戏能恢复港口、船、人物控制和首航进度；
- D7 运行时冒烟、全量 Unity 编译、AgentCore、Server 和 EditMode 回归通过。
