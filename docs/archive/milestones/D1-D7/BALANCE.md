# 数值平衡基线（BALANCE）— 骨架

> 目标：让"强逻辑"可调参。所有数值集中在此定基线，**玩家可学会预判**（支柱 P6）。
> 待填充：每个系统给出初始基线 + 增长曲线 + 风险公式。

## 待填充项

| 系统 | 基线项 | 草稿 | 状态 |
|---|---|---|---|
| 经济 | 初始资金 / 商品基础价表 / 关税系数 / 套利空间 | 🟡 |
| 船员 | 初始数值（60/60/100/0/0）✅ 已定 | 特质增益减益表（50 条） | 🟡 |
| 叛变 | 风险公式 ✅ 已定（见 REQUIREMENTS 6） | 特质修正系数表 | 🟡 |
| 船只 | 8 船型属性表（航速/载重/炮位/造价） | 改装成本曲线 | 🟡 |
| 战斗 | 炮伤/命中/装填 / 登船战数值 | 🟡 |
| 声望 | 声望等级门槛 / 解锁效果 | 🟡 |
| 生存 | 食物→士气映射 / 坏血病阈值 / 生火成功率 | 🟡 |
| 成长 | 技能升级曲线 / 招募水手成本（史实锚定） | 🟡 |

## 平衡原则
1. **高成本高回报**（P4）：盖伦贵，但值得；招募名医贵，但值
2. **付出-风险-回报**透明：玩家能算出"这趟值不值"
3. 全部参数 ScriptableObject 化（game/Assets/Settings），改参不改代码
4. 数值必须**史实锚定**（1675 造价/薪金/物价有据可查）
