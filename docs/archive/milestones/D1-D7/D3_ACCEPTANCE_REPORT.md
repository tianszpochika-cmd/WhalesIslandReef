# D3 最终验收报告：贸易与完整航程可玩环

> 验收日期：2026-08-09
> 范围：D3-01 至 D3-10；结论：**通过**

## 1. 验收结论

D3 已完成一个可运行、可保存、可测试的最小可玩环：

`整备 → 贸易/采集 → 出航 → 日推进与事件 → 抵达/结算 → 保存/继续`

本阶段使用灰盒内容和确定性本地系统，保留了 D2 的人物/船控制、镜头、昼夜、对话和暂停流程。美术精修、完整经济内容、多人联机和 D4 内容不属于本阶段验收范围。

## 3. 操作说明

进入 `InitialHarbor` 后：

- `B`：打开/关闭贸易面板；面板中选择商品、买入或卖出。
- `T`：按当前目标港口开始航程。
- `N`：推进一天；航程结束后自动进入抵达状态。
- `L`：在目标地点登岛并结算。
- `G`：在村庄或荒岛采集一次。
- `C`：保存 D3 贸易、库存和航程快照。
- `Esc`：关闭贸易面板；游戏暂停时由 D2 暂停菜单处理。

## 5. 已知边界与下一阶段

- 当前港口、人物和船仍是灰盒/占位表现，D3 只验证玩法闭环，不代表最终美术质量。
- Server trade 模块是开发态契约镜像，客户端本地系统仍是当前单机玩法的裁决者；后续联网化需要按契约接入并重新确认数据所有权。
- D4 再处理炮战、四国声望、动物、疾病、主线和更丰富内容。
