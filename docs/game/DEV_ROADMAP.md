# D7 之后统一开发路线图 v3.0

> 本文件是唯一开发计划入口。D1—D7 是已完成历史基线；未来工作不再继续沿用旧的“阶段堆任务”模式，而按系统所有权、垂直切片和可验收工作包推进。
>
> 需要直接分发给 Agent 执行时，先使用 [Agent 开发任务总索引](AGENT_DEVELOPMENT_TASKS.md) 找到编号，再打开对应的 D8—D16 章节提示词文件；不要自行从本路线图重新拆出另一套任务编号。

## 2. 开发纪律

每个工作包必须先回答：

1. 归属哪个系统，谁是唯一写者；
2. 输入和输出是否需要 `contracts/`；
3. 影响哪些玩法和存档字段；
4. Agent 只能提出什么，逻辑层如何裁决；
5. 正常、失败、恢复、读档和性能怎么验收。

一个工作包只能有一个主要写者模块。跨模块功能拆成依赖明确的子包，不通过复制数据或私有协议耦合。

## 4. 工作包清单

### D8 数据、契约与存档统一

| 工作包 | 产出 | 验收 |
|---|---|---|
| D8-01 核心实体 | Player、Ship、Crew、Island、Building、Item、Animal、Faction、Quest、Asset | 字段、ID、版本和所有权齐全 |
| D8-02 玩法事件 | Voyage、Trade、Fishing、Property、Farm、Relationship、Treasure、Combat 事件 | 事件可序列化、可追踪、不可重复结算 |
| D8-03 AgentReply | 对话、P2A、提议、情绪和关系建议 Schema | 非法输出不能进入逻辑层 |
| D8-04 存档迁移 | D1—D7 旧存档 → v3 结构 | 旧存档可加载或给出明确迁移失败原因 |
| D8-05 内容 ID | 全领域 ID 表、来源、授权、阶段和测试 ID | 无重复 ID、无孤儿引用 |

### D9 港口垂直切片

一座港口、一艘小船、一个近海鱼场、一个村落 NPC、一个船员 Agent、10 个商品、一个小型寻宝事件、一个天气事件和一次可撤退战斗。

验收：玩家能从整备出发，航行、钓鱼、遇到风暴、与船员讨论、靠港交易、支付工资、修船、保存并恢复。

### D10 角色社会与外观

- 好感、信任、忠诚、恐惧、嫉妒和爱情关系；
- 玩家性别/身份表达、发型、服装、饰品和职业适配；
- 船员会议、礼物、承诺、冲突、离队和个人任务；
- 酒馆牌局作为关系、信息和风险场景。

验收：玩家的一次承诺能影响关系；同一件服装能在角色创建、商店购买、换装、存档和读档中保持一致。

### D11 海洋采集与生态

- 手线、网、笼、岸钓、浅水采集和活鱼舱；
- 鲸豚观察、捕鲸路线的历史/法律/生态后果；
- 珍稀动物救助、收藏、交易、释放和图鉴；
- 猫狗领养、喂养、卫生、预警和船上生活；
- 植被采集、果实、药材、种子、毒物和恢复。

验收：一次过度捕捞会改变鱼群和价格；一次救助会改变声望、收藏记录或后续任务；不使用 LLM 裁决生态数值。

### D12 探索、寻宝与社群

- 海图发现、测深、洞穴、沉船、藏宝线索和非谜题型解锁；
- 原住民和地方社群的礼仪、物物交换、保护区和交易声誉；
- 扑克牌、塔罗牌、酒馆传闻和情报交换；
- 图鉴、收藏、航海日志和特殊发现。

验收：玩家可以用信息、装备、路线和社群关系解决探索目标；失败有替代路线或恢复任务。

### D13 经济、金融与岛屿经营

- 资产估值、买卖、租赁、抵押、税费、产权和违约；
- 贷款、赊账、保险、展期、债务催收和破产保护；
- 农地、果园、蔬菜、牧场、渔场、工坊、仓库和船坞；
- 人口、劳力、供水、食物、防御、污染、生态和政策。

验收：岛屿经营不是菜单按钮；必须在地图上看见建筑/库存/人口变化，并能在经济、势力、任务和存档中恢复。

### D14 战斗、特殊内容与势力后果

- 海战、炮击、接舷、俘虏、投降、撤退、战利品和法律；
- 特殊武器、历史奖励、独特船体模块和收藏品；
- 私掠证、通缉、封锁、护航和列强关系；
- 牌局作弊、走私检查和资产查封等高风险事件。

验收：战斗或违法行为会影响船体、船员、金钱、声望、法律和后续任务，不只生成战利品。

### D15 批量内容生产

按 `REQUIREMENTS.md` 的数量目标生产，每批都必须先有 1 个代表样例通过垂直切片，再扩展到同类内容。

生产顺序：8 类自然模板 → 12 座首批岛 → 50 座岛目录；15 个动物样例 → 300 条目；200 个功能道具；1,000—2,000 个植被条目；建筑、服装、发型、音乐和任务模板按目录生成。

### D16 完整版质量

- 性能：分区流式加载、LOD、对象池、Agent 模拟分级；
- 存档：版本迁移、断电恢复、重复结算保护；
- 内容：历史、敏感内容、授权、文本和本地化审查；
- 体验：新手引导、可读性、无障碍、输入、音频混音和失败恢复；
- 发布：崩溃率、存档成功率、首航完成率、性能预算和商店素材。
