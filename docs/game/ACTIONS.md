# 动作清单（ACTIONS）— P2A 入口

> D8-A04 已将旧草案升级为 60 个结构化 P2A Action。完整注册名、参数 Schema、权限、前置、失败码和执行者以 [`D8_P2A_ACTION_REGISTRY.md`](design/common/D8_P2A_ACTION_REGISTRY.md) 与 `contracts/p2a-action-registry.json` 为准。
> 机制：玩家语音/文字命令 → LLM 映射到 `action_intent` → Schema/边界校验 → 所属强逻辑系统执行和裁决。
> 本文件保留玩法分类入口，不再作为独立的动作事实源。

## 航行类
| 动作名 | 参数 | 说明 |
|---|---|---|
| trim_sail | 帆名, 程度 | 升/降/调整主帆、前帆 |
| steer | 角度/方向 | 左满舵/右满舵/回正 |
| set_course | 目的地 | 设定航线（配合海图） |
| drop_anchor / weigh_anchor | — | 抛锚 / 起锚 |
| stop_ship | — | 停船（下帆+锚） |
| set_watch | 岗位, 船员 | 任命值班（舵手/瞭望/炮手） |
| report | 主题 | 瞭望报告（前方岛屿/敌船/天气） |

## 船务类
| 动作名 | 参数 | 说明 |
|---|---|---|
| fire_cannon | 炮组, 弹种 | 开炮（实心/链弹/葡萄弹） |
| repair | 部位 | 抢修破损/堵漏 |
| bilge_pump | — | 抽水 |
| ration | 标准/丰/俭 | 调整口粮配给 |
| hold_below | 船员 | 关禁闭（惩罚，影响忠诚） |
| reward | 船员, 金额 | 犒赏（提升忠诚） |
| launch_boat | — | 放小艇（登岛/打捞） |
| board | — | 接舷登船战 |

## 登岛与人员
| 动作名 | 参数 | 说明 |
|---|---|---|
| assemble_crew | 目标, 装备 | 集结登岛队伍（带武器/火把/药物） |
| gather | 资源类型 | 采集（水/食物/药材/木材） |
| scout | — | 派侦察（探明危险） |
| treat | 船员, 手段 | 治疗（药物/手术） |
| trade | 对象, 商品 | 与部落/商人交易 |

## 状态
- 执行质量受船员状态影响：疲劳高 → 执行慢/失败率；忠诚低 → **可能阳奉阴违**（返回"动作未完成"事件）。
- 无对应动作的模糊命令：LLM 返回 `none` + 说话内容（船员回应"听不懂"或提出建议）。
