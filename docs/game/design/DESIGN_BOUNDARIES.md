# 设计边界总纲（DESIGN BOUNDARIES）v1.0

> 设计阶段的宪法性文件。与 DESIGN_PILLARS（目标层）配套：
> **PILLARS 定方向（做什么），BOUNDARIES 定权限（谁有权做什么、边界在哪、冲突听谁的）。**
> 所有系统、Agent、NPC、动物的行为边界在此登记；新增元素必须过 `IDEA_BANK` → 支柱排序 → 边界登记。

---

## 1. 玩家边界

### 1.1 能力边界
| 能 | 不能 |
|---|---|
| 移动/攀爬/游泳/划艇（登岛） | 直接修改任何数值（金钱/船员/声望） |
| 自由对话（输入框）与语音命令（P2A） | 无代价跳过惩罚（沉船必有损失） |
| 指挥：岗位任命/命令/决策拍板 | 影响逻辑层裁决（不能"说服"裁判改结果） |
| 交易/战斗/探索/采集/经营 | 查看 LLM 内部记忆原文（只能看"记忆回溯"UI） |

### 1.2 身体与动作集（首批）
走/跑 / 攀爬（船桅、岩壁）/ 游泳 / 划小艇 / 交互（开门、搬货、操舵）/ 采集（砍、挖、拾取）/ 战斗（简化格斗）/ 对话 / 使用工具（望远镜、火石）

### 1.3 失败与惩罚（沙盒不删档，但有代价）
| 失败 | 惩罚 | 可恢复性 |
|---|---|---|
| 沉船 | 货物漂流可捞、船员损失**不可逆**、船换新需重建 | 货物可捞回 |
| 被列强逮捕 | 入狱（时间+罚金）或交赎金；违禁货物没收 | 可恢复 |
| 被海盗抢劫 | 可选抵抗/投降；投降损失部分货物 | 可恢复 |
| 重伤 | 治疗期（行动受限，船员代管） | 可恢复 |
| 玩家角色死亡 | ⚠️ **设计阶段定**：方案 A 永久死亡+继承（重开新角色继承资产，船员记得前任）；方案 B 复活惩罚（丢物品/健康上限） | 待定 |

### 1.4 原则
玩家的每个选择都要有**可预见的后果**（强逻辑）：奖惩规则透明，玩家能学会预判。

## 2. 船员 Agent 边界

### 2.1 权限边界
| 能 | 不能 |
|---|---|
| 说话、表达情绪、提出建议 | 直接修改任何数值（好感变化只能通过 LLM 提议 → 逻辑层裁决） |
| 执行被分配的岗位（舵手/瞭望/炮手…） | 直接触发事件（只能触发"提议"，事件系统裁决） |
| 记住玩家的行为（三层记忆） | 绕过分支锁（被锁的选项 LLM 根本看不到） |
| 在 Persona 与数值约束内决策 | 跨知识边界（不知道的事拒绝，不编造） |

### 2.2 人格边界
- Persona 约束 = 角色一致性承诺：口吻、字数、知识边界（1675 航海时代）
- **角色一致性保护**：即使玩家反复追问，Agent 不能自我矛盾、不能泄露"自己是 AI"、不能因对话技巧被"说服"修改自身性格（性格是硬数据，不是对话可改的）

### 2.3 记忆边界（三层，数值驱动行为）
- 短期：最近 8 轮对话（进上下文）
- 中期：会话摘要（每 10 轮压缩，进上下文）
- 长期：重要性加权事件（Top3 注入）；**好感/忠诚等数值单独存储，直接驱动行为，不进 LLM 上下文**（LLM 看到的是数值化摘要，被锁分支不可见）

### 2.4 执行边界
- 命令执行质量受状态影响：疲劳高→慢/失败；忠诚低→**可能阳奉阴违**（返回"动作未完成"事件，玩家可追责）
- 无模型/断网：降级为模板对话（游戏始终可玩）；本地模型优先，云端兜底

## 3. AI 驱动边界（LLM 权限表）

### 3.1 白名单（LLM 可以负责）
自由对话 / 决策会议辩论 / 篝火夜话 / 叙事（日志/日记/传闻）/ 文化冲突台词 / 事件描述文案 / 命令意图识别（P2A 映射）/ 谈判语气

### 3.2 黑名单（LLM 永不负责——强逻辑红线）
数值结算 / 经济价格 / 事件触发判定 / 船体物理 / 掉落与奖励 / 声望增减 / 战果结算 / 任何状态修改

### 3.3 输出契约与兜底链
`LLM 原始输出 → AgentReply Schema 校验 → 校验失败重试 1 次 → 仍失败用模板兜底`
- 非法输出（缺字段/超范围 affinity_change）**丢弃**，不进逻辑层
- 幻觉被锁死在文案层：LLM 说错了话最多影响观感，**不可能污染数值**

### 3.4 部署边界
- LLM Key 只存服务端（客户端不持有）
- 本地模型（Ollama/qwen2.5）优先，云端（DeepSeek）兜底
- token 计量与配额在服务端（billing 模块）；单航程每船员 ≤20k token 预算

## 4. NPC 逻辑边界（分级设计，控制成本）

| 层级 | 覆盖对象 | AI 策略 | 记忆 |
|---|---|---|---|
| **L1 全 Agent** | 船员（8-12 同屏） | LLM 全对话 + 三层记忆 + 数值 | 有 |
| **L2 智能 NPC** | 商人/官员/部落首领/收藏家 | 有限状态机（交易/任务逻辑壳）+ LLM 对话（谈判语气） | 会话级 |
| **L3 路人 NPC** | 港口居民/酒馆水手 | 模板行为 + 短对话（无记忆，低成本） | 无 |

**谈判边界（关键）**：商人底价/收购价区间由**逻辑层给定**，LLM 只能在该区间内浮动语气——**玩家无法靠"说服"突破底价**（强逻辑红线，防 LLM 漏洞）。

## 5. 动物逻辑边界

- **动物 = 确定性 AI（不使用 LLM）**：行为状态机（觅食/警戒/攻击/繁殖提示）+ 栖息地分布 + 生理数值
- 危险判定数值化：攻击性/毒害等级/群体威胁 → 逻辑层裁决伤害与后果
- 珍稀度 → 交易价值表（逻辑层定价，收藏家收购）
- 真实行为锚点（脚本化）：鲸群迁徙路线固定 / 海豚随船 / 鲨鱼嗅血 / 海龟产卵 / 鸟群指路
- 边界原则：动物**不对话、不算计、不记忆**——它们是"环境的一部分"，行为可预测（真实主义：真实动物就是可预测的）

## 6. 系统间边界（裁决权表）

| 系统 | 数据所有权 | 裁决权 | LLM 角色 |
|---|---|---|---|
| 贸易经济 | 价格/供需/关税 | 经济系统 | 只提供谈判语气 |
| 船员数值 | CrewStats | 强逻辑层 | 提议好感变化，逻辑层裁决 |
| 事件因果 | 触发条件 | 事件系统 | 只生成台词与细节 |
| 声望阵营 | 声望值/战争状态 | 阵营系统 | 只提供交涉台词 |
| 船只物理 | 船体状态 | 物理系统 | 无 |
| 天气 | 天气状态 | 天气系统 | 无 |
| 生存生活 | 火焰/食物/疾病 | 生存系统 | 只描述状态（叙事） |
| 岛屿生态 | 动物/资源 | 生态逻辑 | 无 |

**通信方式**：统一事件总线（事件驱动）；数据所有权唯一（每份数据只有一个系统能写）。

---

## 7. 冲突仲裁规则（优先级从高到低）

1. 设计支柱序号（P1 真实主义 > P2 沙盒 > … > P6 强逻辑）
2. **强逻辑 > LLM**（数值/判定永远优先于 AI 输出）
3. **服务端 > 客户端**（计量/配额/存档权威在服务端）
4. **数值 > 文案**（显示给玩家的文案永远反映真实数值）
5. 边界冲突时：回读本文件 + DESIGN_PILLARS，按 1-4 裁定；仍不清 → 记入"待定"，开会定
