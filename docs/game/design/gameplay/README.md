# 玩法设计总目录

本目录是“玩家实际可以做什么”的唯一入口。领域目录描述系统能力；本目录描述玩家循环、选择、风险、收益和跨系统后果。

## 玩法原则

1. 每个玩法都有入口、动作、资源、时间、风险、奖励、失败和恢复。
2. 玩法必须能和船员、船舶、经济、势力、生态、任务、UI 和存档至少两个领域产生真实联系。
3. 任何奖励不能绕过所属系统凭空生成；任何失败不能只弹一句文本。
4. LLM 只负责对白、建议、牌局气氛、传闻和解释；规则、概率、价格、伤害和奖励由逻辑系统裁决。
5. 玩法优先使用信息、准备和选择制造深度，不使用无意义的重复点击。
