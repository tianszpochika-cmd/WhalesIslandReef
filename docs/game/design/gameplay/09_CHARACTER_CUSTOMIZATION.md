# 玩家性别、身份、发型、服装与装扮

## 1. 玩家角色决策

- 项目只有一个可控制主角，不做“男女双主角切换”；
- 新建角色时选择性别表达、称谓、姓名、年龄段、文化出身和身体外观；
- 存档中保留 `identity_history`，改变称谓或外观不会抹掉过去的法律、债务、声望和关系；
- 港口裁缝、理发师、医生或证件机构可以改变外观表达，但每种改变都有时间、金钱、社会和法律反馈；
- 不用魔法解释身体变化；选择“切换”时表现为身份/外观重新登记和角色自我表达。

## 2. 定制层级

| 层级 | 内容 | 是否影响数值 |
|---|---|---|
| 身体 | 身高范围、体型范围、肤色、脸型 | 仅碰撞/动画兼容，禁止战斗优势 |
| 发型 | 发型、长度、胡须、头巾、帽子 | 天气/职业小反馈 |
| 服装 | 内层、上衣、裤/裙、外套、鞋、手套 | 保暖、防雨、身份和文化 |
| 配饰 | 首饰、徽章、护符、眼镜、腰带 | 识别、关系或少量功能 |
| 装备 | 工具、武器、望远镜、航海仪器 | 由装备系统写性能 |
| 伤病 | 污渍、破损、绷带、跛行、疲劳 | 读取角色状态 |

## 3. 服装经济

服装拥有材料、制作地、职业标签、文化标签、天气适配、耐久、价格、法律限制和资产来源。港口裁缝、商会、战利品、任务、部落交换和特殊奖励都可以提供服装。

服装买卖不能只按稀有度涨价，还要考虑布料、染料、工艺、港口需求、势力徽章和身份风险。

## 4. 解锁方式

- 购买或定制；
- 与裁缝/社群建立关系；
- 完成航线、职业或历史任务；
- 获取特殊奖励和家族遗物；
- 从敌对势力服装中获得伪装，但被识破会带来法律后果。

## 5. 验收

角色创建 → 发型/服装购买 → 换装 → 上船工作 → 雨天/港口检查 → 存档读档，外观、装备、法律身份和关系状态必须互不串写。
