# 玩法总清单与依赖图

## 1. 玩法闭环模板

每个玩法都必须使用以下模板：

```text
入口 → 玩家意图 → 准备 → 执行动作 → 系统裁决
→ 即时反馈 → 资源/关系/世界后果 → 奖励或失败
→ 解锁成长 → 日志与存档
```

## 3. 依赖关系

```text
船舶 + 天气 + 岛屿
        ↓
钓鱼/探索/战斗/运输
        ↓
鱼获/宝藏/货物/信息
        ↓
经济 + 船员关系 + 势力声望
        ↓
资产 + 岛屿经营 + 特殊奖励
```

## 4. 内容扩展规则

- 先做一个完整样例，再批量复制同类内容；
- 新玩法必须登记到需求总纲和本目录；
- 新玩法如果不能解释“为什么玩家要重复它”，只能作为事件或装饰，不得升级为核心系统；
- 玩法数值必须归属一个系统，不在任务、UI 或 Agent 文本里私自修改。
