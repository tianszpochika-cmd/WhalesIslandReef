# 岛屿资产、金融、信用与保险

## 1. 资产类型

- 岛屿经营权；
- 地块、住宅、农地、果园、牧场、渔场；
- 港口商铺、仓库、工坊、船坞和酒馆；
- 船、船上模块、货物和未来船队股份；
- 任务抵押物、家族资产和势力特许。

资产不是纯装饰：每项都要有位置、所有者、权利、估值、收入、支出、维护、风险、法律状态和转让方式。

## 2. 资产交易循环

```text
获得信息 → 估值与产权调查 → 议价/贷款/担保
→ 买入或租赁 → 经营与维护 → 获得收入或承担损失
→ 还债/再投资/抵押/出售/被查封
```

玩家不能购买没有产权依据的地块；有居民的岛屿必须有协议、租赁、共同治理或冲突结果。

## 3. 金融工具

| 工具 | 玩家价值 | 风险 |
|---|---|---|
| 商人赊账 | 没有现金也能进货 | 逾期、价格和关系 |
| 船东贷款 | 买船或改装 | 抵押、利息、查封 |
| 保险 | 分散货物/船体风险 | 保费、证据、拒赔 |
| 资产抵押 | 快速获得现金 | 丧失经营权 |
| 合伙投资 | 建设港口/工坊 | 分红、争议和退出 |
| 预购合同 | 锁定商品买家 | 延期、违约和价格风险 |

## 4. 信用模型

信用由按时还款、交易记录、资产、担保人、势力声望、法律状态、船舶损失和违约次数决定。信用不是单一分数，还需要显示“为什么变好/变坏”。

## 5. 违约和恢复

- 展期：增加利息或交出新担保；
- 以任务抵债：护航、运输、找回资产或提供证据；
- 重组：降低月付，但失去部分利润；
- 破产保护：暂时冻结债务，失去资产和信用；
- 逃债：转入黑市或海盗路线，面对追捕和资产没收。

EconomySystem/FinanceSystem 写钱、债务、保险和信用；PropertySystem 写所有权与估值；FactionSystem 写法律查封；QuestSystem 只提出任务。

## 6. 验收

玩家能买入一间仓库、用其抵押贷款、因风暴申请保险、因证据不足部分拒赔，并在恢复后看到资产、债务、利息和库存完全一致。
