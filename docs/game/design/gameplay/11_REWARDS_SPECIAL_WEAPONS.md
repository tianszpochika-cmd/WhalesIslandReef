# 特殊奖励、独特武器与稀有模块

## 1. 奖励分层

| 层级 | 例子 | 设计要求 |
|---|---|---|
| 普通 | 现金、食物、材料 | 支撑循环，不改变路线 |
| 专业 | 图纸、证书、工具、服装 | 解锁新方法 |
| 稀有 | 特殊船模块、航海仪器、收藏品 | 有来源和维护 |
| 独特 | 历史武器、家族遗物、特殊船体 | 唯一 ID、强烈代价和叙事 |
| 世界级 | 岛屿产权、船队特许、势力称号 | 改变地图关系和长期目标 |

## 2. 特殊武器设计

特殊武器不是普通武器的无条件升级。每件武器必须写清：

- 来源、历史/虚构标签、唯一 ID；
- 弹药或燃料；
- 命中、射程、装填、可靠性、维护；
- 对船体、船员、环境和法律的影响；
- 获取条件、丢失风险、修复和替代路线；
- 是否能被转让、出售、抵押或收缴。

可包括特殊炮架、隐蔽火枪、短程散弹器、信号炮、救援器具和非致命捕缆器，但不设计现代武器或魔法效果。

## 3. 奖励来源

- 主线关键节点；
- 高风险寻宝；
- 势力许可和声望；
- 船员个人任务；
- 岛屿经营里程碑；
- 图鉴/生态保护成就；
- 牌局和社群交换；
- 历史遗址的合法发现。

## 4. 反刷与失败

奖励由 `RewardSystem` 生成并写入日志。任务系统只能提出奖励请求；读档不会重复领取；特殊物品丢失后只能通过修复、追踪、债务、竞争者或新任务恢复，不能无条件重生。

## 5. 验收

完成一条高风险探索获得特殊模块；模块装上船后改变重量/维护/外观；战斗损坏后需要维修；读档、出售、收缴和替代路线都能正确处理。
