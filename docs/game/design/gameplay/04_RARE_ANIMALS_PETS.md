# 珍稀动物、救助、收藏与猫狗

## 1. 珍稀动物路线

珍稀动物玩法不等于“抓到就卖”。每个对象至少提供四种处理方式：

- 观察和记录：完成图鉴、获得路线和生态信息；
- 救助和释放：提升生态/社群声望，可能解锁后续观察；
- 合法转移：交给收藏家、医护机构或势力指定地点；
- 非法捕捉或交易：短期收益更高，但承担法律、疾病、运输死亡和生态后果。

## 2. 稀有度

稀有度来自生境、季节、颜色/年龄变体、行为记录和发现条件，不直接等于更强。每个条目有：

`species_id`、`habitat`、`season`、`behavior`、`rarity_reason`、`capture_policy`、`transport_need`、`buyer_type`、`release_region`、`welfare_state`、`source_note`。

## 3. 收藏循环

```text
获得传闻 → 到达正确生境 → 观察/追踪 → 识别
→ 选择记录、救助、转移或放流 → 处理声望/法律/生态
→ 图鉴补全 → 解锁收藏家、研究者、社群和特殊任务
```

收藏册不只统计数量，还记录首次地点、季节、行为、是否救助、是否造成伤害和证据来源。

## 4. 猫狗系统

猫狗是船上生活和港口关系系统，不是战斗宠物：

- 来源：港口领养、救助、船员推荐、农场交换；
- 状态：饥饿、健康、清洁、疲劳、恐惧、依恋、当前位置；
- 行为：跟随、睡眠、捕鼠、预警陌生人、寻找船员、安抚孤独；
- 限制：船型空间、风暴、疾病、港口检疫、长途补给；
- 后果：宠物走失、受伤、死亡会影响船员士气和关系，不能无成本重生。

## 5. 唯一写者

EcologySystem 写野生动物和生境；AnimalCareSystem 写宠物照料状态；EconomySystem 写交易价格；FactionSystem 写许可证和法律；CollectionSystem 写图鉴完成度；QuestSystem 只消费事实。

## 6. 验收

至少完成一条“发现珍稀海龟—选择保护—后续回到海滩观察产卵”的链路，以及一条“港口领养猫—船上捕鼠—补给不足—船员反应”的链路，并验证读档不重复奖励。
