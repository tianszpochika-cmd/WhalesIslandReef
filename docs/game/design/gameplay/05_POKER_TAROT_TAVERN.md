# 扑克牌、塔罗牌、酒馆与情报

## 1. 玩法定位

牌局是社交风险玩法，不是独立赌场模拟。玩家通过牌局认识人、交换传闻、判断性格、承担债务或改变船员关系。

## 2. 扑克牌循环

```text
进入酒馆/船员休息场景 → 选择牌局等级和下注上限
→ 观察对手、选择跟注/退出/加注 → 结算输赢
→ 处理债务、作弊指控、情报、声望和关系
```

牌局数据：`table_id`、`ruleset`、`ante`、`max_bet`、`players`、`skill_tags`、`cheat_risk`、`debt_limit`、`reward_tags`、`history`。

牌局必须有明确的退出按钮、最大损失、输不起时的替代选择和禁赌港口政策。不能通过保存/读档刷牌局结果。

## 3. 塔罗/牌面占卜

塔罗牌在本项目中不产生超自然事实。它表现为：

- 宗教、民俗和心理安慰；
- 占卜者根据牌面给出带偏差的解释；
- 解释可提供线索方向，但任务系统仍要求玩家用证据验证；
- 不同文化和角色会有不同信任度；
- 错误解释可以导致时间、钱或关系损失。

流程：抽牌 → 角色解释 → 玩家选择相信/质疑/求证 → 任务系统产生软提示或误导 → 后续事实验证。

## 4. 与 Agent 的关系

LLM 可以生成牌局气氛、角色口吻和解释文本，不能决定牌面、赔率、胜负、传闻真伪或任务奖励。船员可能因牌局改变好感、信任、嫉妒和债务。

## 5. 酒馆功能

- 招募、休息、吃饭、喝酒、牌局、传闻、雇佣副业、交换联系人；
- 酒精影响疲劳、健康、判断和冲突；
- 酒馆老板是市场、势力和船员社会的交汇 NPC；
- 牌局、夜话和舞会可以触发关系事件，但不强制恋爱。

## 6. 验收

玩家输掉一局后可以退出并承担债务；赢得一局不能凭空改变商品价格；传闻必须有真假或不确定性标签；同一牌局在读档后不能重复结算。
