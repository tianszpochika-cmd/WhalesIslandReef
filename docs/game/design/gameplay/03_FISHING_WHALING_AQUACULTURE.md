# 钓鱼、捕鲸、活鱼舱与水产经营

## 1. 设计边界

水生玩法分为四种，不混成一个“按键捕鱼”：

1. **钓鱼**：玩家主动寻找鱼场，选择渔具并承担时间与天气风险；
2. **海上采集**：贝类、海草、浅水生物和漂流物；
3. **大型动物观察/捕鲸事件**：鲸豚是生态和航海信号，捕鲸是高风险、受法律和声望约束的路线；
4. **活鱼舱/鱼塘**：船上只做短期暂养，岛上建筑才提供长期水产养殖。

## 2. 钓鱼循环

```text
获得传闻/观察鱼群 → 评估潮汐、天气、水深和船位
→ 选择手线/网/笼/岸钓 → 投放与等待
→ 根据鱼群行为、船速和船员技能收获
→ 分拣、冰/盐/烟处理或活体装舱
→ 烹饪、出售、交换、供给船员或投入任务
```

玩家不需要做高频反应小游戏。若使用小游戏，只表现收线节奏，最终结果仍由鱼种、装备、技能、潮汐、天气和耐久裁决。

## 3. 钓鱼数据

- `FishSchool`：鱼种、数量、迁移方向、深度、活跃时间、食物、捕食者；
- `FishingGear`：渔具类型、适用水层、容量、耐久、噪音、误捕率；
- `CatchRecord`：鱼种、重量、品质、损伤、来源、时间、位置、法律状态；
- `ProcessingRecipe`：鲜鱼、鱼干、腌鱼、鱼油、饵料和废料；
- `FishingPressure`：区域捕捞量、恢复速度、保护规则、价格影响。

## 4. 捕鲸设计

捕鲸不是普通鱼类的放大版。玩家先通过观测、航线、社群情报或势力许可发现鲸群，再选择：

- 放弃追踪，获得观察记录、图鉴和航海信息；
- 伴航观察，提升探险家和科学记录路线；
- 救助搁浅或受伤个体，获得社群/生态声望；
- 在允许且具备装备的情况下猎捕，承担船体、船员、处理、法律、市场和生态后果。

捕鲸数据必须包含 `license_status`、`faction_policy`、`season`、`crew_requirement`、`ship_requirement`、`risk_profile`、`ecology_impact` 和 `historical_review_tag`。未经历史与敏感内容审查，不进入批量内容。

## 5. 活鱼舱与水产养殖

### 船上活鱼舱

活鱼舱是运输和短期供给设施：

- 舱容、换水能力、温度/盐度适配、通风、清洁和死亡率；
- 船速、风暴、拥挤、缺氧和污染会影响存活；
- 活鱼可以在港口高价出售、供厨房烹饪或放流；
- 不能把船上活鱼舱当成无限繁殖系统。

### 岛上鱼塘/网箱

岛屿经营阶段可建造淡水鱼塘、红树林网箱或近岸养殖设施。其输入是鱼苗、饲料、劳力和水质，输出是鱼货、废料和生态压力。

## 6. 失败与生态后果

- 误捕保护物种：罚金、声望损失、港口禁入；
- 过度捕捞：鱼群迁移、价格上涨、鸟类和居民受影响；
- 活鱼死亡：货值下降、腐败、疾病和污染；
- 风暴中作业：渔具丢失、落水、船体损伤；
- 捕鲸失败：船员受伤、装备损坏、信息泄露或敌对势力追踪。

## 7. 验收

晴天、雨天、潮汐、夜晚、保护区、过度捕捞、活鱼舱读档、鱼获处理和价格变化必须全部可测试；鱼群和大型动物行为不得依赖 LLM。
