# 探索、制图、沉船、洞穴与寻宝

## 1. 探索原则

宝藏和遗迹的难点是“获得可靠信息、选择正确路线、携带合适装备、承担风险”，不是把玩家卡在无法理解的谜题上。

## 2. 探索循环

```text
传闻/地图碎片/航海日志 → 交叉验证来源
→ 购买或制作装备 → 规划潮汐、天气和登陆点
→ 测深、观察、追踪、进入洞穴或打捞
→ 处理危险、竞争者和社群规则
→ 找到目标/发现替代证据 → 带回、交易、展示或公开
```

## 3. 内容类型

- 沉船：船体位置、货物状态、海流、潮汐、打捞工具和法律归属；
- 藏宝洞：入口、照明、绳索、回头路线、潮汐和塌方；
- 遗迹：建筑用途、历史记录、社群解释和保护规则；
- 山地路线：坡度、天气、疲劳、落石和视野；
- 海图发现：未知海岸、暗礁、浅滩、鱼场和安全航道；
- 生态发现：珍稀动物、植物、巢穴、产卵地和迁徙路线。

## 4. 线索结构

每条寻宝线索包含 `source`、`reliability`、`region`、`time_window`、`required_equipment`、`danger_tags`、`competing_claims`、`reward` 和 `recovery_route`。

线索可以真假混合；玩家可用测深、日志、NPC 信誉、航海技能和历史资料降低错误率。

## 5. 奖励

奖励可以是现金、货物、历史文件、特殊武器、船体模块、地图、关系、声望、图鉴记录、资产产权或新航线，不允许所有探索最后都只发钱。

## 6. 失败恢复

迷航可以回到已知港口；洞穴失败有回头路线或救援；沉船打捞失败会改变残骸和竞争者；线索错误可以产生新线索而不是永久软锁。

## 7. 验收

至少完成一条包含假线索、潮汐窗口、沉船打捞、法律归属和特殊奖励的探索线，并在中途存档后准确恢复。
