# 好感、关系、爱情与船员社会

## 1. 关系模型

单一好感度不足以表达船员社会，关系至少拆成：

| 维度 | 含义 | 典型来源 |
|---|---|---|
| 好感 | 私人喜欢或厌恶 | 对话、礼物、共同经历 |
| 信任 | 是否相信承诺和信息 | 守约、保密、救援 |
| 忠诚 | 是否留下并执行命令 | 工资、分红、保护、身份 |
| 恐惧 | 是否因害怕而服从 | 惩罚、暴力、敌对势力 |
| 尊敬 | 是否认可能力与判断 | 航行、战斗、经营决策 |
| 依恋 | 是否形成亲密关系 | 夜话、长期陪伴、共患难 |
| 嫉妒/怨恨 | 关系中的负面积累 | 偏袒、背叛、恋爱竞争 |

## 2. 关系循环

```text
事件事实 → 角色解释 → 对话/会议/行动 → 数值裁决
→ 短期情绪 → 长期记忆摘要 → 岗位/派系/任务后果
```

关系变化必须引用事实 ID，不能因为一句随机对白直接跳跃 50 点。

## 3. 爱情和亲密关系

- 玩家与 NPC、船员与船员都可发展友情、依恋或爱情；
- 关系有认识、信任、亲密、承诺、冲突、稳定/分离阶段；
- 影响陪伴、忠诚、礼物、共同任务、嫉妒、背叛、离队和结局；
- 不制作露骨内容；亲密表达以对话、礼物、舞会、夜话、港口重逢和共同选择表现；
- 角色性别、文化、宗教、法律身份和个人底线影响可见路线，但不把它们简化成固定禁止表。

## 4. 玩家可做的关系动作

- 交谈、倾听、道歉、解释、承诺、兑现、奖励、惩罚、委托、救援、送礼、邀请牌局、安排休假、撮合或分开；
- 玩家可以选择不发展恋爱关系；所有关系路线都服务船员社会，不替代核心航海玩法。

## 5. Agent 边界

Agent 生成角色表达、提议和情绪；CrewSystem 写关系数值；QuestSystem 写任务旗标；EconomySystem 写工资和礼物成本；FactionSystem 写法律/势力后果。

## 6. 验收

一次拖欠工资影响忠诚，一次救援影响信任，一次公开偏袒影响嫉妒；玩家可以在关系面板看到原因，而不是只看到一个没有解释的数值。
