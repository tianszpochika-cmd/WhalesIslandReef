# 岛屿经营、土地与治理

## 1. 玩法定位

岛屿经营是长线沙盒终局，不是简单建造菜单。玩家必须同时处理土地权利、人口、物资、建筑、劳力、势力、生态、治安和债务。

## 2. 取得方式

玩家可以通过以下方式获得经营权：

- 购买合法产权；
- 接受势力授予或特许；
- 继承、赎回或偿还旧债；
- 与地方社群签订共同管理协议；
- 发现无人管理的小岛并完成登记；
- 战争或冲突后接管，但会产生法律和外交后果。

不能用一笔钱直接把有居民的土地变成玩家私产。已有社群必须进入协商、租赁、合作或冲突状态。

## 3. 建设层级

| 层级 | 建设 | 作用 |
|---|---|---|
| 生存 | 水井、仓库、住房、诊所、粮仓 | 人口和资源安全 |
| 生产 | 农地、果园、牧场、渔场、木材场 | 食物、材料和商品 |
| 工业 | 工坊、磨坊、制糖、腌制、船坞 | 加工和维修 |
| 社会 | 市场、酒馆、学校、教堂、会所 | 关系、技能和文化 |
| 防御 | 瞭望塔、炮台、城墙、警卫所 | 海盗、战争和治安 |
| 航运 | 码头、泊位、灯塔、仓储、海关 | 船队和贸易 |

## 4. 经营循环

```text
取得经营权 → 勘察地形/水源/资源 → 规划土地
→ 建造设施 → 招募或协商劳力 → 生产与消费
→ 处理税、工资、维护和治安 → 参与势力关系
→ 扩大、出租、出售或放弃资产
```

## 5. 关键数据

- `IslandEstate`：岛屿、产权类型、共同体协议、估值、税率、债务、控制者；
- `LandParcel`：地块用途、肥力、水源、坡度、生境、所有者、租约；
- `PopulationState`：人口、家庭、职业、迁入迁出、健康、满意度、法律身份；
- `BuildingInstance`：建筑、等级、损伤、工人、库存、产出、开放状态；
- `PolicyState`：税、采集限额、宗教安排、贸易限制、治安和保护区；
- `IslandLedger`：收入、支出、工资、维护、贷款、保险和库存。

## 6. 经营选择

- 高税收换取快速建设，但降低满意度和迁入；
- 保护红树林和暗礁，短期少收入，长期提高鱼群与防风暴能力；
- 发展种植园或采矿，获得出口收入，但增加劳资、疾病和生态压力；
- 与地方社群共同治理，建设速度较慢，但获得知识、信任和稳定交易；
- 建造船坞和仓库，提升航运能力，但需要持续维护和防御。

## 7. 失败和恢复

- 欠薪：工人停工、离开或要求谈判；
- 缺水缺粮：健康下降、迁出、价格上涨；
- 过度开发：土壤下降、鱼群减少、风暴损失增加；
- 治安失败：盗窃、走私、火灾、海盗袭击；
- 债务违约：资产冻结、强制拍卖、势力介入；
- 经营者离岛：指定代理人继续运行，不能暂停世界。

## 8. 唯一写者与验收

IslandSystem 写产权、地块和政策；BuildingSystem 写建筑状态；PopulationSystem 写人口；EconomySystem 写账本；EcologySystem 写环境状态；FactionSystem 写法律和控制权。

验收：玩家能购买一块农地、建水井和仓库、种下一季蔬菜、支付工人工资、卖出收成，并在保存/读档后保持所有状态。
