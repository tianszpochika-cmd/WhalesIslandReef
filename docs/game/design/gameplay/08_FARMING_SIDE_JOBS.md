# 种植、果园、牧场、养殖与副业

## 1. 种植循环

```text
获取土地/租约 → 选择种子与季节 → 整地、播种、浇水
→ 分配劳力 → 应对病虫害、旱涝和风暴 → 收获
→ 鲜食、加工、储存、交易或供给船员 → 土地恢复/轮作
```

种植对象包括蔬菜、柑橘、香蕉、菠萝、甘蔗、烟草、咖啡、可可、香料、药草和染料植物。每种作物要有气候、土壤、水、时间、劳力、产量、易腐和市场标签。

## 2. 果实与蔬菜采集

- 野生果实：可直接采集，但有识别、毒性、成熟度和保护区规则；
- 果园：投入苗木、土地和工人，产出稳定但需要维护；
- 蔬菜：周期短，适合船员补给和港口市场；
- 过度采集：降低恢复、影响动物、引起社群冲突和价格上涨。

## 3. 饲养与牧场

第一版支持猫狗宠物和少量家禽/牲畜经营，不做复杂繁殖模拟。动物有来源、饲料、饮水、健康、产物、空间和疾病字段。产物包括蛋、奶、皮革、肉、肥料和运输服务。

## 4. 副业目录

| 副业 | 入口 | 主要资源 | 主要风险 |
|---|---|---|---|
| 渔夫 | 渔村/鱼场 | 渔具、船位 | 风暴、过捕 |
| 向导 | 部落/探险家 | 地图、语言 | 迷路、误导 |
| 打捞者 | 船坞/沉船 | 绳索、潜水浅滩工具 | 船损、法律 |
| 货运承包 | 商会 | 船舱、信用 | 延误、违约 |
| 护航 | 势力/商队 | 战斗船、声望 | 海盗、外交 |
| 药草师 | 诊所/社群 | 植物识别、工具 | 毒物、误采 |
| 制图者 | 航海家/海关 | 测深、观测 | 假情报、天气 |
| 船匠 | 船坞 | 木工、材料 | 事故、工期 |
| 酒馆经营者 | 酒馆/租约 | 现金、食物、关系 | 斗殴、债务 |
| 农场经营者 | 岛屿地块 | 种子、劳力、水 | 病虫害、战争 |

副业不是独立职业锁定。玩家可以在航程之间切换，但时间、资产、技能和船员安排会制造机会成本。

## 5. 验收

玩家能种下一批蔬菜并在下一季收获；能因缺水减产；能把收成加工成船员食物或商品；能接受一份副业后因为航程延误而承担违约后果。
