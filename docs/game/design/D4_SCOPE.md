# D4 内容扩充范围冻结

> 状态：D4-01 已冻结，D4-01 至 D4-10 已完成｜日期：2026-08-09

## 1. 目标

D4 在 D3 的贸易与航程底座上补齐三条可走通的路线：

`商人（势力/贸易） → 私掠者（炮战/通缉） → 探险家（动物/医疗/主线）`

本阶段仍采用确定性强逻辑和灰盒表现。LLM 只负责未来的台词、日志摘要和谈判语气，不负责任何数值、命中、疾病、声望或剧情条件裁决。

## 2. 本阶段交付

| 领域 | D4 交付基线 | 唯一写者 |
|---|---|---|
| 船型与改装 | 5 种船型；船体、风帆、炮位、医疗舱、厨房、住所 6 个改装槽 | `D4ShipyardSystem` |
| 炮战 | 实心弹/链弹/葡萄弹；距离、风向、炮手、命中、船体损伤；简化登船战 | `D4CombatSystem` |
| 势力 | 英、西、法、葡、海盗兄弟会、原住民、走私网络 7 个阵营 | `D4FactionSystem` |
| 干涉 | 声望等级、关税、港口通行、私掠证、禁运、登船检查、护航结算 | `D4FactionSystem` |
| 动物 | 15 种真实物种目录，觅食/警戒/攻击/繁殖提示四态 | `D4EcologySystem` |
| 疾病医疗 | 坏血病、疟疾、黄热病、痢疾、肺痨；健康、发作、治疗 | `D4SurvivalSystem` |
| 主线 | 3 章、9 个锚点任务；前 5 个任务教学航行/贸易/登岛/对话/战斗 | `D4MainlineSystem` |
| 航线日志 | 日期、起终点、事件、战斗、动物、疾病和任务进展自动记录 | `D4LogSystem` |
| 存档 | D4 快照写入既有 `location_json.d4`，旧 D1-D3 存档默认兼容 | `SaveSystem` 只序列化 |
| 服务端 | D4 开发态契约镜像，不取代客户端强逻辑 | `server/src/modules/d4` |

## 3. 明确不在 D4

- 真实多人联机、Steam Cloud、云端强裁决。
- 复杂物理断船、自由舱室摆放、实时接舷格斗小游戏。
- 最终美术、语音、本地化全量和 12 岛完整内容。
- 真实 LLM 生成数值结果；Agent 不能修改 D4 状态。

## 4. 数据所有权

1. `D4ShipyardSystem` 唯一裁决船型解锁、改装等级和改装成本。
2. `D4CombatSystem` 唯一裁决炮战命中、伤害、装填、登船结果和战利品提议。
3. `D4FactionSystem` 唯一裁决声望、战争/禁运/私掠证/通行与检查结果。
4. `D4EcologySystem` 唯一裁决动物状态、危险、观察和收藏结果。
5. `D4SurvivalSystem` 唯一裁决健康、疾病发作和治疗结果。
6. `D4MainlineSystem` 唯一裁决任务前置、章节推进和教学旗标。
7. `D4LogSystem` 只追加事实日志，不反向修改其他系统数值。
8. `SaveSystem` 只复制快照，不计算任何 D4 数值。

## 5. 验收门

- 纯 C#：船型/改装、三种炮弹、命中伤害、登船、七阵营、私掠/禁运/检查、15 种动物、5 种疾病、治疗、3 章任务、日志均有 EditMode 测试。
- Unity：InitialHarbor 显示 D4 HUD；能开启势力面板、升级船、开始炮战、开炮、观察动物、治疗船员、推进主线和保存。
- Server：D4 JSON Schema 与 OpenAPI 路由对应，`npm run build` 通过。
- 存档：D3 快照和 D4 快照同时保存/读取；D3 旧存档没有 D4 字段时正常进入默认 D4 状态。
- 运行时：Unity 脚本无编译错误，D4 冒烟检查入口、HUD、势力和主线对象均创建。
- 留痕：本文件、D4 任务表、验收报告、路线图、上下文和当日 memory 同步更新。
