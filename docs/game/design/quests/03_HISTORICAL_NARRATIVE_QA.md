# 历史叙事与任务验收

## 1. 历史规则

- 1675 年已有的制度、船型、势力和技术才能作为现实背景；
- 虚构角色不能冒充真实历史人物；
- 真实地点和公司要标注时间范围；
- 后世制度不能提前放入；
- 真实受压迫群体不能被简化成商品；
- 历史创伤提供内容警告和低强度选项。

## 2. 任务验收

- [ ] 每个主线任务有目标、准备、选择和后果；
- [ ] 任务有失败恢复；
- [ ] 任务不依赖 LLM 生成条件；
- [ ] 支线可以从多个玩法进入；
- [ ] 船员个人任务会使用关系和特质；
- [ ] 势力任务会读取声望和法律；
- [ ] 任务日志记录事实；
- [ ] 历史来源和虚构说明完整；
- [ ] 120 支线模板有目录而非空数字；
- [ ] 主线作者锚点经过独立审查。
