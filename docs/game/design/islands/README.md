# 岛屿与世界地貌设计

本目录专门存放 50 座岛屿、海域、地质、山地、河流、洞穴、海岸和自然档案。

规划文档：

- 01_ISLAND_OVERVIEW.md：50 座岛的分类、区域和自然档案；
- 02_GEOLOGY_TERRAIN.md：火山、石灰岩、珊瑚、冲积地貌和山地；
- 03_HYDROLOGY_CAVES.md：河流、泉眼、瀑布、洞穴、地下水和蓝洞；
- 04_COAST_REEF_MANGROVE.md：海滩、暗礁、红树林、海草床和泻湖；
- 05_ISLAND_CONTENT_PLACEMENT.md：建筑、资源、动物和任务的空间布置；
- 06_ISLAND_QA.md：导航、出生点、加载、性能和生态一致性。

状态：第一版设计已完成；岛屿经营和产权玩法另见 `../gameplay/02_ISLAND_MANAGEMENT.md`。
