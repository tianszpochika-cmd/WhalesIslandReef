# 地质、山地与地形

## 1. 四类基础地质

| 地质 | 形成的地貌 | 玩法影响 |
|---|---|---|
| 火山岩 | 火山锥、黑色砾滩、陡坡、熔岩管 | 矿物、滑坡、深水湾 |
| 石灰岩 | 峰林、落水洞、悬崖、地下河 | 洞穴、缺水、泉眼 |
| 珊瑚沉积 | 沙洲、环礁、低地、浅滩 | 海水入侵、潮汐、搁浅 |
| 冲积沉积 | 河口、湿地、泥滩、三角洲 | 洪水、红树林、渔场 |

## 2. 山地类型

- 火山锥与火山脊；
- 石灰岩峰林；
- 湿润云雾山；
- 背风干燥山脊。

每种山地要改变：

- 温度、风速和云雾；
- 能见度和远眺；
- 植物高度和动物分布；
- 道路坡度和滑坡；
- 采集、洞穴和资源。

## 3. 高度带

- 海岸带；
- 山麓带；
- 中山带；
- 高地或云雾带。

低岛可以映射为潮间带、沙脊、灌丛和灯塔高点。

## 5. 悬崖和坡地

悬崖分为海蚀悬崖、火山岩壁、石灰岩断崖和河谷崖。

每处必须有：

- 可观察但不可直接通行边界；
- 绕行、绳索或低潮替代路线；
- 落石、滑坡、强风或浪涌风险；
- 鸟巢、海蚀洞、瞭望点或隐藏水道。

不能让角色无条件爬上所有表面。
