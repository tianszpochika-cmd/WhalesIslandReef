# 岛屿世界总览

## 1. 数量目标

世界目标为 50 座岛。每座岛都必须是独立内容单元，不允许只换颜色和名字。

每座岛有：

- island_id；
- 中文名、英文名和历史称呼；
- 主地质；
- 主生境；
- 迎风面和背风面；
- 海岸类型；
- 淡水状态；
- 山地或高地；
- 洞穴、河流、泉眼和湿地；
- 植被和动物代表；
- 人类改造程度；
- 港口、村落、要塞或荒岛标签；
- 航海危险；
- 建筑和势力；
- 任务入口；
- 自然档案；
- 流式加载分区。

| 类型 | 数量 |

每座岛只有一个主地貌，但可以叠加次级地貌。

## 3. 岛屿三层空间

1. 海岸层：沙滩、礁区、浅海、红树林、码头和登陆；
2. 内陆层：村落、农地、河谷、道路、林地和资源点；
3. 高地或地下层：山脊、洞穴、峡谷、泉眼、遗迹和瞭望点。

低矮沙洲没有高地时，用沙脊、泻湖、礁口和潮间带形成变化。

## 4. 自然档案

自然档案必须回答：

- 岛为什么形成；
- 水从哪里来；
- 哪些区域迎风、潮湿或干旱；
- 玩家如何登陆和离开；
- 主要危险是什么；
- 动物和植物为什么出现在这里；
- 人类如何改造或保护它；
- 风暴、火灾和玩家行为后怎样恢复。

## 5. 岛屿可玩闭环

每座重点岛至少有：

观察海域 → 选择登陆点 → 获取淡水或资源 → 遇见 NPC/动物/环境风险 → 完成交易、探索或任务 → 修理补给 → 离岛并留下世界变化。
