# 岛屿与地貌验收

## 1. 世界数量

- [ ] 50 座岛有唯一 ID；
- [ ] 主地貌数量符合配额；
- [ ] 海域分区有导航意义；
- [ ] 目标自然结构有目录和状态。

## 2. 地貌一致性

- [ ] 地质、土壤、植被和水文相互一致；
- [ ] 山地高度影响雾、温度、风和动物；
- [ ] 河流有水源和流向；
- [ ] 洞穴有入口、出口或明确的封闭原因；
- [ ] 暗礁与吃水和海图相连。

## 3. 可玩性

- [ ] 每座重点岛至少有两条路线；
- [ ] 登陆点有风险提示；
- [ ] 淡水和补给状态可理解；
- [ ] 资源采集有恢复；
- [ ] 失败可以绕行或恢复。

## 4. 工程

- [ ] 岛屿按流式分区加载；
- [ ] 自然区域有稳定边界；
- [ ] 角色、船、动物、植被碰撞不互相破坏；
- [ ] 存档可以恢复岛屿状态；
- [ ] 运行时不依赖 LLM 生成地貌或资源数值。
