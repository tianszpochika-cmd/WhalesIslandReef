# 河流、淡水、洞穴与地下水

## 1. 水文目标

世界目标：

- 河流和季节性水道 100 条以上；
- 淡水泉、泉眼和可饮水点 80 处以上；
- 瀑布、水潭和溪流汇合点 40 处以上；
- 湿地、泻湖和潮汐湖 40 处以上；
- 洞穴、海蚀洞、熔岩管和落水洞 60 处；
- 大型洞穴网络 18 个。

## 2. 河流链

上游 → 中游 → 河口或季节性终点。

每条河定义：

- 水流方向；
- 流速；
- 深浅；
- 可涉水点；
- 岸线冲刷；
- 雨季涨水；
- 旱季断流；
- 洪水泥沙；
- 饮水、洗涤、灌溉、捕鱼；
- 河口盐度变化；
- 疾病和污染风险。

## 3. 淡水

淡水点有：

- 容量；
- 水质；
- 恢复速度；
- 旱季修正；
- 污染状态；
- 附近植被；
- 附近动物；
- 玩家取水和社区管理。

过度取水或污染可以造成短期后果，但第一版不做无法恢复的整岛毁灭。

## 4. 洞穴类型

- 石灰岩干洞 32 个；
- 海蚀洞 12 个；
- 火山熔岩管 8 个；
- 落水洞与蓝洞 8 个。

其中 18 个为大型洞穴网络。

## 5. 洞穴分区

- 入口缓冲区；
- 暮光区；
- 黑暗区；
- 水层；
- 生物区；
- 地质区；
- 历史痕迹区；
- 出口区。

## 6. 洞穴危险

- 潮汐浪涌；
- 落石和塌方；
- 烟雾和空气质量；
- 蝙蝠惊扰；
- 湿滑跌倒；
- 地下水污染或盐化；
- 迷路和照明消耗。

第一版不要求复杂水下洞穴潜水。
