D18-A06 Poly Haven license evidence snapshot
Retrieved: 2026-08-14

Official license page: https://polyhaven.com/license
Official asset pages are recorded per item in polyhaven_selected_assets.json.

The official license page identifies the downloadable HDRIs and textures as
CC0 assets. This task only downloaded the explicitly listed 1K files from the
official Poly Haven CDN/API. Site branding, preview pages, thumbnails and
metadata are not treated as asset licenses. The project keeps local SHA-256
records for every downloaded file and does not infer license status for any
unlisted URL.
