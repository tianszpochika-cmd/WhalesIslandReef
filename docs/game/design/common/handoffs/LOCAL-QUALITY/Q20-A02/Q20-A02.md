# Q20-A02 交接：D26 直挂 legacy palm placeholder Renderer 隔离

## 状态

`PASS_WITHIN_SCOPE`（2026-09-11）。本卡只关闭 D26 表现层中直接挂在场景根的 `ph_palm_tree` 遗留 Renderer 路径；父卡 `Q20` 仍为 `PARTIAL/BLOCKED_ASSET`。

## 根因与修改

Unity Pipeline 在当前 `InitialHarbor` PlayMode 之前的只读运行时检查发现 5 个直接场景根 `ph_palm_tree`，其中样本 Renderer bounds 的 `min.y=0.280`，对 R03 自有地形命中分别出现 `0.088m` 和 `0.292m` 的高度差，另外 3 个根没有自有地形命中。D26 原来只找 `D19_SaintMargaret_Root`，因此不能保证这批旧占位树在运行时被隔离。

本卡最小修改：

- `D26HarborEnvironmentRuntime.DisableLegacyTreeRenderers()` 继续扫描每个场景根的 Transform 子树，并同时处理 `D19_SaintMargaret_Root` 与 `ph_palm_tree`；
- Q26/A03 的审计识别直接根和嵌套根下的 `ph_palm_tree`、`ph_trunk`、`ph_leaf`；
- 不修改地形、Collider、NavMesh、Systems、玩法状态、Prefab 正式棕榈准入或 `RenderAuthoredPalms=false`。
