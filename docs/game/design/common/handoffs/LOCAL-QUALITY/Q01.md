## 关键变换事实

- `D2_PlayerAvatar` 由 `D2RuntimeBootstrap` 实例化，出生位置读取 `D2_PlayerSpawnAnchor`，物理组件在同一根上；`D2CharacterController` 将根尺度归一化为 `Vector3.one`。
- `HumanoidVisual`/导入视觉根由 `D2CharacterAnimationController.FindVisualRoot()` 选择。D2 动画控制器在 `Update` 写 root 姿态；`D7CharacterPresentationController` 在 `LateUpdate` 以 0.08m 阈值修正 root 的局部位置。这是 Q02 首要风险。
- 当前场景 `ph_ship_fishing` 是稳定 gameplay root，位置 `(0,0,-5.2)`、统一 scale `2.573956`。序列化锚点为：
  - `D2_PlayerSpawnAnchor.localPosition=(0,0.42735776,0.9712676)`，对应 builder 的 world offset `(0,1.1,2.5)`；
  - `D2_DisembarkAnchor.localPosition=(0,0,1.7482817)`，对应 builder 的 world offset `(0,0,4.5)`。
- 可见船体不是 boarding owner：`D19_R03_ShipVisualInstance` 是 stable root 的表现子节点，使用 world berth offset `(0,0,-3.6)` 转换后的 local offset和 inverse root scale。
- `D19_TerrainRoot` 的 MeshCollider 在 presentation root 下以零位/单位缩放生成；岛面 `Height()` 在港湾低地使用约 0.035m/0.08m 基准高度，不能用固定平面假定岸线。
- 逻辑海面由 `OceanAdapter` 提供：默认 fallback 为 `-0.05m`，当前 D17 日志记录为 `-0.02m`；水面碰撞体被禁用，游泳状态由 D2 角色控制器和行走面恢复判定共同决定。
