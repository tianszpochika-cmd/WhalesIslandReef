日期：2026-09-12

## 本卡处理的问题

`HarborInteractionStabilizer.ReconcileNavigationPolicy` 原来的 early return 只比较了 `EventSystem.sendNavigationEvents` 和缓存的策略状态。另一个 UI owner 如果把 `InputSystemUIInputModule.move` 重新接回 `UI/Navigate`，但没有改变 `sendNavigationEvents`，策略会误以为状态已经正确，导致游戏态 W/S 仍可能被 HUD 导航消费。

本卡只在 UI 输入 owner 内修复：early return 现在同时要求 `InputSystemUIInputModule.move` 与当前策略一致。游戏态预期为 `sendNavigationEvents=false` 且 `move=null`；发现 move action 被外部恢复后，会重新执行策略并清除它。没有修改 Systems、D2 数值裁决、AgentCore、场景或资源。
