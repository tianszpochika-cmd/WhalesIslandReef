## 3. 视觉与边界冻结

- 总方向：统一风格化低多边形、可信比例、清晰光照与反馈；不追求照片级写实。
- 玩家模式不显示实体 ID、LOD、碰撞框、日志、Profiler 或候选状态；开发调试模式必须有 `DEBUG / 本地开发` 水印，且只读。
- 表现层不写天气、关系、任务、生态、奖励、存档和经济事实；UI/Agent 不成为实体唯一写者。
- LOD、对象池、流式加载和音频卸载只能降级表现/刷新频率，不能跳过事实、事件游标或存档。
- `ReleaseApproved` 只能由责任人类审核者签署。Agent 可以整理证据，不能代签。
