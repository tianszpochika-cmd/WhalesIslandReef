# 世界时间、天气与状态基础

## 1. 世界时钟

世界时钟至少记录：

- 年、月、日；
- 小时、分钟；
- 白昼阶段；
- 月相；
- 季节或干湿季；
- 当前海域；
- 世界事件队列；
- 最近一次存档时间。

1675 年是固定历史起点，玩家世界的日期可以向后推进，但不能把现代制度、科技和国家名称提前写入早期世界。

## 2. 时间尺度

| 尺度 | 用途 |
|---|---|
| 秒 | 动画、操舵、装填、交互 |
| 分钟 | 船员工作、天气变化、船体状态 |
| 小时 | 航程、轮班、市场、NPC 日程 |
| 天 | 食物、疾病、施工、任务和日志 |
| 周 | 价格、迁徙、战争压力、季节活动 |
| 月 | 船厂供应、宗教节期、远洋路线和历史事件 |

## 3. 天气状态

天气至少包含：

- 晴朗微风；
- 多云；
- 阵雨；
- 持续降雨；
- 强风；
- 雷暴；
- 雾；
- 热湿闷热；
- 干旱高温；
- 风暴前兆；
- 飓风影响；
- 风暴恢复期。

每种天气要定义风、雨、云、能见度、浪、流、温度、疾病、火灾、动物和植被反应。

## 4. 预警链

大型天气事件必须经历：

常态 → 迹象 → 预警 → 影响 → 恢复。

迹象包括：

- 云层和光照；
- 风向变化；
- 海鸟和鱼群；
- 气压或船员经验报告；
- 港口旗语；
- 海面颜色和浪型；
- 雨幕、雷声和远处闪电。

## 5. 状态机原则

每个状态必须定义：

- 进入条件；
- 持续条件；
- 离开条件；
- 每小时或每天效果；
- 玩家可见反馈；
- 玩家干预；
- 失败恢复；
- 存档字段。

## 6. 随机性

随机必须有种子或可复盘记录：

- 世界种子；
- 事件种子；
- 天气种子；
- 刷新种子；
- 掉落种子。

同一存档在相同输入下，应能复现关键逻辑结果。
