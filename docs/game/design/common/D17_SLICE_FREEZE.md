## 1. 业务切片边界
- **场景/港口**: `InitialHarbor` / 圣玛格丽特（圣玛丽港口区）
- **玩家实体**: `D2_PlayerAvatar`（挂载 Quaternius CC0 Male_Peasant 真实布衣水手网格，非方块人）
- **船只实体**: `ph_ship_fishing` / `ship_small` 小型风帆工作船
- **基础行走面**: `BeachGround`（圣玛丽沙滩）、`DockGround`（主码头平台）、`PierGround`（小艇泊位）
- **闭环故事流程**: 出生落地 -> 港口与沙滩移动/跳跃 -> 走向码头 -> E 键平滑登船 -> 离岸操船与视角调整 -> Esc 暂停/继续 -> F5 存档与主菜单重载 -> 下船回到安全地面 -> 重启恢复

## 2. 输入与交互矩阵
- **键盘/鼠标**: WASD 移动，Shift 奔跑，Space 跳跃，E 上下船交互，右键/中键镜头旋转，滚轮缩放，Esc 呼出暂停菜单（锁定玩法输入），F5 快速保存
- **手柄支持**: 左摇杆移动，右摇杆视角，A/跨平台确认键交互，Start 暂停
