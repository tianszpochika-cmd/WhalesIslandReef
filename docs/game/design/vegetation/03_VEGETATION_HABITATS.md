# 植被生境设计

## 1. 十类主要生境

| 生境 | 主要层级 | 玩法 |
|---|---|---|
| 海滩与沙丘 | 海滨草本、低灌木、耐盐植物 | 海龟产卵、采集、风暴侵蚀 |
| 红树林与盐沼 | 根系、灌木、潮湿底层 | 潮汐航道、鱼苗、木材、药材 |
| 干旱灌丛与仙人掌地 | 荆棘、肉质植物、稀疏乔木 | 缺水、生火、毒性、远眺 |
| 低地季雨林 | 中低层乔木、藤本、灌木 | 木材、果实、遮蔽、泥泞 |
| 湿润热带雨林 | 高冠层、乔木、藤本、蕨类 | 迷路、药材、昆虫、疾病 |
| 云雾森林 | 苔藓、蕨、矮树、附生 | 低能见度、稀有植物、湿滑 |
| 河岸与湿地 | 芦苇、棕榈、湿地草本 | 饮水、捕鱼、蚊虫、洪水 |
| 石灰岩林与喀斯特灌丛 | 浅土、耐旱树、岩缝植物 | 洞穴、缺水、攀爬、鸟巢 |
| 火山岩坡与次生林 | 岩缝草木、先锋植物 | 滑坡、矿物、恢复演替 |
| 农地、种植园与废弃地 | 作物、果树、杂草、次生林 | 劳动、贸易、疾病、土地冲突 |

## 2. 生境最低字段

每个 HabitatDef 至少有：

- habitat_id；
- island_region；
- geology；
- soil；
- moisture；
- salinity；
- altitude；
- canopy_density；
- visibility；
- walkability；
- fire_risk；
- disease_risk；
- plant_spawn_tags；
- animal_spawn_tags；
- resource_tags；
- weather_reactions；
- human_impact；
- recovery_profile。

## 3. 岛屿分配

每座中大型岛至少 8—12 个自然区域，小型岛至少 3—5 个自然区域。

每座岛必须包含：

- 一个主生境；
- 至少两个次生境；
- 海岸与内陆过渡；
- 淡水或明确缺水说明；
- 一处人类改造或自然演替区域；
- 一处有代表性的植物资源；
- 一处不适合玩家进入的生境边界。

## 4. 生境边界

生境边界通过以下信号让玩家理解：

- 土壤颜色；
- 岩石类型；
- 树冠高度；
- 湿度和雾；
- 鸟虫声音；
- 植物密度；
- 水线和潮痕；
- 角色脚步和泥水；
- UI 地图标签。

不能只靠突然换贴图让玩家知道进入了新生境。
