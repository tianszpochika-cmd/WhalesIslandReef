# 植被动态与恢复

## 1. 天气反应

### 风

- 草、藤、棕榈叶和树冠按风速摆动；
- 强风会掉落果实、树枝和枯叶；
- 风暴会造成断枝、倒树和红树林局部损伤；
- 风向改变火灾传播方向和种子扩散。

### 雨

- 叶面出现水珠；
- 泥地和溪流变化；
- 湿地动物出现率提高；
- 蘑菇、苔藓和潮湿植物短期活跃；
- 火把和火源更容易熄灭。

### 干旱

- 叶片枯黄；
- 果实减少；
- 动物向水源聚集；
- 火险提高；
- 灌木和草地进入低恢复状态。

## 2. 玩家影响

玩家砍伐、采集、放火、踩踏、放牧和耕作会产生：

- 空地；
- 树桩；
- 脚印；
- 采集痕迹；
- 倒木；
- 新的次生草本；
- 动物路线改变；
- 火险变化。

普通植被不应瞬间消失或瞬间刷新。

## 3. 采集恢复

恢复由：

- 植物类型；
- 季节；
- 降雨；
- 土壤；
- 采集强度；
- 附近母株；
- 动物活动；
- 玩家保护或破坏；
- 人类管理方式决定。

分级：

- 快速：草、果实、低级药草；
- 中速：灌木、藤本、幼苗；
- 慢速：树木、红树林、海草床；
- 特殊：农作物按种植周期，风暴损伤按恢复事件。

## 4. 火灾

火灾需要同时满足：

- 可燃物密度；
- 干旱；
- 风；
- 火源；
- 隔离条件。

火灾影响：

- 植被死亡；
- 动物逃离；
- 土壤和视线改变；
- 资源短期增加或减少；
- NPC 迁移和任务；
- 次生植被恢复。

第一版不要求永久烧毁整座岛。

## 5. 农地与次生林

农地废弃后按：

草本 → 灌木 → 幼树 → 次生林 → 稳定生境

逐步恢复。恢复速度受降雨、土壤、火灾、放牧、砍伐和附近种源影响。
