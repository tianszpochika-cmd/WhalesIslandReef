# 植被设计

本目录专门存放树木、灌木、草本、藤本、农作物、海滨植物、红树林、海草和植物动态。

规划文档：

- 01_VEGETATION_OVERVIEW.md：植被层级、数量口径和生境关系；
- 02_VEGETATION_CATALOG.md：1,000—2,000 个植被条目和唯一 ID；
- 03_VEGETATION_HABITATS.md：雨林、灌丛、湿地、海岸、农地和喀斯特；
- 04_VEGETATION_DYNAMICS.md：风、雨、旱季、风暴、火灾和恢复演替；
- 05_VEGETATION_INTERACTION.md：采集、药材、木材、食物、毒性和经济；
- 06_VEGETATION_PRESENTATION_QA.md：模型、材质、LOD、风场和性能。

状态：第一版设计已完成；种植、果园、蔬菜和副业另见 `../gameplay/08_FARMING_SIDE_JOBS.md`。
