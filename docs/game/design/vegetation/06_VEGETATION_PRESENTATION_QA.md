# 植被表现、性能与验收

## 1. 资产层级

每类植被至少有：

- 远景轮廓；
- 中景群落；
- 近景单株；
- 可交互实例；
- 枯萎、采集、风暴损伤和恢复变体；
- 季节或天气材质变化。

## 2. 材质

至少区分：

- 湿叶；
- 干叶；
- 沙地；
- 泥地；
- 盐碱；
- 岩缝；
- 火烧；
- 枯木；
- 海水浸泡；
- 农作物成熟阶段。

## 3. 风场

风场按区域分：

- 海滩强风；
- 红树林低位风；
- 雨林冠层风；
- 山脊阵风；
- 洞穴无风或回流；
- 农地开阔风。

不同层的摆动频率和幅度不能完全一致。

## 4. 性能

- 远景使用群落代理；
- 中景使用 GPU Instancing 或对象池；
- 近景才启用碰撞和采集；
- 只有可见或附近区域启用高级风动；
- 植被碰撞按道路、交互点和边界分层；
- 采集状态不为每株植物保存独立高成本对象；
- 50 座岛流式加载时控制植被激活数量。

## 5. 验收

- 1,000—2,000 个条目有目录，而不是只写一个总数；
- 十类生境至少都有可运行样例；
- 植物用途和生境一致；
- 风、雨、旱、火灾和采集会改变表现；
- 普通植物能恢复，剧情植物有明确锁定说明；
- 采集、毒性、工具、库存和经济链路可回溯；
- 没有错误生境刷新；
- 近景无严重穿模，远景无明显跳变；
- 1080p 目标性能不被植被数量破坏。
