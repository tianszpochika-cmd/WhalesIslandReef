# 植被交互、资源与玩法

## 1. 玩家动作

- 观察；
- 识别；
- 采集；
- 砍伐；
- 挖掘；
- 种植；
- 浇水；
- 生火；
- 制药；
- 制作绳索或纤维；
- 烹饪；
- 交易；
- 标记位置；
- 保护或限制采集。

## 2. 资源输出

植物可以输出：

- 食物；
- 淡水过滤材料；
- 药材；
- 毒物；
- 木材；
- 树脂；
- 纤维；
- 染料；
- 香料；
- 燃料；
- 建筑材料；
- 船坞材料；
- 宗教或文化用途物品。

资源产出由成熟度、采集部位、工具、技能、天气和稀有度决定。

## 3. 工具要求

| 行为 | 工具 | 失败后果 |
|---|---|---|
| 拾取果实 | 无或篮子 | 数量少、掉落 |
| 采集药草 | 小刀或药草包 | 损伤植物、误采毒物 |
| 砍灌木 | 砍刀 | 体力和耐久消耗 |
| 砍树 | 斧、木工工具 | 噪音、倒树、受伤 |
| 采集树脂 | 刮刀和容器 | 母株损伤 |
| 采集海草 | 小刀和浅水工具 | 潮位和水流风险 |
| 种植 | 种子、锄具、水 | 成活率和季节限制 |

## 4. 识别与误采

玩家可以通过：

- 角色技能；
- 船员建议；
- 图鉴；
- 气味、颜色和叶形；
- 社群知识；
- 任务线索识别。

误采毒物、过度采集和破坏保护区会产生健康、法律、声望或生态后果。

## 5. 保护与交易

不同港口可能有：

- 木材禁伐；
- 药材专营；
- 宗教植物禁采；
- 红树林保护；
- 种植园产权；
- 原住民社群管理；
- 港口商会收购协议。

玩家可以选择短期利润或长期资源恢复。

## 6. 边界

植被系统唯一写：

- 植物成熟度；
- 采集状态；
- 生境资源量；
- 恢复时间；
- 植被损伤。

库存由 Inventory/Cargo 系统写入，经济价格由 EconomySystem 写入，任务只读取结果。
