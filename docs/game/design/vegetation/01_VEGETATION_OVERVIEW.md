# 植被系统总览

## 1. 植被不是装饰

植被同时承担：

- 地貌识别；
- 生态栖息地；
- 资源来源；
- 视线和声音遮挡；
- 角色路线与天气保护；
- 农业和经济；
- 火灾、疾病和恢复；
- 岛屿历史足迹。

## 2. 数量口径

目标为 1,000—2,000 个植被内容条目，其中：

- 150—200 个基础植物模型；
- 250—400 个树木、棕榈、灌木和藤本变体；
- 180—300 个草本、蕨类、苔藓、附生植物和地被；
- 120—200 个海滨、盐沼、红树林和湿地条目；
- 100—160 个农作物、果树、香料和废弃地植物；
- 80—140 个药用、染色、纤维、有毒或特殊用途植物；
- 其余为枯木、落叶、树桩、漂流木、种子、花果、病害和采集阶段。

条目不等于场景实例。一个模型可以有多个经过审核的内容条目和数千个放置实例。

## 3. 六层植被

1. 冠层：远景轮廓、遮阴、鸟巢和雨水截留；
2. 中层乔木：木材、果实、藤本支撑和动物路线；
3. 灌木层：视线阻挡、药材、毒性和小型动物；
4. 地被层：脚步声、泥水、昆虫和采集；
5. 藤本与附生层：雨林垂直度、遮路和洞口；
6. 潮湿或水生层：芦苇、浮萍、海草、藻类和红树林幼苗。

## 4. 植物标签

每个条目必须有：

- 生境；
- 土壤；
- 耐盐；
- 耐旱；
- 需水量；
- 海拔；
- 季节；
- 成熟期；
- 采集部位；
- 食用、药用、木材、纤维、染料、香料、毒性或燃料用途；
- 本地、引入、种植园或废弃地逃逸标签；
- 是否影响动物、疾病和火灾。

## 5. 植被和世界链路

地质决定土壤，土壤决定植物，植物决定动物，动物和玩家活动决定资源压力，天气决定短期状态，历史聚落决定农业和次生林。

不能把所有岛都铺同一种椰树、草和棕榈。
