# 船舶设计目录

本目录是项目船舶设计的唯一专题入口。旧的 `SHIP_DESIGN.md` 已移入历史归档。

## 文档顺序

1. 01_SHIP_VISION.md：船舶身份、原则、边界和阶段范围；
2. 02_SHIP_TYPES.md：20 种船体类型、用途、优势、短板和开放顺序；
3. 03_HULL_LAYOUT.md：船体结构、尺寸、舱室、甲板和碰撞；
4. 04_FUNCTION_POINTS.md：60 个船上功能点和状态；
5. 05_MODULES_REFIT.md：80 个改装模块、等级、代价和互斥；
6. 06_SAILING_OPERATIONS.md：操帆、舵位、航速、岗位、轮班和 P2A；
7. 07_ANCHORING_MOORING.md：锚、锚链、走锚、缆绳、泊位和小艇；
8. 08_DAMAGE_REPAIR.md：破损、进水、倾斜、火灾、断帆和沉船；
9. 09_SHIPYARD_ECONOMY.md：船坞、材料、工期、旧船、声望和订单；
10. 10_SHIP_DATA_MODEL.md：船型、实例、模块、舱室、功能点和存档；
11. 11_SHIP_PRESENTATION_QA.md：模型、动画、声音、UI、性能和验收。

## 当前事实

- D4 已实现 5 种简化船型、6 个改装槽和 0—3 级改装；
- D7 已实现舵位、上下船、甲板状态和控制权切换；
- M4—M5 目标是 20 种船体、80 个改装模块、60 个功能点；
- 本目录文档已经完成第一层设计，但不代表代码和资产已经全部实现。
