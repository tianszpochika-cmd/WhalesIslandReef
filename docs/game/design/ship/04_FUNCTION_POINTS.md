# 船上功能点目录

## 1. 功能点定义

功能点是船上可以被玩家、船员、系统或事件识别的具体位置。它不是抽象槽位，必须有：

- 唯一 ID；
- 所属舱室；
- 交互锚点；
- 适用船型标签；
- 占用空间；
- 所需船员岗位；
- 所需材料或工具；
- 可用、拥堵、损坏、进水、着火、缺员等状态；
- 对船体、航行、贸易、战斗或生活的影响。

60 个功能点是全局目录目标。每种船只只启用其中一部分。

## 8. 功能点状态

| 状态 | 说明 |
|---|---|
| 可用 | 可以正常交互和分配岗位 |
| 拥堵 | 人员或货物过多，效率下降 |
| 缺员 | 没有对应岗位人员，自动效率降低 |
| 缺材料 | 任务可以登记，但不能完成 |
| 损坏 | 需要船员维修或进入船坞 |
| 进水 | 功能可能降级或暂时关闭 |
| 着火 | 先灭火，再恢复功能 |
| 封闭 | 舱门关闭、防火或隔离导致不可用 |
| 被占用 | 其他改装、货物或任务占用空间 |

## 9. 船型兼容

- 独木舟不启用炮位、货舱、医务室和船坞级功能；
- 小渔船启用基础舵、单帆、锚、鱼舱、简易货舱和小艇；
- 单桅纵帆船启用海图桌、炮位、厨房、住所和基础医疗；
- 商船启用大型货舱、装货吊杆、绞盘和多个水舱；
- 军舰启用炮甲板、火药库、接舷网、军用瞭望台和战斗生活区；
- 改装可以增加功能点，但必须受空间、重量、吃水和船员限制。

## 10. 验收

- 60 个点全部有唯一 ID；
- 3 个样板船型能正确显示各自功能点；
- 每个功能点能被地图、船舶 UI 或船员报告识别；
- 功能点损坏、进水、着火和缺员能影响结果；
- 功能点状态可保存和恢复；
- 不允许由 Agent 直接写入功能点状态。
