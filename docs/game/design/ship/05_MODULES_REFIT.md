# 船舶改造与改良模块

## 1. 四种船务操作

| 操作 | 目的 | 是否改变结构 | 典型地点 |
|---|---|---:|---|
| 维修 | 恢复损坏能力 | 否 | 船上、修船棚、船坞 |
| 改造 | 安装或替换功能 | 是 | 船坞、专业工坊 |
| 改良 | 提升模块等级 | 可能 | 船坞、势力船厂 |
| 装饰 | 改颜色、旗帜、船名和纹章 | 否 | 港口、船坞 |

改造和改良必须带来取舍。增加医务区会减少货舱，增加火炮会增加重量和船员需求，增加淡水舱会减少货物空间，浅吃水改造可能降低抗浪能力。

## 2. 等级规则

- 0 级：船型基础状态；
- 1 级：普通港口工坊；
- 2 级：专业船厂或势力港；
- 3 级：稀有图纸、优质材料或关键任务。

每个模块必须记录等级、条件、耐久、磨损、安装日期、维修日期、是否可拆和互斥模块。

## 11. 安装前提示

安装模块前必须显示：

- 占用哪个功能点或舱室；
- 增加多少重量、吃水和人员需求；
- 改变哪些航速、转向、货舱、炮位或生存属性；
- 需要什么材料、资金、港口等级、声望或图纸；
- 与哪些模块互斥；
- 是否改变模型、声音和交互；
- 是否可拆除，拆除返还什么。

## 12. 模块验收

- 80 个模块全部有唯一 ID；
- 8 个类别各 10 个；
- 每个模块有收益、代价、材料、等级和兼容关系；
- 不能通过连续安装模块让所有属性无代价达到最高；
- 模块损坏、维修、拆除和存档均可追踪；
- Agent 不能直接安装、升级或修改模块。
