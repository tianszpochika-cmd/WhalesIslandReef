# 船体损伤、火灾、维修与沉船

## 1. 损伤模型

船体不能只有一个血条。至少同时记录：

- 结构耐久；
- 船壳破损位置；
- 舱室进水量；
- 左右倾斜角；
- 舵损；
- 桅杆和索具状态；
- 帆具状态；
- 火灾和烟雾；
- 火药安全状态；
- 货物受潮和滑动；
- 船员伤亡、疲劳和岗位缺员。

## 2. 损伤阶段

| 阶段 | 表现 | 主要后果 | 处理 |
|---|---|---|---|
| 轻微擦伤 | 木屑、漏水声、外板划痕 | 维护压力上升 | 航后普通维修 |
| 局部破损 | 舱壁漏水、速度下降 | 需要木工、桶和工具 | 航行中堵漏 |
| 严重进水 | 舱底水位上升、船体下沉 | 货物受潮、船员疲劳 | 抽水、堵漏、减载 |
| 舵或索具损坏 | 转向迟钝、不能有效调帆 | 避礁和战斗困难 | 木工或船坞 |
| 结构危险 | 倾斜明显、物品滑动 | 人员落海、点位失效 | 降帆、避浪、抢修 |
| 沉船临界 | 进水无法控制、结构失稳 | 船员和货物损失 | 放艇、弃船、打捞 |

默认门槛：

- 倾斜角超过 25°：甲板物品开始滑动；
- 倾斜角超过 45°：人员和货物出现落海风险；
- 船体归零进入沉船结算，不直接 Game Over；
- 沉船后货物可以形成漂流或打捞事件；
- 船员损失遵守 DESIGN_BOUNDARIES 的不可逆规则；
- 新船通过购买、重建、继承、势力奖励或合法转移获得。

## 3. 进水

进水由破损位置、舱壁、海况和堵漏状态共同决定：

- 破洞大小决定初始进水速度；
- 舱壁决定进水是否扩散；
- 船体倾斜会让低侧舱室进水更快；
- 高浪和搁浅会增加进水；
- 堵漏只降低进水速度，不自动恢复结构；
- 抽水只能降低水位，不能替代堵漏；
- 货舱进水会造成货物受潮和重量分布变化；
- 火药库进水会降低可用炮弹和火药安全。

## 4. 倾斜与货物滑动

倾斜受到以下因素影响：

- 进水位置；
- 货物重量与分布；
- 压载和配重；
- 炮位和模块重量；
- 风向和浪向；
- 船体结构损伤。

物品按重量、固定状态和甲板区域分成：

- 固定设备：不会滑动，但可能损坏；
- 普通货物：超过 25° 开始滑动；
- 甲板散货：较小角度就可能滚落；
- 人员：超过 45° 有落海和摔倒风险。

## 5. 舵损、断帆和断桅

### 舵损

- 转向速度下降；
- 自动航向误差增加；
- 靠泊难度增加；
- 避礁和战斗脱离能力下降；
- 可以用备用舵柄暂时恢复部分控制；
- 木工或船坞进行完整修复。

### 断帆或索具损坏

- 航速和逆风能力下降；
- 调帆命令变慢或失败；
- 船员需要爬桅、放备用帆或收紧索具；
- 风暴中修理风险增加。

### 断桅

- 大幅降低航行能力；
- 可能造成甲板伤害；
- 需要备用桅杆或进船坞；
- 不能只用普通修理按钮瞬间恢复。

## 6. 船舱火灾

可能起火点：

- 厨房炉火；
- 火药库；
- 油料或酒精；
- 炮击火星；
- 雷击；
- 倾斜导致火源翻倒；
- 玩家携带火把进入易燃区域。

火灾状态记录：

- 起火舱室；
- 火势等级；
- 烟雾；
- 相邻可燃物；
- 舱门和防火隔舱；
- 灭火进度；
- 受损功能点；
- 火药爆炸风险。

玩家和船员可以：

- 提水灭火；
- 关闭舱门；
- 转移火药和货物；
- 使用沙土、湿布和灭火桶；
- 放弃着火舱；
- 无法控制时弃船。

火灾必须影响能见度、健康、炮战、舵位、货物和逃生路线。

## 7. 维修类型

| 类型 | 地点 | 作用 |
|---|---|---|
| 临时堵漏 | 船上 | 降低进水，不恢复满状态 |
| 舱底抽水 | 船上 | 降低水位，消耗体力和时间 |
| 修帆修索 | 船上或修船棚 | 恢复部分帆具效率 |
| 修舵 | 船上或船坞 | 恢复转向能力 |
| 普通船坞维修 | 船坞 | 恢复结构和模块耐久 |
| 大修 | 大型船坞 | 恢复严重结构损伤 |
| 重建 | 专业船厂 | 沉船残骸或严重损坏船体重建 |

## 8. 沉船结算

沉船后依次处理：

1. 船员是否成功登上小艇；
2. 船员伤亡和不可逆损失；
3. 货物漂流、沉底或可打捞状态；
4. 船舶历史记录；
5. 玩家位置和救援点；
6. 购买、重建、借船或任务替代船；
7. 保险、债务、声望和法律后果。

## 9. 验收

- 轻伤、进水、倾斜、火灾、断帆和沉船有不同结果；
- 修理动作受材料、工具、船员和天气影响；
- 火灾和进水能传播但有预警和控制办法；
- 货物损失与位置、受潮、倾斜和火灾相关；
- 沉船后不删除整个世界，也不无提示锁死主线；
- 所有状态能写入版本化存档。
