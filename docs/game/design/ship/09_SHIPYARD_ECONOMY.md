# 船坞、造船与维修经济

## 1. 船坞等级

| 等级 | 可用功能 |
|---|---|
| 临时修船棚 | 堵漏、抽水、修帆、普通维修 |
| 村落船匠铺 | 基础改良、木工、绳索、食物和水舱 |
| 城镇船坞 | 买船、结构改造、炮位、医疗和住所 |
| 大型贸易港船坞 | 高级帆具、货舱、火炮、船体重建 |
| 军港或势力船厂 | 军舰、特殊图纸、私掠和护航配置 |
| 专属船厂 | 稀有模块、特殊船型和历史任务奖励 |

船坞等级是港口建筑数据，不是玩家随意升级的 UI 选项。港口势力、材料供应、战争状态和声望都会限制服务。

## 2. 订单流程

1. 玩家选择维修、改造、改良、装饰或购买；
2. 系统检查船型兼容、空间、材料、资金、港口等级和声望；
3. 显示施工时间、停航时间、替代船需求和风险；
4. 玩家确认；
5. 船坞锁定材料和资金；
6. 按游戏日期推进施工；
7. 船员可以加班、拖延、提出替代方案，但不能绕过条件；
8. 完工后更新外观、功能点和状态；
9. 写入船舶历史和财务日志。

## 3. 施工影响

施工期间：

- 船通常不能出航；
- 货物和船员可能需要临时转移；
- 港口可能因战争、缺材或罢工延迟；
- 玩家可以取消订单，但会损失部分预付款；
- 关键任务不能被无提示地永久卡死；
- 施工状态必须保存，读档后继续推进。

## 4. 材料分类

| 材料组 | 内容 | 用途 |
|---|---|---|
| 船材 | 木板、龙骨木、桅杆木、横桁 | 船体、桅杆、维修 |
| 防水 | 树脂、沥青、麻纤维、油布 | 堵漏、防潮、船壳 |
| 帆具 | 帆布、细绳、粗绳、金属索具件 | 帆、索具、缆绳 |
| 金属 | 铁件、铜件、钉、锚、链条 | 锚、舵、炮架和结构 |
| 战斗 | 炮、炮架、火药、三种炮弹 | 炮位和战斗 |
| 生存 | 水桶、药品、厨房器具、容器 | 生活、医疗和补给 |
| 稀有 | 高质量木材、特殊帆布、工匠件 | 高级模块和特殊船型 |

具体价格、工资和维护值由 `economy/` 与 `gameplay/07_PROPERTY_FINANCE.md` 的统一经济规则提供，不写死在船坞表现层。

## 5. 买船、卖船和折价

玩家可以：

- 买新船；
- 卖旧船；
- 以旧换新；
- 用沉船残骸重建；
- 接受势力或任务赠船；
- 合法转移或捕获敌船；
- 改名、换旗和恢复原名。

旧船折价由以下因素决定：

- 当前耐久和模块状态；
- 船型稀缺性；
- 损伤和历史；
- 是否有合法来源；
- 是否被通缉；
- 船厂所在势力；
- 当前港口供需。

被通缉或来源可疑的船不能当作普通商品直接出售。

## 6. 船厂与社会关系

船厂会根据以下因素改变服务：

- 玩家势力声望；
- 是否持有私掠证；
- 是否携带违禁货；
- 是否欠款；
- 是否有本地担保人；
- 港口是否封锁或处于战争；
- 是否尊重当地社区和工匠。

船厂拒绝服务时必须告诉玩家原因和可行替代路线。

## 7. 船坞 UI

每个订单界面显示：

- 当前状态；
- 目标状态；
- 资金；
- 材料；
- 施工天数；
- 停航期间的影响；
- 改装收益；
- 改装代价；
- 互斥模块；
- 外观变化；
- 是否可撤销；
- 失败和延迟条件。

## 8. 验收

- 船坞等级限制有效；
- 材料、资金、声望、时间和空间条件全部可解释；
- 施工状态可以保存和恢复；
- 旧船折价与船体状态相关；
- 船厂拒绝服务有原因和替代路线；
- ShipyardSystem 是唯一裁决者；
- LLM 只能描述或提出建议。
