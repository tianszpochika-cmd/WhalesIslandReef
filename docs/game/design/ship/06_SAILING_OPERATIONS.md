# 航行、操帆与船员操作

## 1. 操船模式

### 1.1 直接操船

玩家在舵位控制基础航向和速度。角色离开舵位后，船不能继续接受直接输入。

### 1.2 指挥操船

玩家通过按钮、文字或语音给船员下达结构化命令，例如升主帆、收帆、左满舵、报告海深和准备堵漏。

### 1.3 船员代操

玩家离开舵位、进入人物模式、登岛或处理事件时，由指定岗位维持航向或执行队列任务。

三种模式不能同时抢夺控制权，必须沿用 D7 的模态输入锁。

## 2. 航速计算

实际航速由以下因素共同决定：

    船型基础航速
    × 风向系数
    × 帆面系数
    × 吃水与载重系数
    × 船体损伤系数
    × 船员操帆系数
    × 天气与海况系数

界面至少解释前 3 个主要减速原因：

- 风向不利；
- 超载；
- 帆具破损；
- 缺少熟练水手；
- 舵损；
- 高浪；
- 进水；
- 浅水限制。

## 3. 航行状态

| 状态 | 说明 |
|---|---|
| 停泊 | 船未获得有效航行速度 |
| 起帆 | 帆具正在展开，速度逐步增加 |
| 航行 | 按风向、帆面和船员工作计算 |
| 减速 | 收帆、逆风或损伤导致速度降低 |
| 漂航 | 无足够动力，只受风和流影响 |
| 抛锚 | 锚泊系统接管位移 |
| 走锚 | 风流超过锚泊能力，船持续漂移 |
| 搁浅 | 水深不足，速度和转向受限 |
| 进水 | 需要堵漏和抽水 |
| 沉船 | 进入损失、打捞和换船结算 |

## 4. 船员岗位

| 岗位 | 工作 | 影响 |
|---|---|---|
| 舵手 | 保持航向、修正转向 | 偏航、转向延迟 |
| 帆手/水手长 | 升帆、降帆、调帆、修索具 | 帆具反应、逆风效率 |
| 瞭望员 | 观察岛屿、敌船、礁石和天气 | 预警距离 |
| 领航员 | 读图、估算航线、测深 | 迷航和浅滩误判 |
| 炮手 | 装填、瞄准、维护炮位 | 装填和命中 |
| 木工 | 堵漏、修桅、修舵、修外板 | 维修时间和进水 |
| 厨师 | 配给、烹饪、卫生 | 士气、疾病和疲劳 |
| 医生 | 治疗、隔离和急救 | 健康和伤员恢复 |
| 货务员 | 装卸、盘点、防潮 | 装卸效率和货损 |
| 小艇长 | 操作长艇、救援艇和登陆艇 | 登岛、救援和打捞 |

岗位效率由技能、疲劳、健康、士气、忠诚、天气、拥堵和工具状态共同决定。

## 5. 轮班

至少支持：

- 航行班；
- 夜间瞭望班；
- 战斗班；
- 修理应急班；
- 登岛队；
- 留船守备班。

同一船员长期值班会提高疲劳、疾病和事故风险，并可能影响忠诚与关系。

## 6. P2A 船舶命令

### 航行

- 升主帆、降主帆、调整前帆、收帆；
- 左满舵、右满舵、回正舵；
- 保持航向、设定目的地、减速、停船；
- 抛锚、起锚；
- 报告海深、风向、前方危险。

### 船务

- 派人堵漏、抽水、检查舱底、检查索具；
- 修舵、修帆、提水灭火；
- 关闭防火舱门、转移火药；
- 分配口粮、分配淡水、清点货物；
- 准备装卸、放下小艇、收回小艇。

### 战斗

- 装填实心弹、链弹、葡萄弹；
- 瞄准敌船、开炮、维护炮位；
- 准备接舷、放下接舷网、召集战斗班；
- 报告敌船距离。

每个命令结果必须返回：是否接受、执行人、完成时间、当前状态、失败原因和是否产生事件。

## 7. 航行与环境联动

- 吃水决定能否进入浅滩、红树林、河口和小港；
- 船宽决定能否通过礁口和狭窄河道；
- 船高影响风阻、瞭望和桅杆风险；
- 风暴、潮汐、海流、能见度共同影响锚泊与靠岸；
- 船底擦礁、拖网和搁浅可能影响海草床和珊瑚；
- 船灯和噪音可能影响海龟、鸟类和夜间动物。

## 8. 失败可恢复

玩家操作错误必须有可理解后果：

- 走锚：重新抛锚、收帆或驶入避风处；
- 进水：派人堵漏和抽水；
- 断帆：改用备用帆或降低速度；
- 舵损：使用备用舵柄或等待木工；
- 搁浅：减载、涨潮等待、放小艇或请求救援；
- 船员疲劳：换班、休息、降低任务强度。

不能用无提示随机结果永久锁死主线。
