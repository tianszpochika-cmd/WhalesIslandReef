# 船型目录与开放顺序

## 1. 数量口径

20 种船体是 M4—M5 的内容目录目标，不代表当前已经全部建模或可购买。部分船型先作为 NPC、敌船、护航船或历史事件船。

船型不是单纯的数值档位。每种船体必须改变路线、港口、载货、战斗、船员和维护方式。

## 3. 船型核心属性

每个 ShipTypeDef 必须包含：

- 长度、宽度、基础吃水、干舷、甲板层数；
- 基础航速、转向、加速、逆风能力和抗浪能力；
- 货物体积、货物重量、淡水、食物和火药容量；
- 最低、标准、最大船员数；
- 炮位上限、结构耐久、进水容量和倾斜敏感度；
- 隐蔽性、维护难度、采购价、维修基准价；
- 可用泊位、最小安全水深、可用小艇；
- 功能点槽位、兼容模块标签和互斥标签；
- 购买港口等级、势力声望、图纸或任务条件；
- 历史依据、虚构部分和素材来源。

## 4. 开放顺序

推荐玩家开放顺序：

1. 小渔船；
2. 单桅纵帆船；
3. 小型快艇或小型平底艇；
4. 双桅纵帆船；
5. 双桅快帆船；
6. 商用双桅船；
7. 武装商船；
8. 轻型盖伦；
9. 私掠双桅船；
10. 军用盖伦；
11. 其余船型由港口、势力、船厂订单或历史任务开放。

## 5. 船型选择的玩家语言

船坞界面不能只显示“速度 7、货舱 120”。需要把选择翻译成白话：

- 小渔船：能进浅水，适合认识世界，但赚不了大钱；
- 单桅纵帆船：最均衡，适合第一次认真跑航线；
- 双桅快帆船：跑得快，适合追击和护航，但修桅杆很贵；
- 商用双桅船：能装很多货，但需要稳定船员和大港；
- 武装商船：能自保，但炮位会吃掉货舱；
- 轻型盖伦：能走远海，代价是吃水、工资和维护；
- 军用盖伦：适合正面战斗，不适合小港、浅滩和低成本经营。

## 6. 历史校对

每个船型都要登记：

- 1675 年前后是否已经存在；
- 在加勒比的常见用途；
- 与英、西、法、荷、葡等贸易网络的关系；
- 是玩家可购买、NPC 专属还是事件专属；
- 哪些地方是为玩法合并的虚构设计。
