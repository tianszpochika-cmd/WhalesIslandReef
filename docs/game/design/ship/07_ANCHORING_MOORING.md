# 锚泊、缆绳、靠岸与小艇

## 1. 抛锚不是瞬间停止

锚泊结果至少取决于：

- 当前水深；
- 锚链有效长度；
- 海底材质：泥、沙、碎石、珊瑚或岩底；
- 风向、风速、海流和浪涌；
- 船体重量、吃水和当前帆面；
- 锚具等级和锚链磨损；
- 是否有船员在锚位工作；
- 是否处于允许抛锚区。

## 2. 锚泊状态

| 状态 | 白话解释 | 后果 |
|---|---|---|
| 未抛锚 | 船自由受风流影响 | 继续漂移 |
| 抛锚中 | 锚正在下放和抓底 | 不能立刻稳定 |
| 锚固稳定 | 锚抓住海底 | 船在锚泊半径内摆动 |
| 锚抓不牢 | 海底或锚具不合适 | 风大时容易走锚 |
| 锚链过短 | 锚链不足以形成稳定角度 | 抗风能力低 |
| 走锚 | 锚被拖动 | 船持续漂移 |
| 锚链缠绕 | 锚链受礁石、缆绳或船体影响 | 起锚困难、转向受限 |
| 丢锚 | 锚或锚链断裂 | 需要备用锚或进港维修 |
| 暴风拖离 | 风浪超过锚泊上限 | 可能撞礁或断缆 |

## 3. 锚泊 UI

玩家必须能看到：

- 水深；
- 海底材质；
- 锚链长度；
- 锚泊半径；
- 船头朝向；
- 当前漂移速度；
- 风流方向；
- 走锚概率等级；
- 是否有可用备用锚；
- 是否有安全替代锚地。

UI 可以用简单颜色：

- 绿色：稳定；
- 黄色：需要观察；
- 橙色：风浪变化后可能走锚；
- 红色：当前锚泊不安全。

## 4. 起锚

起锚需要时间，并受以下因素影响：

- 锚链长度；
- 锚链是否缠绕；
- 锚是否卡在岩石或珊瑚；
- 风浪和船体漂移；
- 锚机等级；
- 船员数量、疲劳和木工技能。

起锚过程中船体不是完全静止，玩家需要提前收帆、安排瞭望并留出安全距离。

## 5. 靠泊与系缆

港口靠泊至少包含：

- 靠泊点；
- 船体碰撞边界；
- 船头缆桩、船尾缆桩和横缆固定点；
- 船头缆、船尾缆和横缆；
- 跳板；
- 登船入口；
- 泊位长度、宽度和吃水限制；
- 缆绳张力；
- 潮位变化；
- 风暴中断缆风险。

船舶靠泊流程：

1. 瞭望确认泊位；
2. 减帆、减速；
3. 对准靠泊方向；
4. 接近缆桩；
5. 下缆；
6. 系跳板；
7. 进入港口服务状态。

靠泊失败分为撞桩、擦岸、跳板断裂、缆绳过紧、缆绳过松和船位不合规。

## 6. 临时锚地与登陆

- 小船可以使用临时锚地和沙滩登陆；
- 中型船可以在安全海湾抛锚并放小艇；
- 大型船通常需要港口泊位或深水锚地；
- 红树林水道要受船宽、吃水、潮位和转向限制；
- 浅滩登陆必须考虑潮位和退潮后回船路线。

## 7. 小艇

长艇和小艇用于：

- 登岛；
- 打捞货物；
- 救援落水船员；
- 进入浅水和红树林；
- 接舷前侦察；
- 港口与船之间搬运人员和货物。

第一版小艇采用简化操控和确定性状态，不要求独立完整的第二套航海模拟。完整小艇物理、海上追逐和水下救援列入 M6。

## 8. 锚泊验收

- 小船和大船能根据吃水进入不同锚地；
- 抛锚不会瞬间固定位置；
- 风、流、海底、锚链和船员会改变稳定性；
- 走锚有预警和补救路径；
- 起锚有时间和失败结果；
- 系缆、断缆、跳板和泊位限制可观察；
- 暴风中锚泊失败不会无提示摧毁存档。
