# 船体、尺寸与甲板布局

## 1. 船体模板职责

HullTemplate 是船型数据、模型、碰撞和玩法之间的桥梁。它必须定义：

- 龙骨轴线、船头、船尾、左右舷和甲板中心；
- 长度、宽度、吃水线、满载线和危险倾斜线；
- 舵、锚、桅杆、帆、炮位、缆桩、舱口和跳板挂点；
- 角色上下船入口、舵位交互点、船员工作点；
- 碰撞盒、浮力采样点、水下体积近似；
- 进水、着火、断桅、断帆、舵损和倾斜的表现锚点；
- 货物、炮弹和甲板物的安全摆放区域。

## 2. 船体结构

| 部件 | 设计职责 | 主要损伤 |
|---|---|---|
| 龙骨 | 纵向承重和抗搁浅 | 搁浅、撞击、严重结构损伤 |
| 肋骨 | 支撑船体横向形状 | 炮击、挤压、进水扩散 |
| 外板 | 直接承受擦碰和炮击 | 破洞、漏水、磨损 |
| 甲板 | 人员、货物、炮位和交互 | 倾斜、火灾、拥堵 |
| 舱壁 | 隔离进水和火灾 | 破坏、封闭、失效 |
| 桅杆 | 承载帆具 | 断桅、倾倒、航速损失 |
| 索具 | 控制帆和桅杆稳定 | 断索、调帆迟缓 |
| 舵 | 改变航向 | 舵损、转向迟钝 |
| 锚具 | 停船和抗风 | 走锚、丢锚、锚链断裂 |
| 舱口 | 装卸和进入舱室 | 进水、拥堵、货损 |

## 3. 舱室布局

不同船型不必拥有全部舱室，但必须在数据里声明容量、通道和功能点：

| 舱室 | 基础功能 | 典型状态 |
|---|---|---|
| 船头作业区 | 锚、缆、瞭望、登船 | 湿滑、拥堵、损坏 |
| 前部储藏区 | 绳索、工具、备用帆 | 受潮、短缺 |
| 主甲板 | 舵、帆、炮、装卸 | 倾斜、火灾、拥堵 |
| 炮甲板 | 炮位、火药、炮弹 | 进水、烟雾、爆炸危险 |
| 货舱 | 商品、木材、粮食、水 | 超载、受潮、货损 |
| 水手舱 | 床位和个人物品 | 拥挤、疾病、士气 |
| 船长舱 | 海图、日志、私人储物 | 安全、指挥、任务 |
| 厨房 | 生火、烹饪、配给 | 火灾、烟雾、缺水 |
| 医疗区 | 治疗、隔离、药品 | 疾病传播、医药短缺 |
| 木工区 | 堵漏、修桅、修舵 | 工具和材料短缺 |
| 舵区 | 舵轮、舵柄、指挥 | 失去转向、人员拥堵 |
| 舱底泵区 | 排水、压载、检查 | 积水、污染、鼠患 |

## 4. 甲板空间规则

- 炮位占用舷侧和人员操作空间；
- 货物堆高会遮挡瞭望、炮口和通道；
- 医务区、货舱、水舱和住所会争夺舱室空间；
- 火药和厨房必须有安全距离或防火隔舱；
- 船员超过工作容量时，装卸、装填和修理互相阻塞；
- 船体倾斜后，低侧甲板物品滑动，高侧功能点可能暂时不可用；
- 甲板物品必须有安全区、可滑动区和落海边界。

## 5. 船体尺寸与水面关系

必须记录：

- 长度：影响泊位和转向半径；
- 宽度：影响稳定、礁口通过和碰撞体；
- 吃水：影响浅滩、红树林、河口和港口；
- 干舷：影响进浪、抗淹和接舷；
- 船高：影响风阻、瞭望、桅杆和桥洞限制；
- 载重线：超过后速度、转向和进水风险逐步恶化；
- 重心：影响倾斜、货物滑动和炮击稳定。

## 6. 碰撞与交互锚点

每种可操控船型至少需要：

- 船体主碰撞体；
- 舵位交互点；
- 船头和船尾锚位；
- 左右舷缆桩；
- 跳板和登船入口；
- 炮位和炮手站位；
- 货舱口和装卸站；
- 小艇下水点；
- 瞭望点；
- 木工、泵、厨房和医疗点；
- 摄像机跟随点和甲板观察点。

## 7. 表现层级

每种船型至少有：

1. 远景轮廓模型；
2. 中景完整船体；
3. 近景甲板与功能点；
4. 交互状态模型；
5. 破损、进水、着火、断帆和倾斜表现；
6. 改装前后外观差异；
7. 夜间灯光挂点；
8. 水下吃水和碰撞轮廓。
