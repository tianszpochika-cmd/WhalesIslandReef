# 环境声音

## 1. 声音层

每种生境至少有：

- 底噪；
- 近景声；
- 远景声；
- 方向性事件声；
- 交互反馈声。

## 2. 生境声音

| 生境 | 声音 |
|---|---|
| 海滩 | 浪、碎石、海鸟、风、潮水 |
| 雨林 | 树叶、昆虫、鸟、滴水、蛙 |
| 红树林 | 泥水、根系、蚊虫、鱼跃、划船 |
| 山地 | 风、落石、瀑布、回声、雷声 |
| 洞穴 | 滴水、脚步、蝙蝠、浪涌、火把 |
| 暗礁 | 破浪、船底擦碰、索具、警告 |
| 港口 | 人声、木板、货物、钟、船厂 |

## 3. 无障碍

关键声音必须有：

- 文字；
- 图标；
- 颜色；
- 方向提示；
- 可调音量；
- 字幕或日志。

## 4. 动态混音

天气、船舶状态、战斗、洞穴、角色距离和镜头模式会改变混音，但不能遮盖关键提示。
