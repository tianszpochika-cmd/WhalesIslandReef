# 环境表现与天气设计

本目录专门存放水体、天气、风场、光照、声音、特效、昼夜和环境性能。

规划文档：

- 01_WEATHER_SYSTEM.md：12 种天气、预警、灾害和恢复；
- 02_WATER_SYSTEM.md：海面、河流、潮汐、海流、泡沫和浑浊度；
- 03_LIGHTING_MATERIALS.md：地形、船体、植被、水体和洞穴材质；
- 04_ENVIRONMENT_AUDIO.md：海岸、雨林、洞穴、风暴和船舶声音；
- 05_STREAMING_PERFORMANCE.md：50 座岛流式加载、LOD、对象池和性能；
- 06_ENVIRONMENT_QA.md：天气、画质、碰撞和存档回归。

状态：第一版设计已完成；天气、水体、生态和表现规则可进入 D9—D15 开发拆分。
