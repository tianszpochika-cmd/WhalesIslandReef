# 环境流式加载与性能

## 1. 分区

世界按：

- 海域；
- 岛屿；
- 自然区域；
- 场景单元；
- 近景交互区；

分层加载。

## 2. 激活规则

- 近景启用碰撞和交互；
- 中景启用动画和声音；
- 远景只保留轮廓、地图标记和低成本代理；
- 离开区域后保存状态，不保留所有高成本对象；
- 关键任务对象可以提前预加载。

## 3. 性能预算

必须监控：

- 1080p 目标设备帧率；
- 加载尖峰；
- 场景内活动动物数；
- 可交互植被数；
- 船员和 NPC 数；
- 水体和天气特效数；
- 阴影和透明材质数量；
- 存档写入耗时。

## 4. 不能牺牲的内容

性能优化不能删除：

- 船舶控制；
- 关键船员；
- 任务目标；
- 航海危险；
- 重要资源；
- 玩家可见的天气预警。

应先降低远景、代理、更新频率和特效，而不是删除核心逻辑。
