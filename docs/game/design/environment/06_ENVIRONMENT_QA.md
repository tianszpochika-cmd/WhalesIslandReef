# 环境表现与系统验收

## 1. 天气

- [ ] 12 种天气有状态、预警、影响和恢复；
- [ ] 天气影响船、角色、植物、动物、NPC 和水体；
- [ ] 大灾害可预警和避难；
- [ ] 存档后天气状态可恢复。

## 2. 水体

- [ ] 8 类水体有颜色、深度、波浪、流速和碰撞；
- [ ] 吃水和水深联动；
- [ ] 潮汐影响登陆、洞穴、红树林和动物；
- [ ] 暗礁、海草床和河口可被玩家理解。

## 3. 视觉与声音

- [ ] 晴、雨、雾、黄昏、夜间和风暴前有明显差异；
- [ ] 船、角色、植被和地形材质层级正确；
- [ ] 环境声音按生境和距离变化；
- [ ] 关键声音有文字和图标替代。

## 4. 性能

- [ ] 50 座岛可以分区加载；
- [ ] 远景、中景、近景有不同成本；
- [ ] 动物、植被、NPC 和水体不会同时造成帧率崩溃；
- [ ] 关键逻辑不因表现降级而丢失；
- [ ] 存档和加载时间在目标设备可接受。
