# 光照、材质与视觉质量

## 1. 地形材质

至少区分：

- 干沙；
- 湿沙；
- 泥；
- 火山岩；
- 石灰岩；
- 珊瑚碎石；
- 苔藓岩；
- 湿木；
- 农地；
- 盐碱地。

## 2. 光照阶段

- 清晨；
- 上午；
- 正午；
- 下午；
- 黄昏；
- 夜间；
- 月光夜；
- 暴风前低光。

夜间不仅降低亮度，还要改变颜色、可见距离、声音权重和动物活动。

## 3. 天气材质反应

- 雨水在叶面、甲板和岩石积聚；
- 湿地反射提高；
- 雾降低远景和声音清晰度；
- 暴风前海面变暗；
- 火把照亮人物、岩壁、烟雾和水滴；
- 港口灯火在雾雨中产生光晕。

## 4. 质量层级

每个环境资产至少有：

- 远景轮廓；
- 中景材质；
- 近景细节；
- 交互状态；
- 破损或天气变体。

## 5. 质量门

同一地点在晴天、雨天、雾天、黄昏、夜间和风暴前必须有明显但连续的差异，不靠完全替换场景实现。
