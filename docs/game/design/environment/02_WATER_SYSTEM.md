# 水体、潮汐与海流

## 1. 水体类型

- 深海开阔水面；
- 近岸浅海；
- 珊瑚礁浅滩；
- 红树林水道；
- 泻湖和内湾；
- 河口与淡水水面；
- 港池和码头；
- 风暴和暴雨水面。

## 2. 水体字段

- water_body_id；
- type；
- depth_profile；
- salinity；
- turbidity；
- wave_profile；
- current_direction；
- current_speed；
- tide_profile；
- foam_profile；
- color_profile；
- collision_layer；
- navigation_modifier；
- ship_draft_limit；
- fish_tags；
- animal_tags；
- weather_response。

## 3. 潮汐

潮汐至少影响：

- 红树林通道；
- 海蚀洞；
- 沙滩登陆；
- 海草床；
- 河口盐度；
- 锚地水深；
- 沉船和漂流物；
- 螃蟹、贝类和海龟活动。

玩家可以通过潮痕、船员经验、海图和时间判断潮位。

## 4. 海流

海流影响：

- 航线时间；
- 鱼群；
- 漂流物；
- 锚泊；
- 小艇；
- 污染和泥沙；
- 风暴后的残骸。

## 5. 视觉

水体表现：

- 颜色和透明度；
- 波长、浪高和泡沫；
- 反射与浑浊度；
- 船体扰动；
- 河海交汇；
- 港池低浪；
- 礁区破浪；
- 风暴浪峰。
