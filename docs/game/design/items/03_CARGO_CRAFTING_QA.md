# 货物、制作与道具验收

## 1. 货物规则

- 货舱容量按体积；
- 船体载重按重量；
- 易损货物受潮、火灾、碰撞和鼠患影响；
- 违禁品受检查和法律状态影响；
- 任务货物不能被普通交易错误消耗；
- 人的自由身份不能作为货物。

## 2. 制作规则

- 配方有唯一 ID；
- 配方有输入、输出、时间和失败；
- 材料来自具体地点或贸易链；
- 制作状态可保存；
- 破坏或取消订单有明确损失。

## 3. 验收

- 200 个功能道具有目录；
- 300 个装饰对象有资产状态；
- 所有功能道具有重量、体积、耐久和来源；
- 船材可以进入船坞和维修；
- 工具可以被玩家或船员使用；
- 货物损失可由损伤、天气和位置解释；
- 道具、库存、货舱和经济系统写者分离；
- 无法交易的物品有明示原因。
