# 工具、船材与制作材料

## 1. 工具

首批工具包括：

- 望远镜；
- 指南针；
- 测深铅锤；
- 测程线；
- 火石；
- 火把；
- 砍刀；
- 斧；
- 小刀；
- 绳索；
- 水桶；
- 修船工具箱；
- 药草包；
- 捕鱼手线；
- 渔网；
- 捕蟹笼；
- 小艇钩；
- 地图和航海日志。

## 2. 工具字段

- 使用动作；
- 所需技能；
- 耐久消耗；
- 失败概率；
- 环境限制；
- 可维修性；
- 是否可被船员使用；
- 是否影响观察质量；
- 是否允许 P2A 调用。

## 3. 船材

| 材料组 | 内容 | 用途 |
|---|---|---|
| 船材 | 木板、龙骨木、桅杆木、横桁 | 船体和桅杆 |
| 防水 | 树脂、沥青、麻纤维、油布 | 堵漏和防潮 |
| 帆具 | 帆布、细绳、粗绳、金属件 | 帆、索具和缆绳 |
| 金属 | 铁件、铜件、钉、锚、链条 | 结构、锚和炮架 |
| 战斗 | 炮、炮架、火药、炮弹 | 炮战 |
| 生存 | 桶、容器、药品、厨房器具 | 补给、医疗和生活 |

## 4. 制作

制作需要：

- 配方；
- 工具；
- 工作台；
- 材料；
- 技能；
- 时间；
- 许可证或社群知识；
- 失败结果。

Agent 可以建议配方，但制作系统裁决产出。

## 5. 许可证

火药、火器、药品、宗教物品、受保护植物和特殊船材可能受到势力或港口限制。
