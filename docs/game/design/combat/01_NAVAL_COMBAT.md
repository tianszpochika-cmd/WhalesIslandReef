# 海战炮击设计

## 1. 战斗目标

海战是生存、护航、私掠、逃亡和势力冲突的手段，不是单纯竞技场。

## 2. 战斗状态

- idle；
- detected；
- approaching；
- engaged；
- boarding_ready；
- boarded；
- escaping；
- surrendered；
- victory；
- defeated；
- sinking。

## 3. 输入因素

- 船型；
- 炮位；
- 弹种；
- 距离；
- 航向；
- 风向；
- 船速；
- 船体损伤；
- 瞭望质量；
- 炮手技能；
- 装填状态；
- 敌船士气；
- 海况。

## 4. 弹种

| 弹种 | 作用 | 短板 |
|---|---|---|
| 实心弹 | 船体和炮位损伤 | 对帆和人员有限 |
| 链弹 | 破帆、断索、降低速度 | 船体伤害低 |
| 葡萄弹 | 压制甲板和船员 | 射程短、对船体弱 |

## 5. 命中逻辑

距离和角度先决定命中区间，再由炮手、船体运动、天气和弹种计算结果。

结果必须区分：

- 未命中；
- 擦边；
- 船壳损伤；
- 炮位损坏；
- 帆具损坏；
- 舵损；
- 船员伤害；
- 火灾；
- 火药危险；
- 进水。

## 6. 玩家选择

玩家可以：

- 追击；
- 逃跑；
- 保持距离炮击；
- 破帆后接近；
- 压制船员；
- 瞄准船体；
- 投降；
- 请求护航；
- 接舷；
- 放弃战斗。

## 7. 战斗边界

战斗系统唯一裁决命中、伤害、装填、接舷和战果。动画只表现结果。
