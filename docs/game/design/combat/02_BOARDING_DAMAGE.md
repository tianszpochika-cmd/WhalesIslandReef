# 接舷、船员战斗与战后结果

## 1. 接舷前提

需要满足：

- 船体距离；
- 相对速度；
- 舷侧可用；
- 对方未沉船；
- 接舷点未被火灾或倾斜阻断；
- 玩家拥有可用船员；
- 接舷工具和士气满足条件。

## 2. 接舷状态

- 准备；
- 靠近；
- 抛钩和接舷网；
- 登船；
- 混战；
- 撤离；
- 投降；
- 俘获；
- 失败。

## 3. 船员因素

- 人数；
- 健康；
- 疲劳；
- 士气；
- 格斗技能；
- 武器；
- 船长指挥；
- 接舷网和甲板布局；
- 船体倾斜和火灾。

## 4. 战后

战后处理：

- 船体和功能点损伤；
- 船员伤亡、俘虏和失踪；
- 货物和弹药；
- 战利品；
- 法律身份；
- 势力声望；
- 悬赏和报复；
- 船舶历史日志。

战利品必须进入经济或库存系统，不能由战斗文本直接创造。

## 5. 失败恢复

- 逃跑；
- 投降；
- 被俘；
- 受伤后救援；
- 船员伤亡；
- 船只漂流；
- 战后维修；
- 赎金或交换。

## 6. 后置

实时格挡、动作化接舷小游戏和自由登船室内战斗列入 M6。
