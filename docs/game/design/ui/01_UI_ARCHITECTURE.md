# UI 信息架构

## 1. 信息层级

### 一级

- 航行 HUD；
- 船体状态；
- 角色状态；
- 海图；
- 当前目标；
- 重要警报。

### 二级

- 船舶详情；
- 改装；
- 船坞；
- 货舱；
- 船员；
- 贸易；
- 势力；
- 任务；
- 日志。

### 三级

- 物品详情；
- 历史说明；
- 关系记录；
- 生态观察；
- 材料来源；
- 价格变化；
- 事件因果。

## 2. 统一信息

所有状态面板至少有：

- 当前值；
- 上限；
- 变化原因；
- 预计影响；
- 可执行动作；
- 失败原因；
- 恢复建议。

## 3. 船舶 UI

包括：

- 船体耐久、进水、倾斜、火灾；
- 速度、航向、风、海深；
- 货舱体积、重量和货损；
- 淡水、食物、药品、火药；
- 船员岗位、疲劳和轮班；
- 锚、缆绳、泊位；
- 模块、功能点、等级和互斥。

## 4. 交互原则

- 一次只有一个有效控制权；
- 对话、贸易、船舵、暂停和人物输入不能串键；
- 文字提示不能挡住关键按钮；
- 鼠标和焦点离开窗口后恢复；
- 重要状态不只靠颜色表达。
