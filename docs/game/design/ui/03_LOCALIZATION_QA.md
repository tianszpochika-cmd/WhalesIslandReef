# UI、本地化与验收

## 1. 文本分类

- 系统标签；
- 状态；
- 警报；
- 任务；
- 历史说明；
- 船员对白；
- 物品；
- 建筑；
- 势力；
- 生态；
- 教学。

## 2. 文本规则

- 数值和单位不能写死在语言文本；
- 文本不能改变逻辑事实；
- 翻译保留时代语气；
- 历史称呼记录来源；
- 重要内容可跳过；
- 长文本提供摘要。

## 3. 验收

- [ ] 中文和英文键完整；
- [ ] 文本不会溢出按钮；
- [ ] 对话、贸易、暂停和舵位不串键；
- [ ] 警报同时有文字和视觉；
- [ ] 读档后 UI 反映真实状态；
- [ ] 低表现强度和无障碍选项有效；
- [ ] 海图和船舶面板可查询原因。
