# 船舶、海图与输入

## 1. 航行 HUD

显示：

- 船名和船型；
- 航向；
- 航速；
- 风向；
- 海深；
- 目的地；
- 时间；
- 天气；
- 船体警报；
- 当前岗位。

## 2. 海图

海图显示：

- 已知岛屿；
- 港口；
- 航线；
- 浅滩；
- 暗礁；
- 海流；
- 预计航行时间；
- 传闻区域；
- 船员瞭望报告；
- 玩家标记。

未知内容不能提前全部显示，玩家可通过探索、交易、测深和 NPC 了解。

## 3. 输入优先级

1. 关闭危险弹窗或暂停；
2. 关闭当前模态 UI；
3. 处理舵位、炮位或交互；
4. 人物移动；
5. 镜头；
6. 非关键快捷键。

## 4. 可访问性

- 键鼠；
- 手柄预留；
- 字体大小；
- 字幕；
- 色盲辅助；
- 震动开关；
- 音频替代；
- 低表现强度；
- 语言切换。
