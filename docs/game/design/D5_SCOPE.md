# D5 打磨上架范围冻结

> 状态：D5-01 已冻结；目标是把 D4 灰盒可玩环收束为可展示、可测试、可发布准备的版本。日期：2026-08-09

## 1. 阶段目标

D5 的可见闭环是：

`12 岛海图 → 探索/发现 → 50 条特质 → 基础预设捏脸 → 中英切换 → 1080p/60 目标监控 → 成就/云存档桥接 → 发布资料包`

本阶段继续采用确定性强逻辑。Steamworks SDK 未随仓库分发，因此客户端提供离线安全的 Steam Bridge、成就状态和云存档队列；真正的 App ID、Partner 账号、$100 Steam Direct 付款、商店审核、愿望单运营和 Next Fest 报名属于外部发布动作，不由本地代码自动完成。

## 2. 本阶段交付

| 领域 | D5 交付基线 | 唯一写者 |
|---|---|---|
| 世界 | 12 个岛屿、5 种岛屿类型、5 种热带生境、发现/访问状态 | `D5WorldSystem` |
| 特质 | 50 条特质：身体 15、性格 20、经历 10、疾病 5；确定性生成 3-4 条 | `D5TraitSystem` |
| 捏脸 | 8 个基础角色预设，皮肤/发型/发色/服装/体型参数 | `D5CharacterSystem` |
| 本地化 | D5 UI、12 岛、50 特质、8 预设均有中文/英文文案 | `D5LocalizationSystem` |
| 性能 | 1080p、60 FPS 目标档位，低/中/高预设，运行时采样和达标报告 | `D5PerformanceSystem` |
| Steam | 8 个成就、离线安全桥接、云存档待上传队列、商店元数据清单 | `D5SteamSystem` + `D5SteamBridge` |
| 存档 | D5 快照写入既有 `location_json.d5`，D1-D4 旧存档兼容 | `SaveSystem` 只序列化 |
| 服务端 | D5 契约镜像：世界、特质、捏脸、性能、云存档 | `server/src/modules/d5` |
| Unity | 12 岛可视化海图、角色预设切换、语言/画质/成就/保存操作 | `D5RuntimeBootstrap` |

## 3. 明确不自动化的外部发布动作

- Steamworks SDK 的商业包安装和真实 App ID 配置（使用 `WHALEBONE_STEAM_APP_ID` 或项目设置后接入）。
- Steam Direct $100 付款、税务/银行资料、商店审核和真实 EA 上架。
- 愿望单投放、媒体素材投放、Next Fest 报名和社区运营。

这些事项在 `D5_RELEASE_CHECKLIST.md` 中登记为可执行清单，技术侧保证没有 SDK 时也能正常启动、保存和游玩。

## 4. 数据所有权

1. `D5WorldSystem` 唯一裁决发现、访问和当前岛状态。
2. `D5TraitSystem` 唯一裁决特质目录、生成和修正值。
3. `D5CharacterSystem` 唯一裁决角色预设和基础外观参数。
4. `D5PerformanceSystem` 唯一裁决采样、质量档位和达标判断。
5. `D5SteamSystem` 唯一裁决本地成就与云存档队列状态。
6. `SaveSystem` 只复制 D5 快照，不计算世界、特质、性能或成就结果。
7. Unity 和服务端只传递意图/快照，不在表现层修改 D5 数值。

## 5. 验收门

- 纯 C#：12 岛、50 特质分类、确定性生成、8 预设、性能报告、8 成就、云队列均有 EditMode 测试。
- Unity：InitialHarbor 显示 D5 海图和状态面板；能发现岛屿、切换角色预设、切换语言、切换质量、解锁成就和保存。
- Server：D5 JSON Schema 与 OpenAPI 路由对应，`npm run build` 通过。
- 存档：D5 快照保存/读取；D1-D4 旧存档缺少 D5 字段时正常进入默认状态。
- 运行时：D5 入口、海图、12 个岛标记、角色对象和 UI 冒烟通过。
- 性能：目标参数为 1920×1080、60 FPS；运行时报告会明确显示实际采样结果，不伪造硬件性能结论。
- 留痕：范围、任务表、验收报告、路线图、上下文和当日 memory 同步更新。
