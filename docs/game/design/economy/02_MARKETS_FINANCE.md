# 市场、信用、保险与金融

## 1. 市场

市场按港口和商品形成差异：

- 产地港；
- 消费港；
- 军需港；
- 转口港；
- 黑市港；
- 封锁港；
- 灾后短缺港。

价格受到：

- 基础价；
- 库存；
- 需求；
- 贸易路线；
- 关税；
- 战争；
- 天气；
- 玩家交易量；
- 走私和检查影响。

## 2. 价格边界

商人底价和收购价区间由经济系统给出。LLM 只能生成谈判语气，不能让玩家靠一句话突破边界。

## 3. 信用

信用由：

- 按时还债；
- 交易记录；
- 势力声望；
- 资产；
- 担保人；
- 违约；
- 通缉；
- 船舶损失决定。

信用影响贷款、船坞订单、保险、货款和招募。

## 4. 债务

债务字段：

- principal；
- interest；
- due_day；
- creditor；
- collateral；
- late_penalty；
- legal_consequence；
- renegotiation_count。

玩家可以还款、展期、抵押、转债、逃债或以任务换债。

## 5. 保险

保险可以覆盖：

- 货物损失；
- 船体损伤；
- 风暴；
- 海盗；
- 运输延误。

保险不覆盖：

- 故意违法；
- 伪造身份；
- 违反航线限制；
- 夸大货物价值；
- 玩家主动弃船造成的部分损失。

保险赔付受记录和证据影响。
