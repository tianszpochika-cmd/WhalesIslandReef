# 工资、维护与经济验收

## 1. 固定支出

- 船员工资；
- 食物；
- 淡水；
- 医药；
- 火药；
- 船体维护；
- 帆具和索具；
- 港口泊位；
- 税费和关税；
- 债务利息；
- 保险。

## 2. 可变支出

- 临时雇佣；
- 加急船坞；
- 稀有材料；
- 罚金和赎金；
- 战后修复；
- 任务贿赂；
- 贸易损失。

## 3. 验收

- 玩家能看懂一趟航程的成本；
- 价格变化有来源；
- 经济系统能处理缺货和过剩；
- 交易不会凭空创造金钱；
- 债务、工资和维护能保存；
- 商人底价由逻辑裁决；
- 任务奖励不会绕过经济系统；
- 经济压力能推动船舶和船员选择，但不阻塞所有路线。
