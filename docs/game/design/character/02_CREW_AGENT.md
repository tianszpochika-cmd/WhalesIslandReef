# 船员 Agent 设计

## 1. 船员是完整但受约束的 Agent

每名核心船员有：

- 姓名、文化、职业、出身和时代知识；
- 3—4 个特质；
- Persona；
- 短期、中期和长期记忆；
- 健康、疲劳、士气、忠诚、好感和技能；
- 与玩家及其他船员的关系；
- 岗位、轮班和工作任务；
- 个人目标、禁忌和底线。

## 2. Agent 可以做什么

- 说话；
- 表达情绪；
- 记住重要事件；
- 提出航线、修理、交易和人事建议；
- 执行被分配的岗位；
- 在信息不足时承认不知道；
- 对玩家行为产生关系和信任变化的提议。

## 3. Agent 不可以做什么

- 直接改好感、忠诚、工资、耐久、价格或声望；
- 直接触发战斗、疾病、叛变和任务完成；
- 绕过被锁定选项；
- 伪造历史事实和身份；
- 看到系统内部隐藏记忆原文；
- 通过对白突破商人底价、船坞条件或法律检查。

## 4. 三层记忆

### 短期记忆

最近 8 轮对话、当前任务、当前船务状态和当前争执。

### 中期记忆

每 10 轮生成一次会话摘要，保留：

- 玩家命令；
- 船员执行结果；
- 重要承诺；
- 冲突；
- 公开事实；
- 未解决问题。

### 长期记忆

按重要性保存：

- 救援；
- 背叛；
- 欠薪；
- 伤害；
- 宗教和文化冲突；
- 共同战斗；
- 船员死亡；
- 玩家兑现或违背承诺。

数值不依赖 LLM 记忆。忠诚、健康和疲劳单独存储，并由强逻辑直接驱动。

## 5. 命令执行链

玩家语言 → 意图识别 → AgentReply Schema → 动作白名单 → 条件检查 → 船员能力与状态 → 强逻辑裁决 → 结果反馈 → 记忆摘要。

执行质量受：

- 技能；
- 疲劳；
- 健康；
- 士气；
- 忠诚；
- 工具；
- 天气；
- 船体状态；
- 是否有其他任务冲突影响。

## 6. 降级

LLM 不可用时：

- 使用模板回应；
- 保留确定性命令；
- 保留岗位工作；
- 保留数值和存档；
- 明确提示“当前使用简化船员回应”。

## 7. 船员工作日志

每次重要工作记录：

- 船员；
- 岗位；
- 任务；
- 开始和结束时间；
- 是否成功；
- 失败原因；
- 材料消耗；
- 船员情绪；
- 对关系的建议变化。
