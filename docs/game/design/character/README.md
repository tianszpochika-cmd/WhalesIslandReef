# 角色设计

本目录专门存放玩家角色、船员 Agent、NPC、角色特质、职业、关系、行为和动画设计。

规划文档：

- 01_CHARACTER_OVERVIEW.md：玩家角色与角色成长；
- 02_CREW_AGENT.md：船员人格、记忆、岗位和 Agent 边界；
- 03_TRAITS_CULTURE.md：特质、文化、宗教、法律身份和经历；
- 04_CREW_RELATIONS.md：船员关系、冲突、忠诚、叛变和会议；
- 05_NPC_BEHAVIOR.md：港口居民、商人、官员、部落和势力 NPC；
- 06_CHARACTER_PRESENTATION.md：模型、动作、服装、伤病和表情；
- 07_CHARACTER_QA.md：角色逻辑、对话和表现验收。

状态：第一版设计已完成；角色关系、经营副业和外观玩法另见 `../gameplay/06_RELATIONSHIP_ROMANCE.md` 与 `../gameplay/09_CHARACTER_CUSTOMIZATION.md`。
