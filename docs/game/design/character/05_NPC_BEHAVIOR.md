# NPC 行为与社会模拟

## 1. NPC 分级

| 级别 | 对象 | 行为 | 记忆 |
|---|---|---|---|
| L1 | 核心船员 | Agent、岗位、关系、长期记忆 | 有 |
| L2 | 商人、官员、首领、收藏家 | 状态机 + 有限对话 | 会话级 |
| L3 | 港口居民、酒馆水手、工人 | 模板日程和短对话 | 无或极短 |
| L4 | 远景人群 | 群体移动和环境动画 | 无 |

## 3. 行为层

1. 生存：吃饭、饮水、休息、避雨、治疗、逃离危险；
2. 工作：生产、装卸、修船、售卖、巡逻、传教、运输；
3. 家庭：照顾家人、婚姻、葬礼、债务和家庭冲突；
4. 社群：教会、行会、村落、船员、商人家族和逃亡社区；
5. 势力：检查、征税、招募、巡逻、战争和封锁；
6. 个人：复仇、爱情、发财、逃亡、学习和成名；
7. 记忆：信任、恐惧、感激、警惕和传播；
8. 表达：重要 NPC 才使用 LLM，普通 NPC 使用模板。

## 4. 日程

典型港口日程：

- 清晨：开门、祈祷、准备工具；
- 上午：生产、交易、装卸、巡逻；
- 中午：吃饭、休息、避热；
- 下午：继续工作、市场、船坞施工；
- 黄昏：收摊、回家、酒馆和社群活动；
- 夜间：守卫、睡眠、秘密交易、宗教仪式或犯罪。

天气、节日、战争、疾病和玩家行为可以改变日程。

## 5. NPC 认知边界

NPC 只知道：

- 自己看到或听到的；
- 社群公开传闻；
- 职业知识；
- 势力发布的命令；
- 玩家在其可见范围内做过的事。

NPC 不能因为 LLM 需要剧情而知道地图全部内容。

## 6. 玩家影响

玩家可以通过：

- 付款、交易、救援、威胁、谈判；
- 传播消息；
- 改变港口资源；
- 保护或破坏环境；
- 完成任务；
- 建立关系；
- 改变势力声望。

玩家不能直接编辑 NPC 状态面板。
