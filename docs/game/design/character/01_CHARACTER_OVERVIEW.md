# 角色系统总览

## 1. 角色类型

角色分为：

| 类型 | 数量目标 | 逻辑级别 | 作用 |
|---|---:|---|---|
| 玩家角色 | 1 | 可控制 | 选择路线、行动和船长身份 |
| 核心船员 | 8—12 同屏 | L1 Agent | 船上社会、岗位、记忆和关系 |
| 重要 NPC | 60—100 | L2 | 商人、官员、首领、工匠、医生和宗教人物 |
| 普通 NPC | 500—1,000 实例 | L3 | 港口生活、工作、排队和短对话 |
| 历史背景角色 | 按剧情 | 作者控制 | 历史说明和固定叙事锚点 |
| 动物 | 300 条目 | 确定性生态 | 环境和食物链，不使用 LLM |

## 2. 玩家角色

玩家至少拥有：

- 姓名、年龄段、出身和初始文化标签；
- 健康、疲劳、体温、饥饿、口渴和伤病；
- 航海、领航、贸易、炮术、木工、医术、厨艺和格斗技能；
- 特质、声望、法律身份和债务；
- 服装、装备、随身物品和当前船只；
- 已知地图、联系人、任务、日志和传闻。

玩家不能直接修改经济、声望、船体或 NPC 数值，只能通过行动产生结果。

## 3. 角色成长

成长来自：

- 实际使用技能；
- 船员训练；
- 完成任务；
- 获得图纸、证书和声望；
- 结识导师、工匠、医生或领航员；
- 付出时间、金钱和失败代价。

不使用纯粹的“打怪升级”作为唯一成长方式。

- disease；
- bleeding；

### 社会

- loyalty；

- trust；
- fear；
- reputation；
- debt；
- legal_status。

### 工作

- current_role；
- shift；
- task；
- task_progress；
- tool；
- workplace；
- availability。

## 5. 角色死亡和重伤

- 重伤可以导致治疗期、行动受限和岗位空缺；
- 玩家死亡方案仍需最终确定；
- 船员死亡必须有明确原因和日志；
- 关键任务不能用无提示的随机死亡终止；
- 死亡后必须处理遗物、关系、岗位、工资和士气。
