# 特质、文化、宗教与身份

## 1. 特质类别

目标为 50 个以上特质，分为：

| 类别 | 示例 | 影响 |
|---|---|---|
| 身体 | 强壮、旧伤、肺病、怕热 | 健康、体力、疾病 |
| 性格 | 贪婪、谨慎、勇敢、迷信 | 建议、风险、关系 |
| 技能 | 老水手、炮手学徒、木工 | 岗位效率 |
| 经历 | 私掠经历、逃亡经历、船难幸存 | 事件、记忆、法律 |
| 文化 | 英格兰、法兰西、加勒比、非洲裔社群 | 语言、风俗、关系 |
| 信仰 | 天主教、英国国教、改革宗、非洲传统信仰 | 仪式、禁忌、社群 |
| 法律 | 自由、契约、逃亡、被通缉 | 通行、任务、风险 |
| 关系 | 欠债、家族、仇敌、恩人 | 对话、任务、忠诚 |

## 2. 特质字段

每个 TraitDef 包含：

- trait_id；
- category；
- display_name；
- description；
- stat_modifiers；
- job_modifiers；
- event_modifiers；
- relationship_modifiers；
- persona_note；
- forbidden_knowledge；
- cultural_sensitivity；
- source_notes。

## 3. 文化设计

文化不是一个简单的阵营颜色。文化标签影响：

- 语言和称呼；
- 饮食、衣物和生活方式；
- 对宗教、法律和权威的态度；
- 船上冲突；
- 招募和工资；
- 港口社群接纳；
- 任务和救援关系。

同一文化内部也必须存在阶层、职业、信仰和个人差异。

## 4. 宗教与身份边界

宗教可以影响节期、饮食、葬礼、承诺和社群，但不能简化成“善恶阵营”。

法律身份至少区分：

- 自由居民；
- 契约劳工；
- 船员；
- 商人；
- 军人；
- 传教士；
- 逃亡者；
- 被拘押者；
- 被通缉者；
- 原住民社群成员。

人的自由身份不能放进货舱或商品价格表。

## 5. 特质冲突

特质之间可以产生：

- 加成；
- 抵消；
- 冲突；
- 隐性压力；
- 任务分歧。

冲突必须通过数值、事件和关系解决，不由 LLM 自己宣布结果。

## 6. 历史审查

涉及族群、奴役、宗教、殖民和逃亡的特质需要：

- 外部称呼与自称区分；
- 时间和地区校对；
- 不把真实社群只写成敌人或受害者；
- 内容警告和低表现强度选项；
- 历史顾问或敏感内容审阅记录。
