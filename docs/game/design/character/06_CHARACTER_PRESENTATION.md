# 角色模型、动作、服装与表现

## 1. 视觉层级

核心船员需要：

- 可辨识脸部和服装；
- 职业道具；
- 伤病和疲劳表现；
- 船上工作动作；
- 对话姿态；
- 战斗和逃跑动作；
- 个人颜色或小型标识。

普通 NPC 可以使用共享身体、服装和动作组合。

## 2. 动作类别

- 待机、走路、奔跑、跳跃；
- 上下船、登梯、跨缆和靠泊；
- 操舵、瞭望、升帆、降帆；
- 装卸、搬运、修船、抽水；
- 烹饪、治疗、休息和争论；
- 拔刀、持枪、装填、接舷和逃跑；
- 受伤、跌倒、溺水和救援。

## 3. 服装与时代

服装按职业、财富、气候、文化和工作环境组合：

- 船员工作服；
- 船长和官员服；
- 商人和工匠服；
- 军人和私掠者服；
- 原住民社群服饰；
- 宗教人物服装；
- 雨季、湿地和高温适应；
- 受伤、污渍、破损和替换状态。

不使用现代拉链、塑料、现代徽章和明显后世制服。

## 4. 表现与数值

疲劳、健康和士气应影响：

- 站姿；
- 动作速度；
- 咳嗽、跛行、发抖；
- 争论频率；
- 工作失败反馈。

表现只能读取状态，不能反向修改状态。

## 5. 性能

- 核心船员使用完整 Animator；
- 普通 NPC 使用共享 Animator；
- 远景 NPC 使用群体动画；
- LLM 不参与每帧行为；
- 角色对话期间暂停无关高成本动作；
- 港口居民使用对象池和分区启用。
