# 角色系统验收

## 1. 数据验收

- 玩家、船员、重要 NPC 和普通 NPC 有不同数据级别；
- 特质、文化、宗教、法律身份和职业字段完整；
- 角色 ID 唯一；
- 关系为有向数据；
- 健康、疲劳、士气、忠诚和好感有唯一写者；
- 旧存档缺少新字段时可以默认迁移。

## 2. 行为验收

- 船员能执行岗位；
- 疲劳和健康会影响执行；
- 重要 NPC 有日程和职业行为；
- 普通 NPC 不会占用完整 Agent 资源；
- 角色只知道符合其位置和职业的信息；
- 叛变有前兆和可解释原因。

## 3. Agent 验收

- AgentReply 通过 Schema 才能进入逻辑层；
- Agent 不能改数值；
- LLM 不可用时仍能完成基础船务；
- 对话不会绕过法律、价格、任务和身份条件；
- 记忆摘要不会覆盖事实数值。

## 4. 表现验收

- 核心船员可以从远处和职业动作识别；
- 伤病、疲劳、工作和对话表现一致；
- 动作、碰撞、上下船和镜头不穿模；
- 无外部音频时有降级通道；
- 1080p 目标设备下角色数量不会破坏性能。
