# 船员关系、士气与忠诚

## 1. 关系图

关系是有方向的：

- 玩家 → 船员：好感、信任、恐惧；
- 船员 → 玩家：忠诚、欠债、敬意、怨恨；
- 船员 → 船员：友情、竞争、债务、仇恨、亲属；
- 船员 → 社群：家族、宗教、势力、故乡。

关系值不能只靠对白增长，必须由事实事件产生。

## 2. 核心数值

| 数值 | 范围 | 作用 |
|---|---:|---|
| 士气 | 0—100 | 工作、战斗、疾病和抱怨 |
| 忠诚 | 0—100 | 是否执行命令、是否留下 |
| 健康 | 0—100 | 岗位能力和死亡风险 |
| 疲劳 | 0—100 | 执行速度、事故和情绪 |
| 好感 | -100—100 | 对玩家的私人态度 |
| 信任 | 0—100 | 是否相信玩家承诺 |
| 恐惧 | 0—100 | 是否服从但可能积累怨恨 |

## 3. 关系事件

重要事件：

- 玩家按时发工资；
- 玩家克扣或拖欠工资；
- 玩家救援船员；
- 玩家让船员承担过高风险；
- 玩家在宗教或文化上羞辱船员；
- 玩家兑现承诺；
- 玩家公开奖励或惩罚；
- 船员之间争抢岗位；
- 船员在战斗中互相救援；
- 船员死亡或失踪。

每个事件有数值变化和文案表现，数值由 CrewSystem 裁决。

## 4. 会议与冲突

当以下条件满足时触发会议：

- 两个核心船员关系低于冲突阈值；
- 船长做出高风险决定；
- 资源不足；
- 文化或宗教冲突；
- 工资、战利品或岗位分配争议；
- 船员要求改变航线。

会议流程：

1. 船员提出观点；
2. 玩家选择回应；
3. 船员根据人格和事实回应；
4. 系统计算士气、信任、忠诚和工作结果；
5. 记录长期记忆。

## 5. 叛变风险

叛变由多因素决定：

- 低忠诚；
- 长期欠薪；
- 低士气；
- 高疲劳；
- 频繁违背承诺；
- 伤亡过多；
- 领导者特质；
- 敌对势力煽动；
- 船上派系分裂。

叛变不是随机按钮。系统必须给出前兆：抱怨、消极工作、私下集会、离队请求、偷窃或拒绝执行。

## 6. 离队与招募

船员可以：

- 请求加薪；
- 请求休假；
- 申请调岗；
- 离船；
- 推荐亲友；
- 带来新的联系人；
- 在特定法律身份下寻求保护。

玩家不能把所有船员当作无条件可替换资源。
