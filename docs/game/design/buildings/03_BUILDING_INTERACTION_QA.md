# 建筑交互与验收

## 1. 交互动词

- 进入；
- 离开；
- 排队；
- 购买；
- 出售；
- 委托；
- 维修；
- 改造；
- 招募；
- 休息；
- 治疗；
- 祈祷；
- 询问；
- 检查；
- 盗窃；
- 破坏；
- 占领；
- 保护；
- 记录。

## 2. 权限

建筑交互由：

- 玩家身份；
- 势力声望；
- 法律状态；
- 开放时间；
- 门锁；
- 任务条件；
- 资金；
- 工具；
- 社群许可决定。

LLM 只表达 NPC 语气，不能绕过权限。

## 3. 建筑与 NPC

- 商人按营业时间和库存工作；
- 船匠按施工队列工作；
- 守卫巡逻和检查；
- 酒馆 NPC 在晚间聚集；
- 宗教建筑按节期和仪式开放；
- 火灾、战争、洪水会改变日程。

## 4. 验收

- 80 类建筑有目录；
- 建筑实例有唯一 ID；
- 港口可通行、可停船、可装卸；
- 船坞能调用船舶系统；
- 建筑权限和势力状态一致；
- 建筑损坏、关闭和恢复可保存；
- 没有建筑穿地、堵路和错误出生点；
- 近景交互和远景性能分层。
