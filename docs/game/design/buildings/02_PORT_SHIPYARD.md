# 港口、码头与船坞布局

## 1. 港口分区

大型港口至少拆为：

- 外锚地；
- 进港航道；
- 大船泊位；
- 小船泊位；
- 货运码头；
- 船坞；
- 市场；
- 海关和检查站；
- 军事或炮台区；
- 居民区；
- 酒馆和旅店；
- 宗教与社群区；
- 仓库区；
- 贫民或临时居住区；
- 港外农地或湿地。

## 2. 码头

码头必须支持：

- 泊位大小和吃水检查；
- 缆桩、跳板、护栏和碰撞；
- 装卸、修理、补给和上下船；
- 潮位、风浪和断缆；
- 船员、NPC 和货物通行；
- 港口服务排队。

## 3. 船坞建筑

- 临时修船棚；
- 村落船匠铺；
- 城镇船坞；
- 大型贸易港船坞；
- 军港船厂；
- 帆布工坊；
- 索具坊；
- 木工坊；
- 炮匠坊；
- 船材仓库；
- 旧船市场；
- 小艇作坊。

详细施工规则见 ship/09_SHIPYARD_ECONOMY.md。

## 4. 防御建筑

炮台、城墙、瞭望塔、军营、弹药库、检查站和拘留所至少有：

- 所属势力；
- 守卫数量；
- 射界；
- 检查规则；
- 开放时间；
- 战争状态；
- 破坏和修复状态；
- 玩家可见预警。

## 5. 建筑状态

- 正常；
- 缺货；
- 停工；
- 关闭；
- 火灾；
- 洪水；
- 战争损伤；
- 被占领；
- 被封锁；
- 正在修复；
- 废弃；
- 仅任务期间开放。
