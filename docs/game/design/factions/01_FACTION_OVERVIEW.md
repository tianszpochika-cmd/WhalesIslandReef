# 势力与社会网络总览

## 1. 势力类别

首版至少包含：

- 英格兰殖民网络；
- 西班牙殖民网络；
- 法国殖民网络；
- 荷兰贸易网络；
- 葡萄牙商贸和航海网络；
- 丹麦或北欧贸易节点；
- 原住民社群；
- 非洲裔自由和逃亡社区；
- 海盗和私掠网络；
- 走私和跨港商人网络。

游戏中的具体势力 ID、控制范围和历史状态必须按 1675 年校对。

## 3. 势力关系

关系状态：

- neutral；
- favorable；
- allied；
- tense；
- hostile；
- at_war；
- embargoed；
- occupied；
- hidden_support。

关系变化来自事实，不来自对话文案。

## 4. 玩家路线

玩家可以成为：

- 商人；
- 护航者；
- 私掠者；
- 探险家；
- 救援者；
- 走私者；
- 船坞投资者；
- 社群盟友；
- 中立调停者。

每条路线有收益、风险、法律身份和关系后果。
