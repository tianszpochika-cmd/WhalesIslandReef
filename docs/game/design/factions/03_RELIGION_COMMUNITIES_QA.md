# 宗教、社群、自由身份与势力验收

## 1. 宗教和社群

宗教设计影响：

- 节期和日程；
- 饮食；
- 葬礼；
- 承诺和誓言；
- 社群信任；
- 建筑开放；
- 角色特质和冲突。

宗教不能简单映射善恶或敌我。

## 2. 社群设计

社群可以是：

- 港口行会；
- 船员群体；
- 原住民村落；
- 商人家族；
- 宗教团体；
- 工匠社区；
- 自由黑人社区；
- 马龙或逃亡社区；
- 军队和殖民管理网络。

社群有资源、规则、内部矛盾和对外关系。

## 3. 敏感内容边界

- 人的自由身份不能作为商品；
- 强迫劳动和奴役作为历史社会制度与冲突背景处理；
- 不做轻松利润优化；
- 不把受压迫群体只写成敌人、货物或背景板；
- 真实社群需要历史和敏感内容审查；
- 提供内容警告、低表现强度和跳过选项。

## 4. 验收

- 势力有唯一 ID、控制区和政策；
- 声望、战争、禁运、私掠和检查有逻辑写者；
- 法律状态可以保存；
- 玩家有多条势力路线；
- 宗教和社群不只是颜色和旗帜；
- 历史事实与虚构内容有标记；
- Agent 不能直接改声望、法律或战争。
