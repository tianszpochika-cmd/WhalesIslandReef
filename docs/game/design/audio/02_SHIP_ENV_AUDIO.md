# 船舶与环境声音

## 1. 船舶

- 木板吱响；
- 帆布绷紧；
- 绳索摩擦；
- 桅杆受力；
- 锚链；
- 锚机；
- 舵轮；
- 水泵；
- 进水；
- 擦礁；
- 货物碰撞；
- 炮声；
- 装填；
- 缆绳张力；
- 风暴结构声。

## 2. 环境

- 海滩浪声；
- 雨林昆虫和鸟；
- 红树林泥水和蚊虫；
- 山地风和瀑布；
- 洞穴滴水、脚步和回声；
- 暗礁破浪；
- 港口人声、木板、钟和船厂。

## 3. 距离和方向

近景声音要能表达距离、遮挡和方向。声音变化不能直接改变逻辑状态。

## 4. 船员反馈

重要船员报告可用语音、字幕或日志三种方式表现，不能要求玩家必须听到才知道危险。
