# 音乐、语音与音频验收

## 1. 音乐主题

目标为 30 个音乐主题，至少覆盖：

- 主菜单；
- 初始港口；
- 航行；
- 夜航；
- 风暴；
- 战斗；
- 接舷；
- 雨林；
- 洞穴；
- 红树林；
- 贸易港；
- 酒馆；
- 宗教或社群活动；
- 任务锚点；
- 船员安静时刻；
- 结局方向。

## 2. 动态音乐

音乐根据：

- 天气；
- 航行危险；
- 战斗状态；
- 船体损伤；
- 港口状态；
- 任务阶段；
- 船员情绪

分层变化，但不由 LLM 选择音乐。

## 3. 验收

- [ ] 音频事件有唯一 ID；
- [ ] 外部资源有许可证；
- [ ] 船舶和环境音可区分；
- [ ] 关键警报不会被盖住；
- [ ] 音频有字幕或 UI 替代；
- [ ] LLM/语音不可用时仍可游玩；
- [ ] 30 个主题有目录和状态；
- [ ] 音频不会造成明显加载卡顿。
