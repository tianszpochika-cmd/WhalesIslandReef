# 动物、植被、天气与社会联动

## 1. 植物联动

- 花和果实影响鸟、昆虫和草食动物；
- 草地高度影响脚印、藏身和捕食；
- 红树林根系是幼鱼和蟹类育幼场；
- 海草床连接海龟、贝类和礁区；
- 枯木和倒树提供昆虫与洞穴；
- 农地和种植园改变动物路线。

## 2. 天气联动

- 雨季提高蛙类、蚊虫和湿地动物活动；
- 干旱使动物集中在泉眼和河流；
- 风暴前动物寻找庇护；
- 风暴后鸟、鱼、漂流物和残骸重新分布；
- 夜间改变猎食、筑巢和捕捞。

## 3. 玩家联动

玩家的狩猎、捕鱼、砍伐、火灾、噪音和污染会改变：

- 遇见率；
- 逃跑距离；
- 鱼群位置；
- 巢穴使用；
- 危险事件；
- 观察价值；
- NPC 价格和任务。

## 4. NPC 联动

- 渔民根据鱼群变化调整工作；
- 猎人根据动物数量改变路线；
- 船坞和港口根据木材资源改变价格；
- 社群可能保护某些动物或海岸；
- 商人可能交易药材、蜂蜜、皮革或渔获；
- 过度捕捞可能导致冲突和禁令。

## 5. 保护规则

动物不能只设计成可无限刷新的货物。稀有物种和生态关键物种需要：

- 限制捕捞；
- 观察优先；
- 季节窗口；
- 社群许可；
- 生态恢复；
- 法律或声望后果。
