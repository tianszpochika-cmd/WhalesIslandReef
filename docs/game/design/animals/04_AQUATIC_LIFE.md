# 水生生物与海洋生态

## 1. 水域层级

1. 潮间带：螃蟹、贝类、海藻、鸟类；
2. 红树林浅水：鱼苗、虾、幼蟹、蛇、涉禽；
3. 海草床：海龟、草食鱼、贝类和小型捕食者；
4. 珊瑚礁与礁口：礁鱼、鳐、鲨、章鱼和无脊椎动物；
5. 大陆架与外海：鱼群、飞鱼、鲸豚、海鸟；
6. 深水与海底：深水鱼、沉船、强流和大型动物。

## 2. 行为

- 鱼群受潮汐、温度、食物、捕食者、噪音和天气移动；
- 礁鱼拥有小范围领地；
- 鲨鱼受血迹、鱼群、船速和水域影响；
- 海龟在特定季节返回沙滩；
- 鲸豚通过声音和跃出水面提示海况；
- 螃蟹、贝类和海胆随潮位出现或隐藏；
- 水母和浮游生物受水温、风和洋流聚集；
- 风暴后鱼群、漂流木、珊瑚碎片和残骸重新分布。

## 3. 水生玩法

- 水面观察；
- 海色和鱼群识别；
- 手线、网、笼和岸边捕鱼；
- 浅水涉水采集；
- 海龟产卵观察；
- 鲸豚航海观察；
- 暗礁、海草和红树林保护；
- 沉船打捞；
- 风暴前后鱼群追踪。

第一版不要求完整深海潜水和复杂水下战斗。

## 4. 生态节点

珊瑚、海绵、海草、海藻、浮游生物和真菌记录：

- 生长状态；
- 水温；
- 浑浊度；
- 盐度；
- 沉积；
- 风暴损伤；
- 锚链或拖网损伤；
- 恢复时间；
- 与鱼群和玩家活动的关系。
