# 动物系统总览

## 1. 动物的作用

动物承担：

- 生境识别；
- 食物链；
- 航海提示；
- 采集、狩猎和观察；
- 疾病和危险；
- 任务与收藏；
- NPC 生产、贸易和文化关系。

动物不是随机装饰，也不使用 LLM 决定行为。

珊瑚、海绵、海草、海藻、浮游生物和真菌作为生态节点单独计入。

## 3. 动物类型

- 环境表现动物；
- 可观察动物；
- 可采集动物；
- 危险动物；
- 任务动物；
- 稀有收藏动物；
- 生态关键物种；
- 航海提示物种。

## 4. 核心原则

- 不让每只动物都攻击玩家；
- 不把动物行为写成超自然；
- 不用随机生成破坏生境分布；
- 不把真实社群的文化动物关系变成简单货币；
- 动物死亡、捕捞和观察必须影响生态或记录。
