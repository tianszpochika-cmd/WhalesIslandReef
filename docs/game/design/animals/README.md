# 动物设计

本目录专门存放陆生动物、鸟类、昆虫、淡水动物、水生生物、行为状态和生态关系。

规划文档：

- 01_ANIMAL_OVERVIEW.md：动物数量口径和行为层级；
- 02_ANIMAL_CATALOG.md：300 个动物条目和物种标签；
- 03_ANIMAL_BEHAVIOR.md：个体、群体、捕食、迁徙和巢穴；
- 04_AQUATIC_LIFE.md：鱼群、鲸豚、海龟、鲨鱼、贝类和珊瑚生态；
- 05_ECOLOGY_LINKS.md：植被、天气、捕鱼、狩猎和 NPC 活动；
- 06_ANIMAL_QA.md：刷新、生境、性能和确定性逻辑验收。

状态：第一版设计已完成；数量目标以 `docs/game/REQUIREMENTS.md` 为准，批量内容仍待 D15 生产。
