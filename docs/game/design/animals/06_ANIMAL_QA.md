# 动物系统验收

## 1. 目录

- [ ] 300 个条目有唯一 ID；
- [ ] 陆地、淡水、海洋类别数量有记录；
- [ ] 每条目有生境、行为和表现状态；
- [ ] 物种来源和资产许可完整。

## 2. 行为

- [ ] L0—L3 至少有代表性样例；
- [ ] 群体不会无限复制；
- [ ] 动物不会在错误生境刷新；
- [ ] 视觉、声音、距离和天气会影响反应；
- [ ] 危险行为有前兆；
- [ ] 动物行为不用 LLM。

## 3. 生态

- [ ] 植被变化能影响动物；
- [ ] 捕捞和狩猎能产生资源压力；
- [ ] 风暴前后有行为变化；
- [ ] 海草、红树林和礁区有生态联系；
- [ ] 稀有物种有保护和恢复规则。

## 4. 性能与存档

- [ ] 远景使用群体或代理表现；
- [ ] 近景才启用详细状态；
- [ ] 种群状态可保存；
- [ ] 刷新使用可复现种子；
- [ ] 50 座岛流式加载不被动物数量拖垮。
