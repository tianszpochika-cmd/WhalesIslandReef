# 动物行为逻辑

## 1. 行为层级

| 层级 | 内容 | 对象 |
|---|---|---|
| L0 | 待机、鸣叫、游动、飞行、远景逃跑 | 大量远景个体 |
| L1 | 视觉、声音、距离、伤害、食物和天气反应 | 近景普通动物 |
| L2 | 鱼群、鸟群、兽群、领地和首领方向 | 群居动物 |
| L3 | 觅食路线、饮水路线、巢穴、潮汐和昼夜 | 代表性动物 |
| L4 | 迁徙、产卵、捕食链、任务联动 | 关键物种 |

## 2. 基础状态

- idle；
- forage；
- drink；
- travel；
- alert；
- flee；
- attack；
- defend；
- injured；
- rest；
- shelter；
- return_to_habitat；
- dead；
- observed。

繁殖第一版以季节事件和种群状态抽象实现，不要求每个个体真实配对。

## 3. 感知

动物可以有：

- 视觉范围；
- 听觉范围；
- 气味或血迹感知；
- 潮汐和水温感知；
- 群体警报；
- 玩家、船只、火焰和炮声反应。

感知必须有距离、遮挡、风向和天气修正。

## 4. 群体行为

群体至少支持：

- 聚集；
- 分散；
- 领头移动；
- 警戒传播；
- 共同逃跑；
- 资源竞争；
- 受伤个体脱离；
- 暴风前寻找庇护。

## 5. 危险行为

危险判定由：

- 攻击性；
- 饥饿；
- 领地；
- 玩家距离；
- 玩家是否携带血迹；
- 是否靠近巢穴；
- 群体数量；
- 可逃路线；
- 天气和时间决定。

动物不应在所有情况下主动追杀玩家。

## 6. 生态关系

- 植物减少会降低草食动物觅食成功；
- 草食动物减少会影响捕食者；
- 过度捕捞会让鱼群转移；
- 清除红树林会减少幼鱼、螃蟹和涉禽；
- 污染和沉积会降低海草、珊瑚和淡水质量；
- 风暴改变鱼群、漂流木、死鱼和残骸分布。
