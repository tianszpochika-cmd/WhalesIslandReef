# 【D1 收官验收】三个任务的执行方案（含一键脚本）

> 状态：2026-08-08 ｜ 用途：D1 最后三步的执行说明
> **关键结论**：三个任务都必须在 **Unity GUI** 内执行（外部 agent 无 Unity GUI 环境，batchmode License 不可用），因此**由你操作**——但已提供"一键验收脚本"把三步合成**一次菜单点击**。

---

## 任务分析（为什么必须你操作）

| 任务 | 内容 | 能否交给外部 agent | 原因 |
|---|---|---|---|
| ① Test Runner | 跑 EditMode 8 个测试 | ❌ 不能 | Test Runner 是 Unity GUI 面板；batchmode License 在本机不可用 |
| ② 美化脚本 | Tools > Install Harbor Art | ❌ 不能 | 是 Unity 菜单/Editor 脚本，需 Unity 运行 |
| ③ 验证场景 | 打开 InitialHarbor 看效果 | ❌ 不能 | 场景视图操作 |

> 替代方案：外部 agent 能写"脚本"（如 D1Acceptance.cs），但**运行**必须你点。

---

## 方案 A：一键验收（推荐，1 次点击）

已写好 `game/Assets/Editor/D1Acceptance.cs`（提交待做）。Unity 操作：

1. 打开 Unity 工程（等编译完成、Console 无红错）
2. 菜单栏 **Tools → Whalebone → D1 一键验收 (测试+美化+打开场景)**
3. 自动依次执行：
   - ① EditMode 测试（约 10-60 秒，Console 显示 `[D1Acceptance] ① 测试完成：Passed=8 Failed=0`）
   - ② 全绿 → 自动跑港口美化（`[D1Acceptance] ② 测试全绿，执行港口 CC0 美化`）
   - ③ 打开 InitialHarbor 场景 + 弹窗提示
4. 弹窗显示 "✅ 测试全绿（8/8）..." → 点 **Play** 查看美化后的港口

**若测试失败**：脚本自动中止后续并弹窗提示 → 打开 Window → General → Test Runner 看失败详情，贴给我修复。

**若美化异常**：弹窗显示异常信息 → 截图给我。

## 方案 B：手动分步（不用一键脚本时）

1. **① 测试**：Window → General → Test Runner → **EditMode** 页 → **Run All** → 预期 "Passed: 8/8"
2. **② 美化**：菜单 **Tools → Whalebone → Install Harbor Art (占位美化, 幂等)** → Console 应显示完成日志
3. **③ 验证**：双击 `Assets/Scenes/InitialHarbor.unity` → 点 Play → 预期看到：**蓝色海面 / 沙色沙滩 / 木色码头 / 像样的船 / 老水手 / 椰树植被 / 暖色天空**
