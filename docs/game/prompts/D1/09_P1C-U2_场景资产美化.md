# 【提示词 P1C-U2】初始环境场景资产美化（在线获取 CC0 模型嵌入）

## 角色与任务
你是《鲸骨航线》（1675 加勒比海开放世界航海沙盒 RPG）的场景美术工程师。
任务：把 InitialHarbor（圣玛格丽特港）从"纯色几何体灰盒"升级为**带真实感占位资产的场景**——在线获取 CC0 免费模型，通过 Editor 脚本嵌入。

## 必读（按序）
1. `docs/AGENTS.md`（铁律 5 条）
2. `docs/game/SETUP.md` 第 4-5 节（占位素材纪律：只 CC0/CC-BY、`ph_` 前缀、授权登记）
3. `docs/ARCHITECTURE.md` 8.1（资源位置规范）
4. `docs/DEVELOPMENT_STANDARDS.md` 第 1 节（单一写者：你只写 `Assets/Art/Placeholder/`、`Assets/Prefabs/Placeholder/`、`Assets/Editor/HarborArtInstaller.cs`、`Assets/Scenes/InitialHarbor.unity`（经脚本生成）、`PH_ASSET_SOURCES.md`）与第 8 节（DoD）

## 前置依赖（D1 已通过）
- Unity 工程可运行；InitialHarbor 场景可用（当前是纯色几何体灰盒）
- `Assets/Editor/InitialHarborBuilder.cs` 已存在（代码生成场景的模式，**沿用此模式**）
- 本机 batchmode License 不稳 → **你无法跑 Unity GUI** → **一切场景改动必须通过 Editor 脚本实现**，由用户最后在 Unity 里点一次菜单执行

## 任务清单

### 1. 素材获取（在线下载，白名单平台）
只允许以下 CC0/CC-BY 平台（**禁止**其他来源，版权不明一律不用）：
- **Kenney.nl**（已在本机 `assets/placeholder/` 有 Ship Builder Kit / Prototype Kit / Nature Kit——先检查这些包，能用就用，缺什么再下）
- **Quaternius**（quaternius.com，CC0 低模资产丰富：热带植被/建筑/船）
- **Poly Haven**（polyhaven.com，CC0 贴图/HDRI）
- **Sketchfab**（只筛选 License = CC0 的模型）
- **Unity Asset Store 免费包**（仅限 "Free" + 商用许可）
> 若网络受限下载失败：**降级方案**——用 Unity 内置几何体 + 自写 URP 材质（纯代码零下载），但优先在线获取。

### 2. 素材整理（按 ARCHITECTURE 8.1）
- 模型 → `Assets/Art/Placeholder/Models/{Ships,Crew,Island,Props}`
- 贴图 → `Assets/Art/Placeholder/Textures/`
- 命名：`ph_` 前缀（`ph_ship_fishing`、`ph_palm_tree`、`ph_rock`…）
- 更新 `Assets/Art/Placeholder/PH_ASSET_SOURCES.md`（来源 URL / 授权类型 / 下载日期 / 用途）

### 3. 写 Editor 脚本 `Assets/Editor/HarborArtInstaller.cs`（★核心交付，全部改动走这里）
菜单：`Tools > Whalebone > Install Harbor Art (占位美化, 幂等)`
用代码完成（**绝不手写场景 YAML**——D1 教训：手写 YAML 会 fileID 重复）：
- **海面**：给海面 Plane 换蓝色 URP Lit 材质（半透明蓝、轻微波浪动画可选——不做也行）
- **沙滩**：沙黄色材质 + 少量岩石（Nature Kit / 内置 Sphere 压扁）
- **码头**：木板纹理（木色材质）+ 现有木桶/货箱换带纹理版 + 系缆桩/跳板保留
- **船**：用 Ship Builder Kit 拼一艘更像样的小渔船（或下载现成 CC0 渔船模型），替换 `ph_ship_fishing`
- **老水手**：用 Prototype Kit / Quaternius 人形模型，替换 `ph_crew_male`（保留站船头朝向）
- **植被**：椰树 4-6 棵 + 灌木/草丛（Nature Kit / Quaternius 热带植被），沿沙滩边缘布置
- **灯光**：暖色 Directional（加勒比午间）+ 环境光调亮（当前场景偏暗）
- **天空盒**：URP 默认天空盒（或 Poly Haven HDRI 免费 4K）——至少保证不再是纯紫
- **保留**：CameraFollow 绑定、UGUI 地名标签、Build Settings 场景顺序
- 幂等：重复执行先清旧产物再重建；**不触碰** `Assets/Scripts/` 任何逻辑代码

### 4. 场景嵌入验证（脚本内自检）
脚本执行后打印：已放置对象清单 + 数量；提供 `HarborArtSmoke.cs`（可选）：断言场景内存在船/老水手/椰树/海面材质，供用户 GUI 跑 Tools 菜单验证。
