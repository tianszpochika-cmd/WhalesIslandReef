你是《鲸骨航线》的集成测试工程师。任务：把 P0/P1A/P1B/P1C 的成果合流，跑通完整链路并打包冒烟。

## 任务清单
1. **合流检查**：
   - Build Settings 场景顺序：`MainMenu`（0 号）→ `InitialHarbor`（1 号）→ `Bootstrap`（可选移除）
   - 全工程编译零错误、零警告残留
2. **全链路手测**（编辑器内）：
   - 启动 → 主菜单正常显示
   - **新游戏**：输入船长名"测试船长" → 确认 → 存档创建（SaveSystem.NewGame 真实执行）→ 场景切到 InitialHarbor → 看到港口 + 船 + 老水手 + "圣玛格丽特港"标签
   - 退出编辑器 → 重启 → 主菜单 **继续** 按钮可用（HasSave()==true）→ 点击 → 回到 InitialHarbor，船长名/金钱从存档恢复
   - **设置**：改音量/语言（切 English 后 UI 文本变英文）→ 重启后设置保持
   - **关于**：显示版本 v0.1.0-D1
   - 边界：删除存档文件后，继续按钮置灰
3. **单测**：运行全部 Edit Mode 测试（SaveSystemTests 等）全绿
4. **打包冒烟**：Build Windows Standalone → 运行 exe → 主菜单出现 → 新游戏进港口 → 退出 → 重启 exe → 继续读档成功
5. **修复原则**：集成中发现的问题，**只修"接线/顺序/引用"类问题**（如场景顺序、按钮事件未绑定）；逻辑缺陷回报统筹者指派到对应模块，禁止跨模块大改。
