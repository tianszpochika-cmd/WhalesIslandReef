## 任务清单
1. **Unity 项目**：用 Unity Hub 在 `game/` 创建 Unity 6 LTS（6000.x）URP 模板项目（若 Hub 提示目录非空，先备份 Assets 内 .gitkeep 再创建，最后恢复）；确认能打开编辑器无报错。
2. **版本控制**：`git init`（若未做）+ 启用 Git LFS + 确认 `.gitignore`（根目录已有）生效；首次提交。
3. **目录规范落地**：确保 `Assets/Scripts/{Core,Gameplay,Systems,Agent,Networking}`、`Assets/{Art,Audio,Prefabs,UI,Settings,ThirdParty}` 存在（缺失则建）。
4. **AgentCore 接入**：在 `Assets/Scripts/` 下创建 asmdef（`Whalebone.Agent.Runtime`），引用方式：把 `game/AgentCore/` 的 .cs 源码以链接/复制方式纳入 Unity 编译，**且保持 `game/AgentCore/` 可独立 `dotnet build`**（AgentCore 自身 csproj 不动）。Unity 内编译零错误。
5. **SaveSystem 接口桩**（★并行开发的关键契约）：新建 `Assets/Scripts/Systems/Save/SaveSystem.cs`，定义并实现**桩版本**（可编译、返回默认值）：
```csharp
namespace Whalebone.Systems.Save
{
    public struct NewGameParams
    {
        public string CaptainName;   // 船长名
        public string ShipTypeId;    // 默认 "small_fishing"
    }
    public static class SaveSystem
    {
        public static bool HasSave();                    // 桩：返回 false
        public static void NewGame(NewGameParams p);     // 桩：空实现
        public static void Save();                       // 桩：空实现
        public static bool Load();                       // 桩：返回 false
    }
}
```
> ⚠️ 此签名是 P1A（调用）与 P1B（实现）之间的**唯一契约**，不得修改；如需扩展先回报统筹者。

6. **输入系统**：启用新版 Input System；创建空场景 `Assets/Scenes/Bootstrap.unity` 加入 Build Settings；构建目标设为 Windows Standalone。
