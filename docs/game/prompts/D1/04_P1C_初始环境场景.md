# 【提示词 P1C】初始环境场景 — 可并行

## 角色与任务
你是《鲸骨航线》的场景搭建工程师。任务：搭建初始环境场景（初始港口 + 玩家的船 + 老水手 NPC），全部用**占位素材**（灰盒开发）。

## 必读
1. `docs/AGENTS.md`（铁律）
2. `docs/game/SETUP.md` 第 4-5 节（占位素材纪律：只用 CC0/CC-BY；`Art/Placeholder/` 集中放；`ph_` 前缀）
3. `docs/ARCHITECTURE.md` 8.1（资源位置规范）
4. `docs/DEVELOPMENT_STANDARDS.md` 第 1 节（所有权：你只写 `Assets/Scenes/InitialHarbor.unity`、`Assets/Art/Placeholder/`、`Assets/Prefabs/` 下 `ph_` 前缀的 Prefab）

## 前置依赖（P0 已完成）
- 工程可运行；无需等待 P1A/P1B（场景独立）。

## 任务清单
1. **场景**：新建 `Assets/Scenes/InitialHarbor.unity` 加入 Build Settings；场景名=初始港口"圣玛格丽特港"（与 P1B 种子数据中初始位置一致）。
2. **占位资产准备**（可下载 Kenney.nl 的船只/角色/环境 CC0 包，或 Unity 免费包；禁止版权不明素材）：
   - 港口地面（码头木板/沙滩）、海面（URP 默认水占位或平面+半透明材质）
   - 小渔船（`ph_ship_fishing`）、人物（`ph_crew_male` 用标准胶囊体+简单材质即可，或 Kenney 低模人形）
3. **场景布置**：
   - 主光照（Directional，暖色调=加勒比午间）+ 环境光；Camera 第三人称占位（可围绕船旋转的简单跟随脚本放 `Assets/Scripts/Gameplay/CameraFollow.cs`）
   - 港口码头 + 船停靠码头边 + 老水手站在船头（面向大海，简单 Idle 动画或静止）
   - 简单 UI 提示占位："圣玛格丽特港" 地名标签（TextMeshPro 或 UGUI 文本）
4. **可加载性**：场景可从 Build Settings 独立运行（把 InitialHarbor 临时设为起始场景用于自测，**交付时恢复 MainMenu 为起始场景**——若 MainMenu 尚不存在，标注清楚让 P2 处理）。

## 验收（DoD）
- [ ] 场景可加载运行：能看到港口 + 船 + 老水手；相机跟随船
- [ ] 全部素材为 CC0/CC-BY 或占位几何体；`ph_` 前缀；集中在 Placeholder/Prefabs 对应目录
- [ ] 无任何逻辑系统代码（场景搭建职责）；CameraFollow 除外

## 输出与留痕
`git commit -m "feat: D1-P1C 初始环境场景 (DEV_ROADMAP D1)"`；回报：场景路径、资产来源清单、相机脚本位置。
