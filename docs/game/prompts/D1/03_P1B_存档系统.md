# 【提示词 P1B】存档系统与新游戏数据流 — 可并行

## 角色与任务
你是《鲸骨航线》的强逻辑层工程师。任务：实现 SaveSystem 真实逻辑（SQLite 存档）+ 新游戏数据流（Player/Ship/CrewAgent 生成）。

## 必读
1. `docs/AGENTS.md`（铁律——尤其"强逻辑红线"：你的代码**禁止**任何 LLM/网络调用）
2. `docs/game/design/DATA_MODELS.md` 第 1-7 节（Player/Ship/CrewAgent/TraitDef/ShipTypeDef 字段 + SQLite 表）
3. `docs/DEVELOPMENT_STANDARDS.md` 第 1、4、8 节（所有权：你只写 `Assets/Scripts/Systems/` 下 Save/Trait/ShipType 相关 + 单测；命名与 DoD）

## 前置依赖（P0 已完成）
- `SaveSystem` 接口桩存在（签名见 P0 提示词）——**你实现它，不改签名**

## 任务清单
1. **SQLite 接入**：Unity 6 下用官方 `com.unity.sqlite`（或经统筹同意的等价方案，如 sqlite-net 源码包）引入；数据库文件位置：`Application.persistentDataPath/save.db`。
2. **建表与迁移**（对应 DATA_MODELS 第 7 节，字段按文档）：
```sql
players(id TEXT PK, name TEXT, money INT, skills_json TEXT, traits_json TEXT, reputation_json TEXT, inventory_json TEXT, ship_id TEXT, location_json TEXT, play_seconds INT)
ships(id TEXT PK, ship_type_id TEXT, name TEXT, hull INT, cargo_json TEXT, cannons INT, loaded_count INT, supplies_json TEXT, crew_json TEXT, upgrades_json TEXT, state_json TEXT, ship_log_json TEXT)
crew_agents(id TEXT PK, name TEXT, role TEXT, culture TEXT, traits_json TEXT, stats_json TEXT, persona_json TEXT, memory_json TEXT, relations_json TEXT)
trait_defs(id TEXT PK, name TEXT, category TEXT, desc TEXT, stat_mods_json TEXT, persona_note TEXT, event_mods_json TEXT)
ship_type_defs(id TEXT PK, name TEXT, speed REAL, turn REAL, cargo_max INT, crew_max INT, cannon_max INT, hull_max INT, draft REAL, price INT)
```
3. **种子数据**：`trait_defs` 首批 **20 条**（身体 8 + 性格 8 + 经历 4，中文名，示例：强壮/瘦弱/肺病/好视力/贪婪/怯懦/忠诚/嗜酒/豪爽/记仇/乐天/谨慎/老水手/前私掠者/逃犯/传教士/医学徒/落难贵族/前海军/酒量好）；`ship_type_defs` 首批 **2 条**（small_fishing 小渔船 / sloop 单桅纵帆船，属性自定合理值并史实锚定）。
4. **NewGame 数据流**（实现 `SaveSystem.NewGame(NewGameParams)`）：
   - 生成 Player（船长名、初始金钱 500、技能默认 1、初始位置=初始港口"圣玛格丽特港"）
   - 生成 Ship（small_fishing，满耐久，船员 1 人：**老水手** CrewAgent——随机 3-4 条特质、culture=eng、role=deckhand）
   - 全部落库（players/ships/crew_agents 三表）；`HasSave()` 返回 true
5. **Save/Load**：`Save()` 把内存状态（Player/Ship/CrewAgent 对象）序列化回三表；`Load()` 读表还原为内存对象并返回 true/false。
6. **数据访问层**：提供 `GameState`（静态持有当前 Player/Ship/CrewAgent 列表，供 P2 与后续阶段使用）——只写你自己的目录。
7. **单元测试**：`Assets/Tests/EditMode/SaveSystemTests.cs`（Unity Test Framework）：NewGame → HasSave true → Save → Load 还原字段一致；种子数据条数正确。
