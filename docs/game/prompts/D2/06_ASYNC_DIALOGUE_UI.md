# D2 异步任务 06：Unity 游戏内对话 UI

你负责 Unity 对话表现层。前置条件：同步任务 01 已完成；任务 05 的公开调用方式已明确。若任务 05 尚未完成，使用 D2_SCOPE 中冻结的接口和本地 Mock，不等待 Ollama。

## 负责范围

- `game/Assets/Scripts/Gameplay/UI/Dialogue/`。
- 必要的独立 UI Prefab/场景局部对象、输入提示和本地化文案。

## 实现目标

- 玩家靠近老水手或按明确按键即可打开对话面板。
- 显示角色名、回复文本、情绪和好感变化；有加载中、超时、失败和模板兜底状态。
- 对话期间锁定人物/船控制，关闭后恢复控制；ESC 与暂停菜单不互相吞输入。
- 无 Ollama、断网或返回非法内容时，玩家仍能完成一次完整对话。
- 只发起对话请求和显示结果，不自己裁决数值。

## 硬约束

- 不修改 AgentCore 内部算法、SaveSystem 或航行系统。
- 不在 UI 中直接改 `CrewAgent` 好感；通过冻结的领域接口交给逻辑层。
- 所有动态文本使用现有 Localization 机制或在报告中说明临时文案。
- EventSystem/InputSystemUIInputModule 必须复用项目现有约定，避免重建多个 EventSystem。

## 验证

- Mock 模式完成至少 3 轮对话；输入框、确认、关闭、ESC 和暂停恢复可用。
- Ollama 不运行时不黑屏、不无限加载、不每帧刷错。
- 16:9、窗口缩放和鼠标/键盘操作均可用。
- 更新当日记忆日志并返回修改文件、接入点、测试步骤和已知限制。
