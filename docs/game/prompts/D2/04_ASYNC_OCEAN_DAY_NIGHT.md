# D2 异步任务 04：海洋适配、昼夜循环与场景预览

你负责 D2 的世界表现层。前置条件：同步任务 01 已完成，并且已阅读 `docs/game/design/D2_SCOPE.md`。

## 负责范围

- `game/Assets/Scripts/Gameplay/World/` 或 D2_SCOPE 指定的世界表现目录。
- 需要时新增独立的 SeaTrial/InitialHarbor 预览场景与占位材质；尽量不要直接改公共主菜单和存档代码。

## 实现目标

1. 提供 `OceanAdapter` 或等价替换点：Crest 已安装时可以接入，未安装时用低成本海面占位实现，不能因为插件缺失让场景黑屏或卡死。
2. 实现可观察的昼夜循环：太阳/环境光/天空颜色或海面颜色至少有明确变化，并能暂停、继续、重置和保存/恢复时间。
3. 场景中提供清晰的船、甲板/港口、水面和玩家出生点，镜头不会出生在模型内部。

## 硬约束

- 不把 Crest 类型泄漏到 `Systems/` 或 AgentCore。
- 不改变航行数值、不处理好感、不调用 LLM/网络。
- 插件未安装、材质缺失或场景对象缺失时必须有安全降级和一次性明确日志，禁止每帧刷错。
- 不覆盖其他 Agent 正在使用的共享场景根对象；如必须修改，在回报中列出冲突点。

## 验证

- 在 Unity 中进入预览场景，确认海面可见、昼夜至少经历一个完整周期、暂停后时间不继续。
- 无 Crest 时也能运行；Console 不出现每帧重复错误。
- 检查相机和出生点在 16:9 与窗口缩放下都可见。
- 更新当日记忆日志并返回修改文件、运行步骤和已知插件依赖。
