# D2 同步任务 08：Unity 运行时集成

你是 D2 集成负责人。只有在异步任务 03-06 都已交付并提供测试结果后开始。先审查它们的 diff，再合并；不要盲目复制文件。

## 目标闭环

从 MainMenu 新游戏进入 InitialHarbor/SeaTrial 后：

1. 玩家能在甲板/港口区域用 WASD 或方向键移动，鼠标右键/中键调整第三人称视角，滚轮缩放。
2. 通过明确的控制权切换让玩家能控制一艘船前进、减速和转向；船不会因为没有 Crest 或缺材质而卡死。
3. 海面与昼夜循环可见；暂停时航行和时间都停止。
4. 玩家能接近老水手打开对话 UI，Mock/Ollama 任一方式都能完成一次对话。
5. ESC 打开暂停菜单，继续、返回主菜单和退出均可用，返回后再次继续不会叠加旧对象/EventSystem。

## 集成规则

- 航行数值只由航行系统写入，Unity 组件只转换输入和展示状态。
- 对话 UI 只调用 AgentCore/适配器，不直接修改存档数值。
- 场景对象查找必须有稳定标识和安全降级；禁止每帧 Find、每帧报错或自动重复创建。
- 保持 D1 的主菜单、Continue 和 ESC 行为不回归。

## 验收

- 在 Unity Editor 至少完成冷启动、新游戏、移动/视角、航行、昼夜、对话、暂停/返回、继续八项手测。
- Console 无红色错误、无重复每帧日志；Ollama 关闭时仍可玩。
- 运行 AgentCore build 和相关测试；记录 Unity 手测结果、场景步骤和缺陷。
- 更新 D2_SCOPE 的状态和当日记忆日志。
