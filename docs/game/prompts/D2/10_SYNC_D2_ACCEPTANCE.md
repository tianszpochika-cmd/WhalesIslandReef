# D2 同步任务 10：最终验收与收口

你是 D2 验收负责人。只有任务 09 完成后执行；本任务只修复阻塞 D2 DoD 的问题，不顺手扩展内容。

## 必测流程

1. 关闭 Unity/清理运行态后冷启动。
2. 新游戏 → InitialHarbor/SeaTrial。
3. 人物移动、第三人称视角、船只前进/减速/转向。
4. 等待或加速观察昼夜变化；ESC 暂停后确认时间和船不动。
5. 与老水手完成一次 Mock 对话；Ollama 可用时再完成一次本地 AI 对话。
6. 验证 AgentReply 非法/超时时模板兜底，且好感只按合法结果变化。
7. 保存 → 返回主菜单 → Continue；确认船、位置、昼夜和好感恢复。
8. 关闭并重新打开 Unity，再执行 Continue；确认没有重复 EventSystem、重复场景对象、黑屏、紫色材质和每帧报错。

## DoD

- 船能开，人物能动，视角能调。
- 海面/占位海面和昼夜循环可见。
- 本地 AI 不可用时游戏仍可玩。
- 对话、校验、好感、状态反馈、存档/读档闭环成立。
- Console 无 D2 阻塞错误；日志可定位失败阶段但不刷屏。
- AgentCore 独立构建通过，服务端若已实现则 `npm run build` 通过。
- 文档、当日记忆和交接说明完整。

## 交付

输出一份 `docs/game/design/D2_ACCEPTANCE_REPORT.md`：测试环境、版本、步骤、结果、截图/日志位置、剩余已知问题和是否建议标记 D2 完成。只有全部 DoD 通过才能写“D2 验收通过”。
