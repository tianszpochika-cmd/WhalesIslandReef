# 开发目标宣言（Design Pillars）v1.0

> 状态：**已定案**（2026-08-07）｜ 定位：**一切设计决策的仲裁依据**。
> 任何系统、内容、玩法与支柱冲突时，以支柱为准；支柱之间冲突时，序号小的优先。

---

## 0. 时代设定（已定案）

- **故事开始：1675 年，加勒比海。**
- 时代背景（支撑设计的史实锚点）：
  - 1648 三十年战争结束，欧陆进入英西法荷四国角力期；
  - 1665 英国夺取牙买加，皇家港成为海盗温床；
  - 1670 马德里条约：英西互相承认加勒比领地——殖民地格局初步固化，冲突转入贸易与私掠；
  - **海盗黄金时代（1650-1730）开篇**：私掠证、悬赏、宝藏传说盛行；
  - **西班牙珍宝船队（Flota）** 每年往返本土与新大陆——财富的具象，寻宝与拦截的目标；
  - 船型谱系：卡拉维尔 / 盖伦 / 横帆 / 纵帆并存，舰载火炮成熟（6-24 磅）；
  - 医学时代特征：坏血病、热病、外科截肢、草药学——医生是稀缺资源。
- **为什么是 1675**：四国殖民地并存且冲突密集（战争状态可演化）；珍宝船队活跃（目标明确）；船型多样（战术与经营选择丰富）；海盗文化全盛（叙事土壤）；尚未被 18 世纪工业化的"现代性"稀释。

## 1. 设计支柱（6 根，按优先级）

### P1 真实主义（写实，无奇幻）
- **世界是死寂而真实的大海**：风、浪、洋流、潮汐、昼夜、天气共同驱动世界，玩家能感知并利用它们，而非观赏它们。
- **动物是真实的**：鲸群、海豚随船、鲨鱼嗅血、海龟产卵、鸟群导航、蝠鲼跃出水面——真实物种，真实行为。
- **没有魔法、海怪、超自然**：神秘可以存在（未知海域、传闻、宝藏传说），但根源是人造物、自然现象或信息差，不是奇幻。
- **"真实的互动"优先于"超自然的演出"**：宁可让玩家研究季风航线，也不让海怪当 Boss。

### P2 沙盒自由
- 世界不设线性轨道：玩家从一叶渔船起步，商人 / 海盗 / 探险家 / 寻宝人 / 殖民者——**任何路径都通向成长**。
- **后期可经营岛屿、改变势力版图**：建立殖民地、造船坞、招募驻军、与列强博弈（沙盒的终局形态）。
- **世界在玩家缺席时也自行运转**：列强开战停战、物价波动、海盗活跃度、港口兴衰——玩家影响世界，世界也独立于玩家。
- 存档是"世界的快照"，不是"剧情的进度条"。

### P3 任务 = 引导器，不是束缚
- **主线简单而合理**：作用是"教会玩家这个世界怎么玩"（学习设定：贸易、航行、船员、探索），不强制进度、不催进度。
- **支线支持探索 / 玩法拓展 / 收藏 / 寻宝**：是内容入口（带你发现世界的角落），不是工作清单。
- 任务失败不惩罚世界**结构**（不因错过任务失去不可逆内容），只影响当事人际与声望。
- 目标感来自玩家的自我设定，来自"下一次远航要干什么"。

### P4 现实主义的获取与代价（高成本高回报，但不过度设障）
- **成本符合史实**：一艘盖伦的造价、一位名医的薪金、优秀水手的招募——高，且玩家能理解为什么高。
- **获取途径透明、符合逻辑、不设解密门槛**：
  - 宝藏就在酋长屋里的金柜、沉船在已知海域、珍宝在堡垒宝库——**难点在于"知道去哪 + 带对装备 + 承担风险"，不在于猜谜**。
  - 稀有道具/材料：靠"信息（线索）+ 准备（装备/人员）+ 决策（路线/时机）"获得，谜题可以点缀，**不作为获取门槛**。
- 经济哲学：**付出-风险-回报曲线真实**，玩家感到"贵得值"而不是"难到烦"。

### P5 AI 船员社会（核心差异化）
- 每名船员是完整 Agent：可自由对话、有记忆、有文化、有特质、会抱怨、会背叛、会追随。
- 船员是"重交互"的载体：语言喊话指挥（P2A）、决策会议、文化冲突、人际关系演化。
- AI 服务于真实主义：Persona 注入时代与文化，船员像 1675 年的人。

### P6 强逻辑（可预测、可博弈、可复盘）
- 一切裁决落在确定性系统：经济价格、事件触发、船体物理、船员数值。
- AI 只提议，逻辑层裁决；玩家可以学习规则、预判后果、复盘原因（"为什么叛变？→ 忠诚 23 + 克扣奖金"）。

## 2. 体验目标（验收用的三句话）

1. 玩家感到 **"海是活的，人是真的"**；
2. 玩家觉得 **"我的选择有后果，我的船是我的故事"**；
3. 玩家愿意 **"为下一次远航而经营"**。

---

## 3. 范围与节奏（用户授权：不在乎开发时间）

- 完整愿景分阶段推进（M0→M3 + EA 后，见 REQUIREMENTS 第 11 节）；
- **分级是执行顺序，不是内容删减**——支柱内的设计最终全部实现；
- 每年一次"愿景对齐"：开发目标不因进度压力缩水，只调整顺序与优先级。

---

## 4. 不做什么（NON-GOALS，防止跑偏）

- ❌ 不做奇幻：无魔法、无海怪、无超自然事件（传闻可以有，落地必须写实）；
- ❌ 不做强剧情驱动：主线是引导，不是电影；
- ❌ 不做解谜式获取：谜题不构成获取的唯一门槛；
- ❌ 不做纯竞技化：战斗是手段（生存/护航/私掠），不是玩法目标；
- ❌ 不做"什么都白给"：高成本高回报是经济哲学，廉价奖励会杀死长期动机；
- ❌ 不做与时代脱节的现代观念输出：人物价值观按 1675 年写（但涉及种族/宗教/殖民等敏感主题时做**温和化处理**，规避国内监管风险——见 GAME_PLAN Part A.5）。
