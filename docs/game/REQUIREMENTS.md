## 1. 游戏概述

- **一句话**：1675 年加勒比海域的开放世界航海沙盒 RPG——你是无名水手，在英西法葡列强夹缝中经营船与船员，探索岛屿、贸易、寻宝、生存，最终经营自己的岛屿与势力。
- **类型标签**：开放世界 / 航海模拟 / 生存 / 角色扮演 / 贸易 / 沙盒经营（后期岛屿殖民地）/ 单人（多人预留）
- **背景（已定）**：**1675 年**，海盗黄金时代（1650-1730）开篇，加勒比海，英西法葡四国殖民地并存、冲突密集；西班牙珍宝船队活跃。时代依据见 `docs/game/DESIGN_PILLARS.md` 第 0 节。
- **视角**：第三人称（甲板自由行走）+ 舰桥指挥模式（船员调度/航线）
- **目标（已定）**：**沙盒**——无强制结局，玩家自选路线（商人/海盗/探险家/寻宝人/殖民者）；**后期可经营岛屿、地图势力拓展**；主线简单合理（教学引导器），支线支撑探索/玩法拓展/收藏/寻宝。
- **设计哲学（已定）**：**真实主义、无奇幻**——死寂真实的大海 + 真实海洋动物互动；获取途径符合史实逻辑、不设解密门槛。详见 `DESIGN_PILLARS.md`。
- **美术**：低多边形（Synty 类）热带加勒比风格
- **单次时长**：单航程 30-60 分钟；存档长线（数百小时）
- **初始状态（补）**：初始小船一艘（小渔船，2-3 人）、初始资金少量（够补给 + 一次小贸易）、初始船员 2-3 名（含一名老水手，作为新手引导"老师"）、初始负债 ⚠️（可选：开局背负旧船债，主线引导从还债开始——待定，默认不做）
- **失败与惩罚（补）**：沉船不删档（货物漂流可捞、船员损失不可逆）；被列强逮捕→入狱（时间+罚金）或交赎金、货物没收；被海盗抢劫→可选抵抗/投降；重伤→治疗期。**玩家角色死亡处理 ⚠️ 设计阶段定**（永久死亡 vs 复活惩罚）
- **新手引导（补）**：主线即引导器（P3 支柱）——前 3-5 个主线任务依次教会：航行/贸易/登岛/船员对话/战斗，完成后主线转为可选
- **音频方向（补）**：航海氛围（海浪/风声/帆布/雷暴环境音）+ 民间小调（辛巴达式口琴/手鼓，港口/酒馆/航行分场景）+ AI 生成 + 商用授权（见 SETUP 5.5）

## 2. 核心循环（一次航程 = 一个故事）

```
整备：船坞修船 / 市场采购 / 酒馆招募水手 / 听港口传闻
→ 航线规划：看海图 / 选目的地 / 评估天气与列强巡逻风险
→ 航行：值班轮换（舵手/瞭望/炮手）/ 天气应变 / 与船员交谈 / 突发事件
→ 遭遇：风暴 / 海盗 / 列强巡逻 / 疾病爆发 / 海图未标注的未知小岛
→ 登岛：锚泊 / 登陆采集 / 探索 / 危险遭遇（蛇/蚊虫/掠食者）/ 宝藏 / 部落交易
→ 交易与任务：城镇港商业 / 市政任务 / 黑市 / 沉船打捞
→ 结算：卖货 / 修船 / 分红 / 犒赏（影响忠诚）
→ 船员关系与文化冲突演化 → 下一航程
```

## 3. 系统设计（玩家设定 → 整合为 8 大系统）

> 元素全量登记见 `docs/game/IDEA_BANK.md`（创意池，可无限追加）；新元素按支柱排序进入各系统。

### 3.1 贸易经济系统
- 商品 14 种：香料 / 朗姆酒 / 丝绸 / 烟草 / 蔗糖 / 军火 / 黄金 / 木材 / 染料 / 咖啡 / 可可 / 兽皮 / 药材 / **契约劳工**（原"奴隶"已移除——分级与合规风险；如确需相关玩法，用"移民船票/契约劳工"表述）
- 价格公式：`基础价 × 供需系数 × 列强关税 × 事件扰动`（骨架有默认公式）
- 特色：**列强关税差**（英西法葡不同税率 → 走私/黑市玩法）；港口特产差异

### 3.2 船员状态机（含特质系统 ★玩家核心需求）
- 数值：士气 / 忠诚 / 健康 / 疲劳 / 好感（-100~100）+ 技能 8 项（操帆/领航/炮术/木工/医术/厨艺/贸易/格斗）
- **特质系统**（新建）：角色与 NPC 生成时随机 **3-4 条**特质，每条 = 数值增益/减益 + Persona 注入 + 事件概率修正
  - 分类与首批数量（共 50 条）：
    - 身体（15）：强壮 / 瘦弱 / 肺病 / 肠胃好 / 老花眼 / 伤腿 / 好视力 / 抗热 / 怕冷 / 酒量好…
    - 性格（20）：贪婪 / 怯懦 / 忠诚 / 嗜酒 / 多疑 / 冲动 / 谨慎 / 豪爽 / 记仇 / 乐天…
    - 经历（10）：老水手 / 前私掠者 / 逃犯 / 传教士 / 前海军 / 落难贵族 / 奴隶贩子 / 医生学徒…
    - 疾病（5）：坏血病 / 热病（疟疾） / 黄热病 / 痢疾 / 肺痨（"梅毒"已移除——分级风险；疟疾/黄热病是加勒比真实大杀手，更贴背景）
  - 映射示例：`肺病` → 疲劳上限 -20%、健康衰减 +50%、Persona 注入"你时常咳嗽，爬桅杆吃力"
- 叛变机制：忠诚 + 士气 + 特质（贪婪者更易被策反）→ 事件系统裁决
- **疾病与医疗**：医生职业 / 医疗舱 / 草药（登岛采集）→ 对应健康系统 ⚠️（医疗系统深度待定）
- **人际关系与爱情**（新增）：好感度深化为多维度关系（友谊 / 信任 / 爱情 / 仇恨 / 嫉妒）
  - 玩家↔NPC：对话/礼物/共患难推进感情线（分级内克制表达，不露骨）
  - NPC↔NPC：船员之间也会恋爱、结仇、争风吃醋（AI 生成互动，强逻辑触发事件）
  - 爱情影响：忠诚加成（爱着玩家的船员更忠诚）/ 叛变风险（被背叛的恋人可能投敌）/ 事件（三角恋、争风吃醋）
  - 载体：篝火夜话、酒馆舞会、港口重逢（重交互场景）
  - 分级：Steam 年龄分级问卷按"浪漫/轻微暗示"填写，不做成人内容

### 3.3 事件因果链
- 首批事件 12-15 个，三类：
  - 自然：风暴 / 台风 / 雾 / 坏血病爆发 / 鼠患 / 搁浅 / **船舱火灾**（火药库最危，真实威胁）
  - 人为：海盗袭击 / 列强登船检查 / 叛变苗头 / 船员斗殴 / 文化冲突（宗教/价值观）/ **爱情冲突（争风吃醋/背叛）**
  - 探索：沉船线索 / 宝藏地图 / 部落遭遇 / 珍稀动物目击
- 触发 = 数值阈值 + 随机 + 剧情锚点（强逻辑裁决，LLM 只生成台词与细节）

### 3.4 声望阵营与列强干涉系统（列强争夺 ★玩家核心需求）
- 阵营 7 个：英格兰 / 西班牙 / 法兰西 / 葡萄牙 / 海盗兄弟会 / 加勒比原住民 / 走私网络
- 声望效果：关税折扣 / 专属任务（护航、私掠证）/ 港口通行权 / 通缉与悬赏
- **战争状态**：列强间开战/停战会改变海域局势（巡逻强度、商品价格）→ 玩家可火中取栗
- **海上强国干涉（新增深化）**：1675 常态——
  - **禁运/封锁**：特定港口禁运 → 走私/黑市机会（高风险高回报）
  - **私掠证**：合法抢劫敌国商船（海盗路线的"合法化"，需对应国声望）
  - **扣押/登船检查**：货物合规判定，违禁品被没收/罚款
  - **护航任务**：护卫商队，列强发布
  - ⚠️ 外交谈判（作为势力代表）💡 后置
- 文化差异影响谈判（见 3.7）

### 3.5 船只系统 ★玩家核心需求（最大系统，分 4 子块）
- **3.5.1 船型**（首批 8 种，属性：航速/转向/载重/炮位/船员上限/耐久/吃水/售价）：
  - 小渔船(2-3人) → 单桅纵帆船 → 双桅纵帆船 → 横帆快船 → 小型盖伦 → 商船 → 军用盖伦(重炮) → 传奇旗舰 ⚠️（旗舰后置）
- **3.5.2 改装与装饰**：船体/帆/炮/货舱/医疗舱/厨房/住所（舱室家具）/喷漆/风帆涂鸦——全部数值化+外观层
  - ⚠️ 小游戏拓展（如修船小游戏、装填小游戏）：放 EA 后，先做数值化改装
- **3.5.3 船体状态**：耐久 → 破损 → 进水 → 倾斜（倾斜角影响甲板物品滑动/落海概率）→ 沉船（沉船后货物漂流+船员损失，不直接 Game Over）
  - 买卖：港口船坞（带旧船折价换新）
  - ⚠️ "断裂/物体物理滚动"：M2 做**简化版**（倾斜角数值 + 槽位物品落海概率），完整物理后置
- **3.5.4 驾船与岗位**：玩家设岗位（舵手/瞭望/炮手/修船/瞭望），AI 船员执行；**语言喊话 = P2A 命令**（"左满舵""升主帆""准备接舷战"）→ 这是"重交互"的旗舰卖点
  - 航线日志：自动记录（日期/航路/事件/船员日记，AI 生成摘要）
  - 武器：炮（实心弹/链弹/葡萄弹）+ 登船战（简化格斗）

### 3.6 天气系统
- 7 种：晴 / 多云 / 雨 / 大风 / 风暴 / 台风 / 浓雾（+ 黄昏/日落氛围光）
- 影响：航速 / 疲劳 / 船舱进水 / 事件概率 / 贸易价格（台风后港口缺货）

### 3.7 岛屿与生态系统 ★玩家核心需求（含文化系统）
- **地貌（已定案）**：加勒比 **热带海岛生态**——红树林 / 椰林 / 珊瑚礁 / 雨林 / 白沙滩；与 1675 加勒比背景一致（原"地中海地貌"方案已废弃）
- 岛屿类型 5 种：城镇港（船坞/商业/市政）/ 村落（部落/集市）/ 荒岛（采集/危险）/ 特殊岛（沉船/宝藏/遗迹）/ 列强要塞
- **动物逻辑（拟真降级为"可预判行为"）**：栖息地分布 + 行为状态机（觅食/警戒/攻击/繁殖提示）——完整"繁育/进食拟真"放 EA 后
  - **首批 15 种（全部真实物种，无奇幻）**：海洋 6（鲸群 / 海豚 / 鲨鱼 / 海龟 / 蝠鲼 / 鱼群）/ 无害陆生 4（鬣蜥 / 鹦鹉 / 寄居蟹 / 蟹）/ 危险 4（毒蛇 / 蚊虫群 / 鳄鱼 / 美洲豹）/ 珍稀 1（黄金鹦鹉 ⚠️（金色变种，写实化））
  - **真实行为锚点**：鲸群迁徙路线固定、海豚随船伴航、鲨鱼被血腥味吸引、海龟特定沙滩产卵（珍稀动物互动点）、鸟群指引近陆方向
  - **危险机制**：蚊虫→疾病源；毒蛇→中毒（需医生/药物）；美洲豹/鳄鱼→登岛必须"团结"（带武器/多人/火把）
- **珍稀动物交易与收藏（新增）**：捕猎/圈养/交易珍稀动物（黄金鹦鹉、海龟、鬣蜥等）——真实生意：加勒比珍稀动物运回欧洲贵族圈
  - 买家：港口收藏家 NPC、庄园主、原住民交换（文化差异定价）
  - 收藏册系统：博物收集（探险家路线的成长与声望来源）
  - ⚠️ 圈养（船上/殖民地）💡 后置
- **文化系统（4 大文化群 + 原住民）**：英格兰/西班牙/法兰西/葡萄牙 + 加勒比原住民
  - 每文化：语言口吻 / 宗教（天主教/新教/本土信仰）/ 价值观（荣誉/贸易/殖民态度）/ 行为礼仪
  - 游戏化：文化差异 → 贸易价差 / 任务解锁 / 谈判成功率 / **船员内部文化冲突事件**（AI 生成，强逻辑触发）
  - LLM 优势点：Persona 注入文化背景后，NPC 的价值观冲突对话天然真实——这是"纯 Agent"游戏最能打的差异化

### 3.8 生存与生活系统（新增 ★真实主义支柱的载体）
- **火焰**：生火（火石/燧发，技能+天气影响）；火把（夜间登岛/驱兽）；**火灾**（船舱火药库失火 = 真实威胁事件）
- **篝火**：登岛营地过夜（恢复疲劳但暴露风险）；**篝火夜话 = AI 船员交互场景**（讲故事/吐苦水/密谋/谈情——重交互新载体）
- **烹饪**：厨房舱 + 篝火烹饪；食材（捕捞/采集/采购）→ 餐食质量影响士气/健康
- **坏血病与饮食**：长期缺新鲜蔬果 → 坏血病风险；柑橘/野菜（登岛采集或港口采购）预防与治疗（1675 民间经验存在）
- **淡水**：淡水舱容量 / 登岛补水 / 干旱风险 💡
- **工具与装备（新增）**：指南针（领航精度）、望远镜（瞭望半径）、海图/六分仪（测纬度）、测深绳（防搁浅）、绳索/工具套装（采集修理效率）——挂接船员技能与 P2A 命令

## 7. AI 使用策略（成本控制）

- 必须用 LLM：自由对话 / 决策会议 / 叙事生成 / 文化冲突台词 / 传闻
- 禁止用 LLM：数值结算 / 经济价格 / 事件触发判定 / 船体物理（强逻辑红线）
- 本地 vs 云端：本地 80%（日常对话，含文化口吻） / 云端 20%（主线演出、长叙事）
- **成本预估** ⚠️：登岛/遭遇场景对话频度上升 → 单航程每船员 token 预算从 15k 上调至 20k，商业模型需覆盖（见步骤③）
