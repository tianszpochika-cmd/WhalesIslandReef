## D1 UI 点击失效修复（6ad7f13，01:02）

- 用户截图：Console 警告 `activeInputHandler: 0` + 点确认"没反应" + Game 视图仍 MainMenu 场景。

- **教训**：EventSystem/InputSystemUIInputModule 必须始终是最新且带 InputSystem UI Module 的；BuildCanvas 不应"信任"场景里的 EventSystem 状态，应每次强制建立正确状态。
