### Unity 6 API 变更教训（重要！）
- **`PlayerSettings.activeInputHandler` 和 `ActiveInputHandler` 枚举已在 Unity 6 中移除**。新 Input System 由 manifest.json 包含 `com.unity.inputsystem` 包自动启用（默认 activeInputHandler=1）
- **`GraphicsSettings.renderPipelineAsset` 在 Unity 6 中弃用**，应使用 `GraphicsSettings.defaultRenderPipeline`
- **`ScriptableObject.CreateInstance` 创建 ScriptableObject 不会写入所有 SerializeField 字段**——直接保存的 .asset 文件不完整（如 53 行），Unity 加载时标记为 Missing。修复方法：用 `Library/PackageCache/com.unity.render-pipelines.universal@9c1decc64651/Samples~/.../SamplesForwardRenderer.asset` 的 75 行完整模板覆盖
- **Unity 6 中 `Assets > Create > Rendering` 有 "URP Asset (with 2D Renderer)" 和 "URP Asset (with Universal Renderer)" 两个菜单**——3D 项目必须用后者

### URP 资产引用链（参考模板）
```
GraphicsSettings.m_CustomRenderPipeline (guid) → WhaleboneURP.asset
  WhaleboneURP.m_RendererType: 1 (=UniversalRenderer, 3D)
  WhaleboneURP.m_RendererDataList[0]: {guid} → WhaleboneURP_Renderer.asset
    WhaleboneURP_Renderer.m_Script: guid de640fe3... (=UniversalRendererData)
```
RendererType 枚举：`Custom=0, UniversalRenderer=1, _2DRenderer=2`

### 沙箱内 Unity batchmode 限制（不可绕过）
- LicenseClient 通过命名管道 IPC → 沙箱阻止握手超时
- ImportWorker 通过 TCP 端口监听 → 沙箱阻止 bind 端口（port=0）
- 仅用户桌面手动打开 Unity GUI 不受此限制（用户进程不在沙箱内）

- **观察**：999+ 警告其实是 Unity Console 累积显示（即使错误已修复，老警告仍在）。**用户需要 ① Clear Console（右上角 Clear 按钮）② Stop Play ③ 重 Play** 才能看到真实状态。
- **教训**：Unity 6 transform.rotation 写入后内部调用 .eulerAngles 触发严格检查；Unity.LookRotation 仍可能产生不正规 quaternion，必须 .normalized 双重保险。
